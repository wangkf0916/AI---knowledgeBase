## 一、功能简介

「数学 AI 练习课」是一个**探索中的创新项目**，当前处于灰度阶段。

- **定位**：学生完成某知识点核心课后，通过本课完成个性化巩固练习；
- **形态**：按猿辅导大班课框架，近似一节「**录播课**」；
- **亮点**：AI 老师**大杨**的真正 **1 对 1 私教课**——根据每个孩子的入门测结果、理解速度和回答情况，动态调整讲解内容和节奏，每个学生的课程路径**独一无二**；
- **当前灰度**：以 2026 年寒假课程「因数与倍数」为例进行灰度，春季以**加购**形式上线，班课名示例：「超级大脑私教课」。

> ℹ️ 该课程**没有回放**：课程内容根据学生实时表现动态生成，不适合以回放形式呈现；每节课提供 3 个可预约时间段替代。

## 二、学生端核心流程

### 2.1 完整流程

```
了解知识图谱 → 知识回顾（或有） → 入门测 → AI 个性化诊断
→ 基础知识讲解（或有）→ 讲错题（或有）→ 拓展题讲解（或有）→ 效果检测（必有）
```

### 2.2 各环节说明

| 环节 | 是否必有 | 说明 |
|---|---|---|
| **知识图谱** | 必有 | 展示本节课涉及的知识点结构 |
| **知识回顾** | 或有 | 一般用于复习课 |
| **入门测** | 必有 | 诊断学生知识掌握情况，结果决定后续学习路径 |
| **基础知识讲解** | 或有 | 根据入门测诊断，讲解不掌握的知识点 |
| **讲错题** | 或有 | 针对入门测中答错的题目讲解 |
| **拓展题讲解** | 或有 | 根据入门测正确数量决定是否推送 |
| **效果检测** | 必有 | 根据不掌握度个性化选题，检验学习效果 |

## 三、个性化分层算法

### 3.1 不掌握度计算

每道题与若干知识点关联，入门测完成后系统计算每个知识点的**不掌握度**：

$$不掌握度_i = \frac{\sum(e_{in} \times K_n)}{\sum N_i}$$

- $N_i$：知识点 $i$ 在入门测中出现的题目总数（同一题中出现多次算 1 次）
- $K_n$：第 $n$ 道题的权重（当前全部默认 = 1）
- $e_{in}$：知识点 $i$ 在第 $n$ 题是否做错（错 = 1，对 = 0）

### 3.1 不掌握度——大白话理解

> ℹ️ 以下公式是给产品/研发看的，辅导老师只需理解大白话版本即可。
>
> **大白话**：一个知识点在入门测里出现 5 次（5 道题都涉及到它），学生做错了 3 次，那这个知识点的不掌握度就是 3 ÷ 5 = 60%。超过 55% 的阈值，系统就判定「这孩子没掌握这个知识点」，自动安排讲解；低于阈值就跳过。所以做错越多、涉及某知识点越集中，该知识点就越容易被讲到。

### 3.2 基于不掌握度的动态路径

**基础知识讲解触发条件**（同时满足）：
- 入门测错误 ≥ 1（可动态配置）
- 该知识点不掌握度 ≥ 55%（可动态配置）
- 教案中已生产该知识点的剧本

**拓展题讲解触发条件**：

| 入门测错题数 | 拓展题安排 |
|---|---|
| 错误 > 1 | 不学习拓展题 |
| 错误 = 1 | 学习拓展题 1 |
| 错误 = 0 | 学习拓展题 1 和 2 |

**效果检测选题逻辑**：题目预选池中，根据每个知识点的不掌握度动态选题，并按展示重要性排序。

## 四、课程基本信息与预约机制

### 4.1 班课结构

学生购买的是一个「**班课**」，班课下包含多节「**课程**」：

| 层级 | 示例 |
|---|---|
| 班课 | 超级大脑私教课 |
| 课程 1 | 四则运算 |
| 课程 2 | 运算律 |
| 课程 3 | 小数的意义和性质 |

### 4.2 时间机制

每节课程有 **3 个行课时间**，教室开放时间均为当天 **19:00**：

| 概念 | 含义 |
|---|---|
| **默认时间** | 学生购课时每节课默认的上课时间 |
| **可选时间** | 每节课可供预约的时间段，每段为当天 19:00 起 24 小时，共 3 个 |
| **履约周期** | 从第一个可选时间开始，到最后一个可选时间结束的完整时间段 |
| **预约时间** | 学生实际选定的那一个可选时间段 |
| **教室关闭时间** | 预约时间段结束前 **2 小时**，教室将不再允许新进入 |

> ⚠️ 每节课程有**独立的履约周期**，学生必须在该周期内完成预约和上课，**过期后无法补课**。

### 4.3 支持设备

| 设备 | 支持情况 |
|---|---|
| 手机端 | 支持上课 |
| Pad 端 | 支持上课 |
| PC 端 | **仅可查看班课卡片，不支持上课** |

### 4.4 约课开放时间（灰度示例，实际以运营配置为准）

## 五、预约流程

### 5.1 预约方式

| 方式 | 操作 |
|---|---|
| **辅导老师发 H5 链接** | 老师将预约链接发给学生，学生自主选择时间 |
| **辅导老师代操作** | 老师在后台直接帮学生预约 |

### 5.2 学生正常预约流程

1. 收到辅导老师发来的预约 H5 链接；
2. 打开链接，看到所有课程卡片及可选时间；
3. 点击某节课程，选择合适的行课日期；
4. 点击底部「确定预约」，完成预约；
5. 班课主页对应课程卡片显示预约时间。

### 5.3 更改预约时间

1. 再次打开预约链接，选择已预约的课程，切换到其他可选时间；
2. 点击「更改预约时间」；
3. 弹窗提示：「本课程已在进行中，改选时间将清空目前课程内容并重新开始，确认选择吗」；
4. 确认后完成改约。

> ⚠️ **重要**：如果学生已上过部分课程内容，改约会**清空进度**，请务必提醒用户。

## 六、上课入口状态说明

| 场景 | 按钮状态 | 点击后 |
|---|---|---|
| 未到预约时间 | 置灰「未开始」 | 提示「未到课程开始时间」 |
| 在预约时间内，未上过课，距关闭 ≥ 2 小时 | 亮起「进教室」 | 正常进入教室 |
| 在预约时间内，上过课但未完课，距关闭 ≥ 2 小时 | 亮起「进教室，部分未完成」 | 从上次退出位置继续 |
| 距教室关闭 < 2 小时，还有其他可约时间 | 亮起「需改约」 | 提示「本次课程即将结束，可联系班主任老师重新约课」 |
| 距教室关闭 < 2 小时，无其他可约时间 | 置灰 | 提示「已无可预约时间，请联系班主任老师」 |
| 课程已完课或已过期 | 显示 ✓ | 无响应 |

## 七、Focus 功能模块

### 7.1 调整用户上课时间

- 在带班表配置「**预期上课时间**」列，列内初始展示本节课的默认上课时段，老师可逐人调整；
- 在「单次课回访」Tab 下勾选用户 → 通过**高级群发**发送调整时段的链接，用户自行选择。

### 7.2 催到课

- 在带班表配置「**AI 练习课**」列，实时展示用户是否到课及行课中的相关数据；
- 带班表**每分钟自动刷新**一次，也支持手动点击列右上角「刷新」；
- 从未进教室的用户状态显示为「**未到课**」；
- 进入过教室的用户会激活上课环节，前两个环节默认为「知识讲解 & 入门测」，完成入门测后系统**自动匹配**后续行课环节（不同用户路径可能不同）。

### 7.3 实时跟课

- 根据用户「**当前状态**」筛选异常用户：
  - 离线中
  - 后台播放
  - 长时间未开口（需辅导自行识别「上一次开口时间」来判断）
- 根据「**环节进度条**」查看 / 筛选用户的行课进度，发现行课进展异常的用户进行实时跟进。

### 7.4 课后回访

- 带班表针对完课用户提供**用户分层**（取决于入门测、效果检测的作答表现）；
- 用户的**作答详情页**展示作答明细及系统评价话术，可供辅导参考取用；
- 完课后会生成**课程报告**，老师可通过私发或高级群发触达用户进行效果外化。

### 7.5 催完课

- 通过「AI 练习课」列的筛选项中「**是否完课**」，筛选未完课用户并进行相关运营。

## 八、退费规则

退费以**单节课程**为单位计算：

| 课程状态 | 条件 | 是否可退 |
|---|---|---|
| **完课履约** | 上课且达到「履约完课节点」（进入**思维大挑战**环节） | **不可退**，核销课时费 |
| **未完课** | 上过课但未达到履约完课节点 | **可退**，退还本课课时费 |
| **未行课** | 未预约或预约后未上课 | **可退**，退还本课课时费 |

> ℹ️ 退费须由用户主动发起，以整个班课为单位退，以单节课程核销状态做计费。

> ❓ **待确认**：「思维大挑战」在第二章流程中未被列为独立环节名称，与「效果检测」的关系不明确——是同一个环节的不同叫法，还是效果检测之后的独立环节？这直接影响辅导老师判断学生是否已达到履约完课节点。请向产品确认后补充。

## 十、常见问题 FAQ

| 问题 | 处理方式 |
|---|---|
| 学生打不开预约链接 / 显示空白 | 检查链接是否正确；确认学生是否有课程权限（无权限提示「当前用户无当前课程权限」）|
| 学生想改约，但提示「原课程已完成，不可更改预约」 | 该课程已完课，无法更改时间 |
| 学生想约某时间但显示置灰 | 该时段已过期，或距结束不足 2 小时；引导选其他时间段 |
| 学生在 PC 端想上课 | 当前仅支持手机和 Pad 端，PC 端只能查看班课信息 |
| 学生退出教室后想继续 | 预约时间内且距关闭 ≥ 2 小时：可重新进入从上次位置继续；距关闭 < 2 小时：联系班主任重新约课 |
| 课程报告在哪看 | 班课主页 → 对应课程卡片下方 → 点击「报告」；只有完课后才会生成报告 |
| 学生要求退费 | 参考退费规则；已完课不可退，未完课和未行课可退 |
