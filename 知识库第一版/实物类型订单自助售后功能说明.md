## 一、功能背景

随着自有商城实物类商品销量上升，C 端无自助售后能力导致在线客服压力较高。本次新增 App 侧实物商品自助售后流程（退货退款 + 仅退款），后端由 **Just 2.0 配置化工单**承接。

---

## 二、售后入口与触发条件

**入口**：订单详情页 → 「申请售后」按钮

**按钮显示条件：**
- 当前订单为**实物类型订单**且**已支付**且**非三方订单**

**按钮状态说明：**

| 状态 | 表现 | Toast 提示 |
|---|---|---|
| 商品设置不可退 | 置灰 | 本商品不支持退货，如有问题，请联系客服 |
| 超过售后周期且无已有售后单 | 置灰 | 已超过售后截止时间（xxxx年x月x日）。如有问题请联系客服 |
| 商品处于可售后状态 | 正常 | 点击跳转「选择售后类型」页面 |
| 商品已存在相关售后单 | 显示「售后详情」 | 点击进入售后单详情页 |

**售后周期认定：**
- **退款周期**：商品签收后 **7 天内**且**订单发货 10 天内**
- 签收状态 T+1 零点开始计算

## 三、售后类型

### 3.1 退货退款

**适用场景**：用户需要将商品实物退回换取退款。

**退回方式（根据订单状态区分）：**

| 订单状态 | 退回方式 | 说明 |
|---|---|---|
| 已发货未签收 | 订单拦截 | 拦截可能不成功，需用户关注后续状态，若商品已派送需协助拒收或退回 |
| 已发货已签收 | 自行寄回 | 商品寄回地址在审核通过后以短信告知，用户需填写快递单号 |

**寄回仓库地址：**

| 仓库 | 地址 |
|---|---|

| 华通仓 | 北京市平谷区马坊镇马坊南街 35 号华通云仓 收货组，电话：010-6099 9324 |
| 数核仓 | 广东省塘厦镇沙新 216 号黄金叶科技园 A 栋 3 楼数核云仓 李荣荣，电话：17702625536 |

**申请表单关键字段：**
- 申请数量（最多申请订单项剩余件数，最少 1 件）
- 申请原因（枚举选择）
- 详细描述（最多 200 字）
- 上传凭证（订单已签收时出现，最多 3 张，每张 ≤20MB，格式 jpg/jpeg/png/HEIF）
- 联系人信息（默认填充收货人信息）

---

### 3.2 仅退款

**适用场景**：无需退货，直接申请退款（任何订单状态下均需走完整售后流程）。

**申请金额限制**：最多申请当前订单项最大可退金额，支持编辑。

**其他字段**：申请原因、详细描述（不允许输入 emoji）、上传凭证（已签收时出现）、联系人信息。

---

### 3.3 申请原因枚举

| 状态 | 可选原因 |
|---|---|
| 未收货 | 不想要了 / 商品错选/多选 / 发货时间问题 / 地址信息填写错误 / 价格高于其他平台 / 没用/少用/错用优惠 |
| 已收货 | 7天无理由 / 发货时间问题 / 商品质量问题 / 商品错选/多选 / 商品破损/包装问题 / 商品与页面描述不符 / 少件/发错货/未收到货 |

## 四、售后单状态机

### 4.1 状态流转表

| 当前状态 | 可到达的下一状态 | 自动超时倒计时（可配置） |
|---|---|---|
| 已发起 | 同意退货 / 拒绝退货 / 同意退款 / 退款撤销 | **72H** 后自动同意退货 |
| 同意退货 | 已填写逆向单 / 同意退款 / 退款撤销 | **240H** 后自动撤销退款 |
| 拒绝退货 | 已发起 / 退款撤销 | **168H** 后自动撤销退款 |
| 已填写逆向单 | 同意退款 / 拒绝退款 / 退款撤销 | **240H** 后自动同意退款 |
| 同意退款 | 退款成功 / 退款失败 | — |
| 拒绝退款 | 已填写逆向单 / 退款撤销 | **168H** 后自动撤销退款 |
| 退款撤销 | — | — |
| 退款成功 | — | — |
| 退款失败 | — | — |

### 4.2 特殊规则

| 场景 | 规则 |
|---|---|
| 用户发起退货退款 + 订单**未发货** | 系统默认跳过「同意退货」流程，直接同意退款 |
| 用户发起退货退款 + 订单**已发货** | 走完整售后流程 |
| 用户发起仅退款 | 无论订单状态，均走完整售后流程 |
| 客服发起退货退款 | 发起后系统直接默认同意退货，走后续流程 |
| 客服发起仅退款 | 发起后系统直接默认同意退款 |
| 重新发起 | 生成新的售后单 |
| 修改申请 | 在原售后单上修改（不校验是否已过售后周期） |

## 五、退款规则

- 退款将退还**实际支付金额**，猿币/金币/优惠券等资产**原路返还**；
- 若原路退款失败，退款将退回**余额**，可联系客服提现；
- **有赠品**的主商品退货时，需将赠品一并退回，否则主商品无法全额退款；
- 用户上传寄回快递单号 **240H 后**仍未收到客服审核结果，系统**自动退款**。

**退款时效参考：**

| 退款渠道 | 预计到账时间 |
|---|---|
| 余额 / 金币 / 猿币 | 实时到账 |
| 微信 / 支付宝 / QQ 钱包 | 一般 1-3 天 |
| 银行卡 / 信用卡 | 一般 1-15 天（以银行为准） |
