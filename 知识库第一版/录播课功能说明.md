## 一、背景与简介

**背景**：高中暑期课程以录播产品形式售卖，用户对录播内容错误的容忍度更低，需要为主讲老师提供更便捷的录课工具。

**核心功能**：
- 老师 iPad 端支持**随时录课、分阶段重录**；
- 学生端可配置录播视频的解锁时间，教室内体验与线上回放基本一致；
- 目前处于初期探索阶段。

## 三、核心概念

### 3.1 模板课

- 老师 iPad 端录制的内容，无固定上课时间，可在解锁时间前的任意时间提前录制；
- 内容组成：老师录制的所有内容（课中 + 课间）。

**有无课间的区别：**

| 配置 | 老师录课要求 | 学生端展示 | 是否打铃 |
|---|---|---|---|
| 无课间 | 不需要录制课间 | 不展示课间 | 不打铃 |
| 有课间 | 需要录制课间 | 展示课间 | 打铃 |

### 3.2 录播视频

- 学生端看到的内容，无固定上课时间；
- 学生可在解锁时间后任意时间进教室观看（相当于看一节回放）；
- 内容组成：与模板课一致（**课间部分会被裁掉**，学生看不到课间）。

### 3.3 回放转直播课（伪直播课）

- 以模板课内容生成一节伪直播课；
- 体验基本与直播课一致：固定时间上课，所有学生同时进教室，可在讨论区发言；
- ⚠️ **无课间的模板课无法生成伪直播课**；
- 详细教程：[回放转直播使用流程](https://shimo.zhenguanyu.com/docs/jXptJr38hDQ8gyqC/)

### 3.4 时间阶段概念

| 概念 | 定义 |
|---|---|
| 课中 | 上课铃 → 相邻下一个下课铃之间的内容 |
| 课间 | 下课铃 → 相邻下一个上课铃之间的内容 |
| 课程阶段 | 上课铃 → 相邻下一个上课铃之间的内容（= 课中 + 课间，最后一个阶段除外） |

**示例**：一节课时切割为 70=【0，30，40，70】的课程：
- 【0，30】= 第一个课中；【30，40】= 课间；【0，40】= 第一个课程阶段；【40，70】= 第二个课程阶段。

## 四、课堂功能支持列表

| 类别 | 支持情况 |
|---|---|
| 课堂活动 | 随堂测、少儿互动题、跟读；其余均**不支持** |
| 基础功能 | 课堂视频、课堂音乐、动态表情、倒计时；其余均**不支持** |
| 教学内容 | 课件、板书、老师视频、老师音频；有课间的录播课学生端有打铃，无课间则无 |
| 激励 | 有激励的课程支持**答题得金币**；签到、全勤等均**不支持** |
| 讨论区 | 无（学生端用 UI 图盖住） |
| 重点内容 | 同线上，仅高中阶段支持 |

## 五、录制前准备

### 5.1 录制入口

Amaze 后台开设录播课程后，主讲老师登录**老师 iPad 端**，可在课程录制入口看到待完成任务，点击进入课程录制列表。

### 5.2 录制列表

- 仅展示**未到解锁时间**的录播课程（已过解锁时间的不展示）；
- **待录制 Tab**：未到解锁时间且未完成录制；
- **已录制 Tab**：未到解锁时间且已完成录制；
- 并班课：只需录制一次，解锁时间更晚或已过解锁时间的课程不出现在列表中。

**列表操作：**
1. 点击课程名称旁下拉按钮，可查看班课信息（含所有并班课）；
2. 点击「查看课件」，可查看对应课程的最新教案（需先在 Muse 完成备课）；
3. 点击「进入录制」→「确认」，加载**当前最新教案**开始录制（录制过程中更新教案，需重新录制后才生效）；
4. 支持班课筛选，快速找到目标班课的课程。

> ⚠️ 录播教室最长存在 **24 小时**，超时自动销毁。进入录制后需尽快完成，避免隔天继续时教室已关闭。

## 六、录制中

### 6.1 录制界面改动点

相较大班直播课，录播教室改动如下：
- 删除了**讨论区**；
- 导航栏文案：显示教室自动关闭时间（首次进入后 24 小时）；
- 返回键：仅在**非录制状态**出现；
- 新增课程录制区域，包含：录制说明、录制进度条（绿=课中 / 橘=课间 / 红=拖堂）、录制总时长、操作按钮。

### 6.2 录制操作按钮

| 按钮 | 作用 |
|---|---|
| 开始录制 | 进入录制中状态 |
| 重录本段 | 暂停录制当前阶段，回到上一个已保存的课程阶段状态，已录制内容清空（**不可逆，无二次确认**） |
| 完成本段 | 停止录制，出现弹窗可选「重新录制本阶段」或「保存进度」（存储点固定在每个课程阶段末尾） |
| 继续录制 | 完成一个阶段后，继续下一个阶段的录制 |

### 6.3 中途退出与重进

- 非录制状态下可退出教室，录制中课程会**置顶显示**，同一时间只能存在一个录播教室；
- 重进时点击「进入录制」：
  - 未超过 24 小时：「继续录制」在已保存进度的基础上继续；
  - 已超过 24 小时：弹窗提示，需重新录制整节课；
- 点击「清空重录」：清空已保存进度，加载最新教案，重新录制。

### 6.4 课间录制注意事项

下课铃响后进入课间，课间内容显示为橘色：

1. **下课铃仅作参考**，老师自行判断何时点击「进入课间」。点击时间会影响课中 / 课间内容划分，进而影响学生看到的**录播视频**内容（课间会被裁掉）；
2. 课间尽量**不要翻页、写笔迹**，否则学生看录播视频时会出现跳页 / 笔迹消失；
3. 若只录**伪直播模板课**（课间不裁掉），无此限制；
4. 是否录制课间视使用场景而定：
   - 仅用于录播视频 → 课间休息片刻即可；
   - 用于生成伪直播 → 需认真录制课间内容。

### 6.5 结算全勤与完成录制

- 最后一个课程阶段下课铃响后，有激励的课程出现「结算全勤」按钮；
- 结算全勤时，需当前**无任何教学活动 / 课堂活动**；
- 结算后出现「下课」按钮，点击后选择「保存进度」完成录制；
- 录播课最多可**拖堂 10 分钟**，超过自动关闭教室。

## 七、录制后

### 7.1 课程预览

- 老师 iPad 端**暂不支持**预览录制内容；
- 可在**管理员端（仅支持桌面端）**预览，建议每次录完都先预览，确认课件内容连贯。

**管理员端下载地址**：
```
https://amaze.zhenguanyu.com/#/clientDownload
```
（路径：Amaze 工作台 → 更多 → 客户端下载 → 管理员版客户端）

**使用说明**：
- 账号：猿辅导老师账号或学生账号，需在**内网环境**下登录；
- 操作路径：回放 Tab → 录播课 → 课程回放 → 精简版 / 完整版（也可直接搜索课程 ID）；

| 版本 | 包含内容 | 使用场景 |
|---|---|---|
| 精简版 | 课中（不含课间） | 学生看到的录播视频 |
| 完整版 | 课中 + 课间（老师录制的所有有效内容） | 以录播课为模板生成的伪直播课 |

### 7.2 重新录制

在「已录制 Tab」找到对应课程选择「重新录制」，会**清空所有已录制内容**并创建新录播教室，自动拉取 Muse 最新教案。

## 八、学生端

### 8.1 教室内

基本功能同回放，**无讨论区**。

### 8.2 教室外

**录播课有固定的开放时间，到时间后所有录播课统一解锁。**

| 展示项 | 说明 |
|---|---|
| 班课卡片 / 班课主页 | 展示班课开放时间 |
| 时间轴 | **不展示**（录播课统一时间开放） |
| 课程总时长 | 展示每节录播课的总时长 |
| 学习任务 | 「核心课 × N」，N = 未进入过教室的课程数 |
| 入口文案 | 「进入教室」 |
| 全部开放后 | 固定展示「课程已全部开放」 |
| 仅有金币榜 | 录播课只展示金币榜 |

**其他限制：**
- 录播课**不发送**课程报告；
- 录播课**不可进行**课程评价；
- 录播课**无**课前准备环节；
- 录播课允许调班，**不允许退课**（调班相当于退旧课赠新课，旧课数据完全清除）；
- 录播课**无**课前预习、课后练习、课后拓展、小老师等环节，只有核心课。
