## 一、背景

原有标签体系依赖主管通过管理手段逐级通知部署，效率低、筛选复杂时一致性难保证，且运营数据无法与用户分层策略对齐。为此产研开发了**主管标签系统**，由主管统一配置下发，一线辅导老师直接使用，并支持回收运营数据。

---

## 二、主管管理标签

**入口：** Focus 顶栏 → 管理 → 运营计划 → 标签管理

### 2.1 标签列表

- 展示标签名称、范围筛选条件、创建人；
- 支持按**部门范围**和**班课范围**筛选，支持关键词搜索；
- 自己创建的标签默认置顶；
- 支持操作：创建、修改、删除、恢复、复制。

### 2.2 创建标签

- 支持**主管及以上层级**创建，支持一次性**批量创建**；
- 管理者下发标签**无数量限制**（原先 8 个标签限制仅针对个人自定义标签，管理下发标签不受此限制）；
- 同一部门/班课范围下**不允许重名**；但允许上级分别给子部门 A 和子部门 B 配置同名标签（两者 ID 不同），请上下级提前沟通，避免名称冲突。

### 2.3 修改标签

- 仅允许修改**名称**，生效的部门和班课范围**不允许修改**；
- 如需修改范围，须先删除再新建；
- 一般只能修改自己创建的标签；换主管后，旧主管创建的本部门标签可继承修改。

### 2.4 删除标签

> ⚠️ 删除标签除归档至"已删除" Tab 外，还会**清空一线老师已给用户打的该标签标记**，操作前请提前做好团队周知。

### 2.5 恢复标签

- 支持从"已删除" Tab 恢复标签；
- 恢复后可同步恢复被清空的用户标记；
- 自动继承被恢复标签的原有配置。

### 2.6 复制标签

支持快速复制**已结束班课**下曾用的标签，自动继承原配置，减少重复填写。

## 三、带班表添加主管标签列

**入口：** Focus 顶栏 → 管理 → 运营计划 → 带班表配置 → 找到对应模板 → 点击"查看"进入编辑 → 将"**主管下发标签**"列添加到模板中。

---

## 四、辅导老师使用标签标记用户

支持入口：**带班表** · **用户个人详情** · **企微侧边栏**

与原有带班表标签操作基本一致，有两点核心区别：

| 对比项 | 主管标签 | 个人自定义标签 |
|---|---|---|
| 创建方式 | 由主管统一配置下发 | 一线老师自行创建 |
| 一线老师权限 | 只能标记/取消标记用户，**不能创建或删除** | 可自行创建和删除 |
| 数据回收 | ✅ 支持运营数据看板 | ❌ 无法回收数据 |

> ℹ️ 主管创建标签后，系统**自动下发**到对应部门和班课范围，一线老师无需重复创建即可直接使用。

## 五、标签运营数据看板

**入口：** 管理 → 带班数据 → 系统班 → 标签-运营数据

以主管创建的**标签**为维度，回收该标签下所有被标记用户的运营数据，支持：

- **时间维度**：累计查看 / 分日查看（观测趋势）；
- **数据透视**：分首续/非首续、主管、小组、个人、年级、学科、教材版本等。

**主要数据字段：**

| 分类 | 字段示例 |
|---|---|
| 标签信息 | 名称、生效部门、班课范围、覆盖班课数/老师数、标记用户数、标记率 |
| 微信数据 | 加微人数/加微率（仅学生 / 仅家长 / 学生+家长） |
| 核心课数据 | 到课率、90% 到课率、完课率、直播课测验正确率、课后环节参与人次 |
| 答疑课数据 | 汇总人次及分节数据 |
| 通话数据 | 总呼出次数、接通率、接通时长分布（≤1min/1-5min/5-10min/10-20min/>20min）、呼出覆盖率 |

> ⚠️ **仅标签系统创建的标签**可回收和查看运营数据；此前一线老师自行创建的个人自定义标签**无法回收数据**。建议用于统一运营的用户分层标签均通过标签系统发布。

## 六、常见问题

**Q：当前主管下发标签还需要老师手动打标？**
A：是的。未来会支持**系统按条件自动标记用户**，无需一线老师操作，敬请期待。

**Q：标签能否联动任务系统给不同分层用户自动发消息？**
A：Lesson 维度的标签联动任务系统已上线（[使用说明](https://shimo.zhenguanyu.com/docs/AroGpYym9G2LcOK4/)）；Episode 单节课标签在规划中，将在自动打标功能上线后跟进。

**Q：看板会有续报数据吗？**
A：规划中。当前建议新建"已续报"标签，由老师手动标记，通过每小时观测"已续报"标签的标记率（标签标记数 / 带班人数）进行估算。

**Q：标签太多管理混乱怎么办？**
A：建议不常用或无数据回收需求的临时性标签不要创建在标签系统中，并定期清理。标签**隐藏和分组功能**已在产品规划中，将陆续实现。
