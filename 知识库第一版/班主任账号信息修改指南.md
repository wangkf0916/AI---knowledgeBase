## 一、修改 Focus 班主任工作信息

以下信息均可在 **爱马仕系统** 中修改，需联系**主管或组长**操作：

> 入口：[爱马仕系统](https://hermes.zhenguanyu.com/#/organization-management?) → 点击成员姓名 → 班主任信息 → 点击编辑

可修改字段：

| 字段 | 说明 |
|---|---|
| 班主任姓名 | 工作台昵称，非员工真实姓名 |
| 短名 | — |
| 头像 | — |
| 微信及二维码 | ⚠️ 更换微信号时，需同步修改【哆啦】相关信息，参见 [哆啦相关问题文档](https://shimo.zhenguanyu.com/docs/A1wyzb991Y5bTmvy) |
| 个人介绍 | — |
| 教师资格证 | — |
| 阶段 / 科目 / 地区 | 后续将自动同步为部门属性信息（预计 8 月份上线）|

## 二、更换 Focus 工作台账号

目前**只有一种方法**可以更换班主任账号：

**操作路径：** 猿辅导手机客户端 → 右下角【我】→【设置】→【账号与安全】→【修改手机号】→【更换手机号】

> 要求客户端版本 ≥ **6.11.0**

**注意事项：**

1. 更改的手机号必须为**未注册过**猿辅导旗下所有产品的新手机号。
2. 猿辅导旗下所有产品（猿辅导、猿题库、小猿搜题、小猿口算、斑马英语、斑马思维）均使用**统一账号**，修改后所有产品同步变更，需使用新手机号登录。
3. 猿辅导账号**每月可修改 2 次**，不建议随意修改。

> 如不满足以上条件，建议用新手机号重新注册。

## 三、常见账号问题处理

### 3.1 班主任工作账号被注销

**背景：** Focus 工作账号的前提是存在一个猿辅导客户端的学生账号，若客户端账号被注销，Focus 班主任账号也将无法登录。

- 被注销账号多为账号本人联系客服注销；
- 若是**离职老师注销账号影响接班老师**正常使用，可**联系客户尝试恢复**。

---

### 3.2 班主任工作账号无资格

登录 Focus 账号后提示"资格被取消"，常见原因如下：

| 情形 | 处理方式 |
|---|---|
| **离职班主任** | 办理完成离职流程（OA 所有审批流程结束）后，系统自动取消 Focus 工作台资格。如仍有小班需要继续服务，请主管或组长根据文档完成**离职甩班**：[甩班文档](https://shimo.zhenguanyu.com/docs/kGEyX7NN0PVYiZxY) |
| **离职回流的班主任** | 企业微信联系【猿辅导技术支持】申请恢复资格，需提供：离职回流班主任姓名、工作台账号、新 LDAP、旧 LDAP |
| **其他情况** | 优先联系主管询问情况 |

---

### 3.3 爱马仕未展示工作账号 / 工作账号错误

**背景：** 1 个 LDAP 只能绑定 1 个工作账号。

**排查步骤：**

1. 让班主任登录 Focus 工作台 → 进入头像 → 个人信息页，检查绑定的 LDAP 是否正确。
2. 若**未绑定 LDAP**：登录 Focus 后会立即提示绑定流程，根据提示操作即可。
3. 若**绑定错误**：企业微信联系【猿辅导技术支持】，提供工作台账号，申请解绑错误绑定关系，然后老师本人刷新工作台，根据提示流程重新绑定正确的 LDAP。
