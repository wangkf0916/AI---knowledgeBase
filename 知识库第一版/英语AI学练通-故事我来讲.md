## 一、功能概览

**故事我来讲**是 L2 阶段用户在英语 AI 学练通中，每周 **Day 5** 的阅读课环节，承接绘本 DIY，以**思维导图**形式练习英语阅读和提炼关键情节的能力。

**主要流程：**

```
情节精炼 → 场景编排 → 故事再现 → 报告页
```

## 二、具体功能说明

### 2.1 情节精炼

**目标：** 从绘本内容中选出关键情节单词。

**流程：**
1. 系统首先朗读本页绘本内容；
2. 将绘本内容拆为**单词粒度**的可点选模块；
3. 用户根据题目要求选出对应单词，按要求数量点击确认提交；
4. 作答正确 → 展示**关键情节页**（有出现动效，自动播放该句子，播放完进入下一页）；
5. 作答错误 → 有错误标识。

**页面类型：**
- **自动朗读页**：自动播放绘本句子，播放完成后点「下一页」翻页；
- **作答页**：选词交互；
- **关键情节页**：展示选出的关键句。

### 2.2 场景编排

**目标：** 用思维导图整合关键情节，回顾故事结构。

**思维导图页：** 展示绘本的主题（预配置）和起因 / 经过 / 结果，用户通过拖拽匹配故事内容。

- 拖拽物：来自上一环节「情节精炼」找出的关键情节句；
- 思维导图分为两种类型：

| 类型 | 规则 |
|---|---|
| **流程图** | 需按顺序拖拽到正确位置 |
| **树状图** | 各拖拽物平级，只有主题需拖准确，其他细节不要求顺序 |

**交互规则：**
- 向上拖进对应空格；
- 拖拽正确 → 自动吸附；
- 拖拽错误 → 弹回原位。

### 2.3 故事再现

**目标：** 跟读 AI 生成的个性化单词练习文章，复习掌握不好的词汇。

> 使用**大模型能力**，根据每个用户掌握不好的词汇个性化生成练习文章（每人内容不同）。

**交互流程：**
1. 环节说明页（动效提示当前学习阶段，播放完自动跳转）；
2. 跟读页：依次跟读每句话，内容来自思维导图拖拽物；
3. 跟读结果展示（与其他跟读题结果展示形式相同）。

### 2.4 报告页

完成全部环节后展示学习报告：

| 展示内容 | 说明 |
|---|---|
| 左侧 | 评星（每页跟读的星级） |
| 右侧 | 跟读作品列表 |
| 播放页 | 点开跟读作品，依次播放每页跟读录音 |
