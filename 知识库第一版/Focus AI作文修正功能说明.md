## 一、功能入口

**路径：** Focus → 顶部导航 → 教学 → **AI 作文修正**

---

## 二、任务列表

> 页面顶部**红点**显示当前班主任**待修正的作文数量**。

进入后，任务列表**默认展示「进行中」及「已结束 7 天内」班课下所有用户已提交的作文**，按提交时间**正序**排列，显示提交用户、所属班课小班、修正状态。

支持按以下字段**检索**：

- 提交时间（含快捷选项：最近 7 天 / 最近 1 个月 / 昨天 / 今天）
- 班课、小班
- 学生
- 作文题目（⚠️ **必须先选择班课、小班**，才能选择作文题目）
- 修正状态（未修正 / 已修正）

点击列表中任一作文右侧的「**修正**」按钮，进入修正页面。

---

## 三、修正页面结构

| 区域 | 内容 |
|---|---|
| 顶部 | 显示当前作文对应的用户，支持点击「上一个 / 下一个」切换 |
| 左侧 | 用户的作文报告预览 |
| 右侧 | 辅导老师可操作的修正区域 |

## 四、修正操作详情

### 4.1 查看用户原图

- 点击原图可**放大**；有多张图片时可左右切换；
- 图片下方按钮支持**旋转图片**。

### 4.2 编辑用户原图（替换）

- 点击后支持**替换**用户的作文图片；
- 提交后系统会重新走一遍模型修正流程，输出新报告。

### 4.3 异常判定

**修正顺序：** 先点开**原图**查看学生手写作文，再结合 OCR 识别结果，判断作文是否异常。
> ℹ️ 极少数情况下，学生上传无关照片但已经过一轮手动修正，导致 OCR 结果呈现为正常文章。判断是否异常时，需**同时参考照片和 OCR 结果**。

**进入页面时若系统已预选了异常类型**，仍需人工再次确认是否确实异常，不可直接忽略。

**常规异常：**
选择对应的异常情况，确认「个性化范文」模块内容无误，直接提交修正即可。

**高危风险词：**
当作文中存在高危风险词时，系统默认选中"内容异常"，并标注命中风险词的具体段落。
- 辅导老师判断该词是否真的敏感：
  - **是**：在个性化润色中粘贴范文，提交修正；
  - **否**：选择"否"异常，继续正常批改。

### 4.4 编辑器操作

点击「**开始修正**」进入编辑器，左右两侧均可操作。

#### 左侧：原图操作

**圈画类型：**

| 类型 | 用途 |
|---|---|
| 错误圈画 | 圈画错别字、错误标点 |
| 拼音生字 | 圈画用户作文中写的拼音 |

**划线类型：**

| 颜色 | 用途 |
|---|---|
| 绿色线 | 好词好句 |
| 红色线 | 单句润色 |

**常用操作：**

| 操作 | 方法 |
|---|---|
| 删除错别字圈画 | 选中红色圆圈 → 点击右上角「❌」 |
| 修改错别字圈画 | 选中红色圆圈 → 再次点击右上角文字 → 出现文本框编辑 |
| 删除划线 | 选中任意线 → 点击右上角「❌」（同组线整组删除，右侧细项点评同步删除）|
| 添加错别字/错误标点 | 选中「错误圈画」工具 → 点击图片中任意字 → 在文本框输入正确内容 |
| 调整划线范围 | 选中线组 → 拖动左右两侧小圆点 |
| 调整划线位置/角度 | 选中线组 → 再次点击某条线 → 按住拖动；或拖动两侧小圆点调整角度 |

#### 右侧：文本框操作

| 内容项 | 说明 |
|---|---|
| 文体 | 展示该篇作文的文体（最上方） |
| 全文总评 | 对应报告最上方的总评描述，可修改 |
| 好词好句 | 细项点评，可修改文本；若要删除需在左侧删除对应划线 |
| 句子润色 | 细项点评，可修改文本；若要删除需在左侧删除对应划线 |

> ℹ️ **标签颜色与评语倾向规则：** 标签为**红色**时，评语应为**表扬**；标签为**绿色**时，评语应为**批评**。若两者不一致，需按评语倾向将标签转换为对应颜色。

**字句批改常见标点错误（需格外注意）：**
- **引号**：前后引号是否匹配、全角/半角格式是否正确、单双引号是否正确；
- **省略号**：是否完整、格式是否正确（注意不是英文格式的 6 个英文点）；
- 重要标点是否缺失或使用错误（如分号、顿号等）。

> ℹ️ 兜底页面字体不好辨认标点时，可将文本复制到 WPS 或企微对话框中辨别。

**个性化润色兜底方向：** 若润色后文章结构不完整（缺少开头或结尾），可从范文中复制截取添加开头或结尾，保证全文通顺即可。

### 4.5 保存与提交

**保存：** 点击编辑器「保存」，保存当前所有操作，跳转回批改预览页，左侧报告预览同步更新，状态变为「修正中」。

**提交修正：**

> ⚠️ **提交后学生端即可看到报告，请确认无误再提交。**
>
> ⚠️ 若提交后发现问题，再次修改并提交时，用户会**再次收到一次提醒**，建议一次批改到位。

带班表中展示用户写作练习的以下字段，均支持筛选：

- 状态
- 分值

## 六、特殊情况处理

| 情况 | 处理方式 |
|---|---|
| 连续拼音遮挡 | 点击拼音文本框进行拖动 |
| 用户上传横版作文 | 让用户重新拍照，辅导通过二次上传重新提交图片 |
| 同一段文字被划多种线或同时标记了错别字 | 选中最上方的线 / 错别字拖走，再选中下方内容调整 |
| 报告预览与编辑器中的原图序号不一致 | 正常现象，无需处理 |
| 编辑错别字或拼音生字时 | 注意不要让文本框遮挡序号 |

## 七、英语作文修正

> 来源：[石墨文档](https://shimo.zhenguanyu.com/docs/3al78EpYXyGzHmwm) · 整理日期：2026-04-25

### 7.0 配置前提

带班表需由主管配置「**写作练习**」列后，英语作文修正任务才会出现在列表中。

### 7.1 功能入口

**Focus → 顶部导航 → 教学 → AI 作文修正**（入口与语文作文相同）

### 7.2 任务列表

进入后展示待修正任务，支持按以下字段检索：提交时间 · 小班 · 学生 · **作文题目** · 修正状态

> ℹ️ 与语文版区别：搜索字段为「作文题目」而非「课程」。

### 7.3 修正页面结构

| 区域 | 内容 |
|---|---|
| 顶部 | 当前作文对应的用户，支持「上一个 / 下一个」切换 |
| 左侧 | 用户的作文报告预览 |
| 右侧 | 辅导老师可操作的修正区域 |

### 7.4 查看与替换原图

- 点击原图可**放大**，多张图片时可左右切换；图片下方按钮支持**旋转**；
- 点击可**替换**用户的作文图片，提交后重新走一遍模型修正流程，输出新报告。

### 7.5 异常判定

当作文属于异常情况时：
1. 选择对应的**异常情况**；
2. 仅需在「**个性化润色**」模块粘贴已准备好的范文；
3. 无需进行其他模块的修正操作，直接提交。

### 7.6 修正模块详情

英语作文修正共三个模块（均支持手动修改 + 重新生成，但**重新生成速度慢，非必要不建议使用**）：

| 模块 | 说明 |
|---|---|
| **全文总评** | 对应报告最上方的总评描述，可直接修改文本；不满意可点击「重新生成」 |
| **字句批改** | 三个错误维度：词汇错误 / 语法错误 / 格式错误；支持修改文本框内容，也支持直接**删除**某条错误点评；支持重新生成 |
| **个性化润色** | 需辅导老师粘贴约定好的**范文（含标题）**；支持重新生成 |

### 7.7 提交修正

> ⚠️ **提交修正后，学生端立即可见报告，请务必确认报告无误后再提交。**
