## 一、功能介绍

将某节课（**模板课**）的回放作为新课程的内容，以直播形式播放给学生，学生可体验答题得金币、讨论区发言等直播课专属功能。

> ⚠️ **特别注意**：模板课的课前 10 分钟内容同样会录入转成的直播课，老师录制模板课时**至少需要提前 10 分钟进入教室**，课前可播放视频、音乐或做一些假互动。

| 概念 | 说明 |
|---|---|
| 模板课 | 需要复制回放的课程 |
| 模板课 ID | 需要复制回放的课程 ID |

## 三、使用流程

### 3.1 确定模板课 ID

符合条件的课程在直播下课后会**自动生成模板课**，可在「课程详情页 - 状态」查看是否已生成。

**模板课生成条件（须同时满足）：**
- 仅使用**大班教室**的课程（大班小组教室 / 新答疑教室 / 新小班教室等无法生成）
- 2021.7.19 12:00 之后的课程
- 直播课上**未使用过**音视频上麦
- **未使用过**旧互动题
- **非** 使用 PDF 课件且发起过随堂测的课程

### 3.2 创建回放转直播课程

在「班课详情页」→「增加回放转直播课程」，填写课程信息，重点关注：

- **上课时间**
- **模板课 ID**
- **本节课有无激励**

> 注意：
> - 新创建的课程需要与模板课的课时切割**保持一致**；
> - 建议在上课前 **1 小时**就创建好。

### 3.3 上课

| 阶段 | 说明 |
|---|---|
| 课前 10 分钟 | 学生端展示倒计时蒙层，可在讨论区发言 |
| 开始上课后 | 同步播放模板课回放内容（课件、板书、老师音视频画面），学生可在讨论区发言 |
| 上课过程中 | 学生可参与答题（仅支持随堂测、少儿互动课互动题），也可获得金币（与激励配置相关） |
| 结束 | 模板课播放完毕后自动下课 |

> ⚠️ 回放转直播课到预定上课时间后**不会立即播放**，而是要等跨过「模板课打上课铃 → 老师点击开始上课」的时间间隔后才会播放正式内容。因此，选择模板课时尽量选**打上课铃到开始上课时间间隔短**的课程。

## 四、课堂功能支持列表

### ✅ 支持的功能

| 类别 | 功能 |
|---|---|
| 基础功能 | 课件、板书、老师视频、老师音频、双向视频 |
| 讨论区 | 发消息、仅看老师助教发言 |
| 课堂互动 | 多人语音、课堂动效、讨论区快捷互动卡（全员禁言中也可使用）、幸运彩蛋、弹幕、点名发言 |
| 教学活动 | 随堂测、进门测、出门测、少儿互动课互动题、跟读、主观题（学生端仅支持作答，不展示榜单）、拍照互动、小小演说家（灰度中）、分组对话（灰度中） |
| 激励 | 模板课有激励 → 支持直播答题得金币、签到、全勤、称号；若模板课为有激励系统班课程 → 还支持**回放答题得金币** |
| 跟课端 | 支持视频沟通 |
| 购课 | 支持展示购课链接 / 购课活动 |

### ❌ 不支持的功能

其余课堂互动和教学活动在模板课中未做限制，但在回放转直播课中**不会展示**。为避免穿帮，建议模板课**不加入暂不支持的互动和教学活动**。
