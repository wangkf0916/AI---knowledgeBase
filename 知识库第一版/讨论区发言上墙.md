## 一、需求背景

当前学生在课上的主要互动行为是**课堂测验、小组语音、讨论区发言**，学生受到主讲老师的个性化反馈和关注较少，情感体验不足。

**为什么从讨论区发言切入？**
1. **场景频次高**：讨论区发言是主讲老师高频使用的互动工具，也是学生参与互动的主要场景；
2. **流程自然流畅**：主讲老师提问 → 针对精彩发言课件区展示，整体连贯，且一节课可覆盖较多学生；
3. **激励效果强**：让积极回答的学生获得被关注感，同时激励更多学生跟上课堂节奏。

**预期使用频次**：一节课 2～5 次。

**典型使用场景：**
- 课前课间互动游戏
- 题目讲解过程（如"这道题运用了什么公式？"）

## 四、功能详述 · 主讲老师端

### 4.1 讨论区展示信息

- 在学生昵称后增加 `[本季上墙N]` 标签，示例：
  ```
  李乐意[可乐1班][本季上墙5]：老师，我知道这个题怎么做
  ```
- **统计口径**：当前学季、同年级、同科目系统班中该学生的上墙总次数（包含同学季上下系统班数据），实时变化；
- 只有数字大于 0 时才展示该标签。

### 4.2 挑选发言上墙

**发起时机**：课前、课中、课后任意时间均可发起。

**两种操作方式：**

| 方式 | 操作 | 说明 |
|---|---|---|
| 方式一：点击 | 点击某条发言 → 弹出功能组件（禁言 / 上墙）→ 点击「上墙」 | 再次点击已上墙发言，功能组件显示「取消上墙」；点击后从课件区清除 |
| 方式二：拖动 | 长按某条发言 → 拖动到课件区释放 | 以发言框中心点落入课件区为判断条件；未落入课件区则不触发 |

> 首次使用点击上墙且未用过拖动时，会弹出气泡提示「长按发言可拖动到课件区上墙」，3 秒无操作或点击任意处后消失。

### 4.3 课件区展示规则

1. **排列顺序**：从左到右、从上到下，某列放不下时自动下一列；某条被删除后同列下方内容自动上顶；
2. **展示信息**：学生头像（优先使用签到拍照头像）、学生昵称、发言内容；
3. **内容超出课件区**时，toast 提示「上墙内容已超出展示区域，建议清除后再添加」；
4. **上墙区域外**允许写笔迹；上墙内容区域上**不允许**写笔迹；
5. **点击某条上墙内容**进入选中态，右上角显示删除按钮；点击课件空白处或区域外，选中态消失；
6. **点击删除**后，该条内容从课件区清除，其余内容位置不自动调整（再次添加时按既有顺序继续排列）。

### 4.4 一键清除上墙

- 有上墙内容时，课件区右上角显示「清除上墙」按钮；
- 仅老师端显示，学生端和跟课端**不显示**此按钮；
- 点击后，课件区所有上墙内容一键清除。

### 4.5 与其他活动的互斥 / 兼容关系

**互斥活动**（双向限制）：

| 情况 | 提示 |
|---|---|
| 上墙进行中 → 点击以下活动按钮 | Toast：「请先清除发言上墙」 |
| 以下活动进行中 → 老师拖动发言至课件区 | Toast：「当前课堂活动期间不允许上墙」，拖动不生效 |

互斥活动包括：**课堂测验、主观题、跟读朗读、分组对话、思辨说 / 博雅会谈、拍照互动、结算全勤、倒计时、点名发言、听没听懂、课堂视频**。

**兼容活动**（可同时进行，互不影响）：

课堂动效、手势投票、快捷互动、快速投票、小组语音、音频上麦、视频上麦、课堂音效。

> - 上墙发言图层**低于**测验 / 跟课等控件蒙层，优先保证教学活动功能按钮；
> - 先上墙后查看榜单：榜单图层**始终在上墙图层上方**；
> - 翻页时：上墙内容**自动清除**；翻页预览缩略图中**不展示**上墙内容。

### 4.6 异常处理

| 场景 | 处理方式 |
|---|---|
| 断网重连 / 退教室重进 / 切设备 | 保留上墙内容 |
| 上墙操作时断网 | 课件区不显示，toast 提示「操作失败，请检查网络连接状态」 |
| 新建白纸 / 复制课件 / 复制板书课件 | 效果同翻页，自动清除上墙；切回原课件后不恢复 |
| 辅导老师已删除的发言 | 点击上墙无效，toast 提示「该发言已被辅导老师删除」；已上墙内容被删除后从上墙消失，同样提示 |
| 辅导老师发言 | 不允许上墙，拖动释放后自动收回，toast 提示「辅导老师发言不允许上墙」 |
| 拖动已上墙的发言 | Toast 提示「该发言已上墙」 |
| 拖动表情图片（666 等） | Toast 提示「图片内容暂不支持上墙」 |

## 五、功能详述 · 学生端

1. **课件区展示**与老师端保持一致；
2. **两处区别**：
   - 学生端**不展示**发言内容的选中状态；
   - 当学生**自己发言**被选中上墙时，使用**特殊 UI** 明确提示；
3. iPad 和桌面端与学生端逻辑一致，均在课件区展示；
4. 点击**截图**按钮时，截图中包含上墙内容；
5. 点击**标记**按钮时，标记列表缩略图是否包含上墙内容以技术成本为准，两者均可接受；
6. **图层优先级**：辅导老师视频沟通组件 > 其他弹窗 ≈ 上墙内容（与课件区同层级）。

---

## 六、功能详述 · 跟课端

- 辅导老师在此环节**不参与实际互动**，课件区状态与学生端保持一致；
- 无发言内容选中状态。

---

## 七、功能详述 · 其他端

| 端 | 处理方式 |
|---|---|
| 管理员端 | 正常展示课件区，与学生端逻辑保持一致 |
| 回放教室 / 伪直播教室 | 与直播时展示状态一致，正常展示上墙内容 |

## 八、9-3 版本更新：小组教室讨论区字数限制调整

1. 字数限制从 **15 字** 扩大至 **30 字**；
2. 字数超过 18 时（一屏展示不下），静止一段时间后自动播放**向下滚动动效**，滚到底部后停止；
3. 静止 2 秒后，发言消失；若当前消息展示中立即有新发言，**新消息替代旧消息**，旧消息不再展示；
4. 区域内**不需要**支持手动滑动。

## 九、数据埋点（Frog 打点 · 老师端）

1. 点击学生发言内容
2. 点击「上墙 / 取消上墙」按钮
3. 点击课件区「删除上墙」按钮
4. 点击「清除上墙」按钮
5. 拖拽发言内容成功上墙的事件
