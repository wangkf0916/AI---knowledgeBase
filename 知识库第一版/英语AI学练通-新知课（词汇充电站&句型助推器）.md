## 一、功能概览

词汇充电站与句型助推器是**新知课**中的两个核心学习环节，结构完全相同，目的不同：

| 环节 | 学习目标 |
|---|---|
| **词汇充电站** | 以词汇学习为目的 |
| **句型助推器** | 以句型学习为目的 |

**共同结构：**
1. **视频学习与跟读**：老师在趣味视频中教授词汇 / 句型，用户学习并跟读；
2. **互动题练习**：练习跟读、选择、拖拽等互动题目。

## 二、具体功能说明

### 2.1 视频播放

| 状态 | 进度条 | 进度调节 |
|---|---|---|
| **视频未播放完毕**（未完整播放过一次） | 展示进度条 | ✅ 支持调整 |
| **视频已播放完毕**（至少完整播放过一次） | 不展示进度条 | ❌ 不支持调整 |

- 支持点击播放 / 暂停控件；
- 点击空白位置不影响播放。

### 2.2 视频内插题

视频内可插入**跟读题**和**单选题**两种类型：

**跟读题规则：**
- 一次跟读达到 **3 星** → 直接自动过题；
- 一次跟读未到 3 星 → 强制**二次跟读**（二次结果无论几星均过题）；
- 作答交互：自动开启麦克风录音，无声后自动提交；
  - 环境嘈杂时可手动点击提交；
  - 一次作答错误 → 进入二次作答前先自动播放**示范音频**，播放完再开启录音。

**单选题规则：**
- 仅有**一次作答机会**，答对/答错均直接自动过题；
- 先点选选项，再点「提交」，提交后在原位反馈正误。

### 2.3 互动对话

模拟与老师对话的场景，营造「老师带着我做题」的感觉。支持配置三类消息：

| 消息类型 | 交互规则 |
|---|---|
| **老师语音** | 以语音消息形式展示，显示中文讲师头像；自动播放，支持手动点击重新播放 |
| **题目（单选题）** | 提交后在选项上展示正误；答错以老师消息形式发送正确选项 |
| **题目（跟读题）** | 交互同单选题逻辑；3 星为正确，否则无香蕉 |
| **题目（拖拽题）** | 点击或拖拽均可；点击时按从左至右顺序自动吸附；拖拽后顺序正确即算对 |
| **重点回顾卡片** | 自动播放英文 + 中文音频，支持点击重播；仅展示，无交互 |

### 2.4 互动题（独立环节）

独立于视频的练习题，题型同互动对话（单选、跟读、拖拽），规则相同。

## 三、激励说明

| 激励类型 | 触发条件 | 香蕉数量 |
|---|---|---|
| 视频跟读题 | 3 星 | **5 个** |
| 视频跟读题 | 2 星 | 3 个 |
| 视频跟读题 | 1 星 | 1 个 |
| 视频跟读题 | 0 星 | 0 个 |
| 互动题（非跟读）答对 | — | **3 个** |
| 互动对话跟读题 3 星 | 正确 | **3 个** |
| 互动对话跟读题 ＜3 星 | 错误 | 0 个 |
| 连胜激励 | 连续答对累计 | 以 "x5" 形式累计，获得老师表扬 |

## 四、Q&A

**Q1：播放未完成时中途离开是否保留进度？**
A：目前未完全播放、中途离开的情况，**均不保留进度**。

**Q2：跟读题权限问题？**
A：跟读题需要用户打开麦克风权限，首次进入时会提示。不打开权限则**无法完成题目**。

**Q3：互动对话跟读题与视频跟读题香蕉数量不一致？**
A：互动对话中只有 3 星算「正确」获得 3 个香蕉，与视频跟读按星级给（1-5个）逻辑不同，属于正常设计。
