## 一、功能概览

**情景小剧场**是新知课（Day 1-4）中的口语练习环节，通过**为角色配音**的目标，引导用户在趣味情景中完成英语跟读练习，达到开口说英语的目的。

**主要流程：**

```
角色选择 → 系统语料播放 → 角色语料配音 → 完成配音 → 播放配音（用户录音）
```

## 二、具体功能说明

### 2.1 角色选择

- 页面展示 **3 个角色**，从 8 个固定角色中选取；
- 选择任意角色后点击「Let's do it」，进入该角色的场景对话；
- 每个角色可配置多个场景对话，目前一般配置 **3-4 个**场景对话。

**完成规则：**
- 完成任意 **2 个**角色后，本环节算作**完成**，自动跳转下一环节；
- 可在之后重新进入完成第 3 个角色（第 3 个角色有**额外 10 香蕉**奖励）；
- 每完成一个角色，自动跳转回角色选择页，已完成的角色置灰，未完成的高亮引导选择。

### 2.2 场景对话

每个场景对话包含**一组两句对话**：
- **系统语料**：由系统自动播放；
- **角色语料**：需要用户进行配音（跟读）。

两句语料顺序**不固定**，以教研老师配置为准。

**配音交互规则：**

| 情况 | 处理方式 |
|---|---|
| 一次配音获得 3 星 | 直接切换下一场景对话 |
| 一次配音未获得 3 星 | 强制进行**二次配音** |
| 二次配音仍未获得 3 星 | 展示「跳过」按钮，用户可手动过题或继续练习 |
| 获得 3 星或手动过题后 | 以**角色消息形式**再播放一次用户的配音录音 |

- 配音规则类似跟读题：先自动播放示范音频，再自动开启录音；
- 可做多次（答错时可继续跟读作答）。

## 四、Q&A

**Q：情景小剧场的跟读题可以做多次吗？**
A：答错时可以继续跟读作答。

**Q：选择角色是自由选择吗？**
A：是的，可以选择任意角色，完成两个后自动进入下一环节，后续可回来完成第三个。
