## 一、需求背景

> **宝石商城入口**：App → 个人中心 → 宝石商城（C 端用户用宝石兑换礼品的商城，运营侧在 Eagle 后台配置商品）

宝石商城（Eagle 后台，即运营配置后台）拓展礼品品类，新增**头像框**，促进用户宝石消耗，进而激励用户循环参与活动。

## 二、Eagle 后台配置

> 适用角色：运营（Eagle 后台礼品配置）

### 2.1 新增物料类型

- 物料配置项中的【物料类型】字段新增「**头像框**」值。

### 2.2 头像框礼品配置项

| 配置项 | 说明 |
|---|---|
| 物料名称 | 文字填写 |
| 初始库存 / 剩余库存 | 数值填写 |
| 礼品入口图 | 支持 **lottie 格式动态图**（宝石商城、邀请有礼、周分活动页均需支持） |
| 头像框图片 | 支持 **lottie 格式动态图** |
| 头像框获得动效 | 必填，用于兑换成功展示 |
| 头像框佩戴动效 | 必填，用于佩戴成功展示 |

> ℹ️ 其他基础字段（上下架等）配置逻辑与现有礼品类型一致，无差别。

## 三、C 端用户兑换流程

### 3.1 兑换流程总览

头像框兑换流程整体复用**线上非实物无需发货礼品的已有流程**，以下仅说明有差异的部分：

**礼品入口图**
- 宝石商城页、邀请有礼活动页、周分活动页均需支持展示 lottie 动态图。

**头像框详情页**
- 头图：支持 lottie 动态图。
- 主副标题取 Eagle 后台配置值。

**确认兑换弹窗**

| 元素 | 内容 |
|---|---|
| title | 「确认兑换？」 |
| 固定文案 | 头像挂件，一经兑换，不予退换<br>兑换后可在【我的礼品】查看佩戴 |
| 【取消】 | 弹窗消失 |
| 【确认】 | 扣除宝石 → 发放头像框到用户账户 → 弹窗隐藏 → 展示「头像框展示弹窗」 |

**头像框展示弹窗**
- 展示头像框动效 + 佩戴到默认头像后的效果，动效循环播放。
- 【**立即佩戴**】：将当前头像框佩戴到用户当前头像，展示佩戴动效 + 佩戴后效果。
- 佩戴失败时 toast 提示：「佩戴失败，请重试」。

### 3.2 其他使用场景兼容

| 场景 | 处理方式 |
|---|---|
| 阶梯礼品（邀请有礼等） | 用户达到阶梯条件时，系统**自动发放**头像框 |
| 后台补发 | 支持运营通过 Eagle 后台手动补发头像框 |
| 周分 / 邀请活动页 | 礼品展示需兼容动态头像框图 |
| 盲盒配置头像框 | 抽中时**仅展示盲盒动效**，不展示头像框本身动效；抽中弹窗右侧按钮文案变为【去佩戴】，点击跳转至「我的礼品」页（不立即佩戴） |

## 四、我的礼品页展示

**卡片列表展示：**
- 显示后台配置的头像框图片 + 主标题。
- 显示来源活动（同线上其他礼品）及状态「已发放」。
- **头像框不支持取消兑换**。

**卡片详情页：**
- 显示图片、主标题、订单创建时间、兑换信息（宝石兑换的显示「消耗宝石」字段）。
- 头像框动效循环播放。
- 【**立即佩戴**】：点击后展示佩戴动效弹窗（复用兑换流程的弹窗）。
  - 本期**不支持取消佩戴**。
  - 头像框**不可叠加佩戴**：若当前头像已佩戴其他头像框，自动取消原头像框后佩戴新头像框。

## 五、动态头像框展示兼容

### 5.1 需要兼容的页面

| 端 | 页面 |
|---|---|
| 手机端 | 个人中心页、个人中心二级页 |
| Pad 端 | 个人中心页、个人中心二级页 |
| 桌面端（PC） | 头像展示入口、头像弹窗 |

> ℹ️ 编辑资料页**本期不需要支持**动态头像框展示。

### 5.2 头像框加载时机

| 端 | 刷新时机 |
|---|---|
| 手机端 | 启动 App 后 / 从宝石商城返回后 |
| Pad 端 | 启动时 |
| 桌面端 | 启动时 / 点击头像菜单时 |

### 5.3 加载失败降级策略

- 头像框加载失败时，展示**无头像框的头像样式**。
- 刷新时新头像框加载失败，展示**上一个状态的头像**（上一个头像框 / 无头像框）。
- 动态头像框动画需**连续循环播放**。

## 六、版本要求

> ⚠️ 佩戴功能需要 App 为以下最低版本，版本未达到时用户兑换后将无法佩戴。请在版本全量后再上架头像框，避免兑换后佩戴失败。

| App | 最低支持版本 | 全量时间 |
|---|---|---|
| 猿辅导（辅导） | 8.29.1 | 2026-04-27 |
| 猿辅导素养课 | 3.29.1 | 2026-04-27 |
| 小猿优课 | 1.89.1 | 2026-04-27 |

| 页面 | 事件 |
|---|---|
