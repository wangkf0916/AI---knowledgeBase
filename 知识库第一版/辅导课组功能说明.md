# 辅导课组功能说明（辅导老师 iPad 端）

>
> 整理日期：2026-04-24 · 文档记录时状态：全量

>
> 适用角色：辅导老师

---

## 一、功能背景

为提升系统班核心课前后辅导老师课堂的**学生关注能力与互动能力**，在辅导老师 iPad 端新增以下功能，帮助达到更好的互动效果。

---

## 二、适用范围

**仅针对辅导老师的辅导课组开放**，目前包含：

- 课前回顾课
- 表达力课堂
- 巩固复习小课堂

> ⚠️ 辅导老师的其他课堂及主讲老师所有课堂**不在范围内**。

---

## 三、新增功能清单

1. 课堂当前学生在线状态
2. 讨论区签到消息提醒
3. 学生列表
4. 上麦最多支持 3 人同时上麦
5. 支持讨论区 / 学生列表 / 随堂测作答统计点人上麦

---

## 四、功能详解

### 4.1 课堂当前学生在线状态

老师 iPad 导航栏直观显示本节课各状态人数：

| 状态 | 说明 |
|---|---|
| 应到人数 | 所有购买本节课的用户 |
| 在线人数 | 当前在教室的人数 |
| 后台人数 | 本节课曾进过教室，但当前在后台运行的人数 |
| 到课离线人数 | 本节课曾进过教室，但当前已经离线的人数 |
| 缺勤人数 | 本节课始终未进教室的人数 |

### 4.2 讨论区签到消息提醒

- **时机**：课前 10 分钟学生签到后，讨论区消息提示签到成功；
- **内容**：`X 班的 "学生昵称" 进入教室签到`；
- 老师可即时向进入教室的学生打招呼。

### 4.3 学生列表

**入口**：讨论区右上角，点击后展示本班所有学生的列表。

**列表内容：**
- 班级、昵称（括号内显示后台设置的真实姓名，未设置则显示「未设置」）；
- 本节课、本季课学生的上麦次数（仅统计辅导课组，不含主讲老师课程）；
- 学生的报名状态及在线状态。

**排序规则：**
- 默认按学生进小班的顺序排序；
- 可切换为「本季度上麦次数由低到高」排序。

**筛选维度：**

| 维度 | 可选项 |
|---|---|
| 班级 | 全部 / 1班 / 2班 / 3班…（根据老师带班数量） |
| 报名状态 | 全部 / 续报 / 联报 / 跨报 / 未报名 |
| 到课状态 | 全部 / 在线 / 后台 / 离线 / 缺勤 |

### 4.4 上麦最多支持 3 人同时上麦

- 发起音视频上麦后，辅导课组默认开启**多人上麦模式**，最多支持 **3 人**；
- 达到 3 人后不能继续给麦，需先对已上麦学生下麦再继续；
- ⚠️ 若老师想使用单人上麦，每次给麦前须先将当前上麦学生下麦，否则会出现短暂"两人在麦上"的现象。

### 4.5 点人上麦（三种入口）

> ⚠️ 点人上麦**不需要学生要麦、不需要学生同意**，老师看不到麦序列表，最多也支持三人。

**讨论区点人上麦：**
- 入口：点击学生发言，出现上麦入口，选择上麦类型；
- 点击后该学生直接上麦。

**学生列表点人上麦：**
- 入口：在学生列表中点击某个学生，出现上麦入口；
- 现象同讨论区点人上麦。

**随堂测作答统计点人上麦：**
- 入口：随堂测结束后，出现作答统计入口；
- 展示答错 / 答对 / 未作答学生名单，老师可点击某学生让其上麦。

## 六、补充说明

### 点人上麦 vs 工具栏上麦

- 使用讨论区 / 学生列表 / 测验小结页**点人上麦**时，学生端只展示上麦信息，**没有举手相关操作**；
- 若想让学生主动要麦，需从老师 iPad **工具栏**发起音视频上麦。

### 音频上麦 vs 视频上麦

| 对比 | 说明 |
|---|---|
| 相同 | 支持工具栏上麦 & 点人上麦；支持同时三人上麦 |
| 不同 | 音频上麦只展示学生头像；视频上麦展示学生视频画面 |
