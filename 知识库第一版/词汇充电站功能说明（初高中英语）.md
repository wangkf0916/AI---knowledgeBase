## 一、功能概述

为初高中英语增加课后词汇练习功能，根据老师设置的知识点和学生历史做题记录，**智能推送**适合学生的题目。

**功能范围：**

| 维度 | 范围 |
|---|---|
| 学段 | 初中、高中 |
| 学科 | 英语 |
| 年级 | 7～12 年级 |
| 班课类型 | 系统班、特训班、短期班 |
| 支持端 | 小猿优课 移动端、Pad 端、桌面端 |

## 二、学生端

### 2.1 入口

核心课卡片下，点击「词汇充电站」入口进入练习环节。

### 2.2 练习逻辑

**题目类型：**

| 类型 | 说明 |
|---|---|
| 基础巩固 | 老师设置的基础题目 |
| 难题进阶 | 做对基础题后推送 |
| 错题重练 | 针对做错的单词再次练习 |
| 单词回顾 | 复习已练习过的单词 |

**推题规则：**
- 同一课次首次练习：推送老师设置的题目；
- 后续练习：优先推错过的单词；无错题则推进阶题目；
- 中途退出会记录进度，但**不保留连胜数值**。

**支持题型：** 选择、拼写、跟读

### 2.3 金币奖励

在后台设置时限内完成环节后发放金币：

| 班课类型 | 第 1 次 | 第 2 次 | 第 3 次 |
|---|---|---|---|
| **长学季**（系统班） | 5 金币 | 5 金币 | 10 金币 |
| **短学季** | 10 金币 | 5 金币 | — |
| **特训班、短期班** | 15 金币 | — | — |

### 2.4 报告页

完成所有题目后进入报告页，展示学习内容和掌握情况。
- 逾期前可**无限次重复练习**；
- 报告页支持「再练一次」入口。

## 三、Cyber 平台配置

### 3.1 资源树知识点创建（Step 1）

**入口：** Cyber → 资源树

在上一级知识点右侧点击按钮，选择「新建子级知识点」或「在上/下方添加知识点」，在弹窗中：
- 选择「可绑题」；
- 输入知识点名称（一般为词汇或短语文本）。

### 3.2 添加词汇信息（Step 2）

点击「+ 添加资源」→「添加词汇信息」，填写以下字段：

| 字段 | 是否必填 | 说明 |
|---|---|---|
| **词汇文本** | 必填 | 默认等于知识点名称，可二次编辑；仅支持英文/数字/半角标点；上限 40 字符 |
| **释义** | 必填 | 默认带入词典中文释义，可二次编辑；上限 45 字符；最多添加 5 个释义 |
| **词性** | 必填 | 默认等于知识点名称，可二次编辑；短语可填「无」（填「无」则学生端不展示词性） |
| **音频** | 必填 | 上传 mp3，或点击「使用 TTS 合成音频」生成；TTS 音频可返回平台修改音色/内容 |
| **配图** | 选填 | 支持 png/jpg，比例 3:2，大小 ≤ 1M |
| **音标** | 选填 | 点击「查询」展示每个单词的所有音标，可逐词选择；词汇文本修改后音标自动清空 |

保存后可点击「编辑」二次修改词汇信息。

### 3.3 自动生成题目（Step 3）

点击「系统生成题目」，系统根据词汇信息自动生成题目，放入「#基础巩固」维度。

> ⚠️ **只支持在手动创建题目之前**自动生成；若已手动创建题目，需清空所有题目后才能自动生成。

**自动生成的题型：**

**① 朗读题：** 每个释义生成一道朗读题
- 内容：跟读文本（=词汇文本）+ 配图 + 音频 + 音标 + 释义（词性+释义）
- 基础难度：2

**② 文本单选题（中英双向各一套）：**
- 题干英文→选项中文：若有多个释义，每个释义分别生成一道题
- 题干中文→选项英文：同上
- 干扰项：选 3 个同级知识点下同词性词汇（不足 3 个则取同级任意词汇）
- 基础难度：2

### 3.4 手动添加题目（Step 4）

每个知识点题目分「#基础巩固」和「#难题进阶」两个维度，点击对应维度右侧「+ 创建题目」。

**支持题型及关键配置：**

| 题型 | 核心配置要点 |
|---|---|
| **朗读题** | 音频文本（上限 40 字符）+ 音频（必填）+ 音标（选填）+ 配图（选填，3:2）+ 释义（必填，上限 45 字符） |
| **文字单选** | 题干文本（词汇/短语≤40字，句子≤160字）+ 音频（词汇/短语时选填）+ 4 个选项（上限 30 字符） |
| **图片单选** | 文本（词汇/短语≤40字，句子≤160字）+ 4 个图片选项（3:2，≤1M）+ 音频（词汇时选填） |
| **拼写题** | 文本及填空（≤30字符，支持插入 1-5 个空）+ 正确选项 + 最多 4 个干扰项（选项字符≤4） |
| **短语填空** | 文本及填空（≤40字符，支持插入 1-5 个空）+ 释义（必填，≤45字符）+ 最多 4 个干扰项（选项字符≤20） |

> 词汇/短语文本支持高亮橙色（色值 #FF7400）；句子文本需以标点符号结尾。

### 3.5 课后环节选题配置

**有班型的课程 → 在 Cyber 班课设计配置（Amaze/主讲工作台仅可查看，不可编辑）：**

Cyber → 班课产品 → 班课产品详情页 → 课程设计详情页 → 「词汇充电站」环节 → 点击「选题」

选题完成后，在【词汇总览】和【题目总览】查看：
- **词汇总览**：所选题目绑定的知识点（仅展示，不可编辑）；
- **题目总览**：分「基础巩固」和「难题进阶」两个维度，支持按维度清空。

**无班型的课程 → 在 Amaze / 主讲工作台配置**（逻辑同 Cyber 班课设计）。

## 四、Focus 平台

### 4.1 管理者看板

**系统班服务看板 → 课后环节参与人次 → 词汇充电站**

计算逻辑：

| 指标 | 说明 |
|---|---|
| 1 次闯关 | 只完成一次 |
| 2 次闯关 | 只完成两次 |
| 3 次及以上 | 完成三次及以上 |
| 累计闯关 | 完成一次即算 |

**带班表配置（主管配置）：**
- 单次课回访：管理 → 带班表配置 → 单次课回访，将【词汇充电站】加入；
- 累计课程回访：管理 → 带班表配置 → 累计课程回访，将【累计词汇充电站】加入。

> ℹ️ 寒假若老师使用默认带班表，无需配置；已改过带班表的需手动添加。

### 4.2 单次课回访（一线老师）

> 需主管配置带班表后生效。

| 用户状态 | 展示内容 |
|---|---|
| 未点击开始作答 | 展示「-」 |
| 作答后 | 展示最新一次练习结果：练习次数 / 正确率 / 排名 / 掌握单词数（本节课） |

- 点击正确率可查看本节课最后一次练习的报告；
- 支持回访标记（高级群发报告算回访）；
- 支持字段筛选。

### 4.3 学生个人详情页

展示某节课的练习次数、正确率、排名、掌握单词数（同单次课回访）。

### 4.4 累计词汇充电站

| 指标 | 说明 |
|---|---|
| 完成课次 | 用户完成闯关的课程数量 |
| 练习次数 | 当前班课各节课练习次数加和 |
| 正确率 | 每节课最新词汇充电站正确率加权平均（分子分母分别相加） |
| 掌握单词数 | 每节课掌握单词数加和 |

点击可查看用户在该班课下所有词汇充电站完成情况，支持按完成状态筛选。

### 4.5 榜单

**工具 → 榜单：**
- **单节课榜单**：课程有词汇充电站即有此选项，完成一次练习即算；
- **累计班课榜单**：班课有词汇充电站即有此选项，取用户完成练习的课程节数。
