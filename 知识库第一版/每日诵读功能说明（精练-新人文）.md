## 一、功能简介

校内试卷基础部分必有**古诗文背诵默写**，而这部分的背诵检查在家庭作业中高度依赖父母监督，是家长日常痛点之一。

本功能通过**「超前背」+ AI 检测**的方式，帮助学生提前背诵熟悉，同时帮助家长检测背诵效果，夯实校内基础。

落地于**精练 tab**，主要环节：朗读、背诵、习题练习。

## 三、学生端功能说明

### 3.1 背诵列表页

- 支持 **1-6 年级全部内容**；
- 每篇文章按年级展示，用户选择文章后进入具体背诵环节。

### 3.2 文章背诵环节

每篇文章最多配置 **朗读、背诵、练习** 三个环节，教研老师在后台可自定义保留组合：
- 全部三个环节：朗读 → 背诵 → 练习
- 精简组合：朗读 → 练习（去掉背诵）

#### 环节一：朗读

| 步骤 | 说明 |
|---|---|
| 进入页面 | 默认播放原声 |
| 朗读中 | 支持**实时检测**朗读效果 |
| 朗读结束 | 展示朗读结果 |

#### 环节二：背诵

| 步骤 | 说明 |
|---|---|
| 背诵中 | 支持**实时反馈**背诵结果 |
| 提示功能 | 点击「提示」展示对应提示词，支持边背边看提示 |
| 背诵结束 | 展示背诵结果 |

#### 环节三：练习

- 每篇文章下题量：最少 **1 道**，最多 **10 道**；
- 目前仅支持**单选 / 多选**题型。

### 3.3 完成报告

展示所有环节的完成情况及具体细节。

### 3.4 练习记录

- 按时间维度记录所有文章的练习情况；
- 同一文章**重复练习**则展示多个卡片；
- 点击卡片进入对应的报告页。

### 4.1 资源树（文段公共内容）

文言文、课文等文段是**可复用资源**，公共内容统一存储在资源树，未来可在其他场景复用，避免重复生产。

**文段公共内容包括：** 标题、正文、背景图等。

**创建知识树规则：** 必须严格按照 **年级 → 学期 → 课文** 三层结构创建，不能缺少或增加层级。

**文段配置项：**

| 配置项 | 要求 |
|---|---|
| 缩略图 | 比例 1:1，大小 1M 以内，PNG 或 JPG |
| 标题 | 如「静夜思」，可设置拼音 |
| 副标题 | 如「[唐]李白」，可设置拼音 |
| 正文 | 如「窗前...思故乡。」，可设置拼音 |
| 内容播报音频 | 必须包含标题+副标题+正文，大小 **5M 以内**，格式仅支持 **MP3** |
| 背景图（选填） | 比例 3:2，格式 JPG / PNG，大小 1M 以内 |
| 知识点 | 可关联多个 |
| 背诵要求 | 根据文段类型选择「校内必背」或「素养拓展」（不同类型内容生产有差异，不能随意选） |

> ⚠️ 音频文件超过 5M 会导致 App 加载慢，请严格控制大小。

### 4.2 诵读环节配置

**校内必背** 需配置朗读、背诵、练习 3 个环节：

**背诵环节 - 提示词标记：**
1. 光标选中要添加的提示文本；
2. 点击输入框上方「提示」下拉列表，选择该文本是第几个提示；
3. 提示文本可以跨行；
4. 至多添加 **8 组提示**，每组字数不限。

> ⚠️ 文本框内容需与背诵环节文本保持一致，**不能修改正文**。若资源树上文段内容发生变更，系统会清空全部提示标记，并触发预警邮件（需教务老师在「新版预警邮件后台」设置接收人）。

**练习环节配置：**

| 配置项 | 说明 |
|---|---|
| 题量 | 1-10 道 |
| 题型 | 仅支持单选、多选、不定项；**多问大题不可选** |
| 题目内容 | 支持田字格、下划线、斜体、拼音、文字下加点、下划波浪线等特殊格式；**带图片的题目会被系统拦截** |

**素养拓展** 类文段：除不用配置背诵环节的提示标记外，其余逻辑与校内必背一致。

### 4.3 发布流程

- 每生产完成一个文段，App 即发布一个文段；
- 生产一批内容后，确认可面向学生开放，**企业微信联系杨凌宇**开放入口。
