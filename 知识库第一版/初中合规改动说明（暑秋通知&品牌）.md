## 一、背景

为满足合规要求，初中暑秋上课在体验侧维护的**通知机制**需进行调整，同时**小猿优课**相关报告中的品牌名称需统一修正。

---

## 二、生效范围

| 维度 | 范围 |
|---|---|
| App | 猿辅导 App、小猿优课 App |
| 学季 | **24 暑期及后续学季** |
| 阶段 | 初中 |
| 班课类型 | 全部 |
| 科目 | 全部 |
| 年级 | 7-9 年级 |
| 特殊说明 | 额外包含**小学六年级数学沪教版** |

---

## 三、改动内容

### 3.1 通知全部关闭

**【猿辅导 App】【小猿优课 App】**

与课程体验相关的**通知全部关闭**，包括：
- 短信
- Push
- IM 消息
- 催到课外呼

**【猿辅导公众号】**

所有通知全部关闭（包括上课通知、报告推送等）。

---

### 3.2 小猿优课公众号：保留报告推送

为保障小猿优课直播课用户的基础行课体验，**小猿优课公众号**的报告推送予以保留（上课提醒类不保留）。

**保留推送的报告类型：**

| 报告类型 | 对应功能 |
|---|---|
| 课程报告 | — |
| 课课练报告（笔记） | [课后笔记功能说明.md](./课后笔记功能说明.md) |
| 习题报告（随堂探究） | [课后习题功能说明.md](./课后习题功能说明.md) |
| 订正报告 | [课后习题功能说明.md](./课后习题功能说明.md) |
| 拓展练习报告 | — |
| 单词听写报告 | [英语课后练习（单词听写&个性化纠音）.md](./英语课后练习（单词听写&个性化纠音）.md) |
| 结课报告 | — |
| 阶段复习/测试报告 | [阶段复习功能说明.md](./阶段复习功能说明.md) |
| 考试报告 | [单元模考功能说明.md](./单元模考功能说明.md) |

### 3.3 品牌名称修正（永久生效，不区分学季）

> ⚠️ 以下改动**永久生效**，不区分学季，且**不影响猿辅导 App 和猿辅导公众号**（仍展示「猿辅导」）。

**【小猿优课 App】和【小猿优课公众号】**中凡显示「猿辅导」的地方，统一改为「**小猿优课**」。

**问题一：小猿优课公众号内报告链接标题显示「猿辅导」**

需修改为「小猿优课」，涉及报告：
- 课程报告
- 课课练报告（笔记）
- 习题报告（随堂探究）及点击「查看答题情况」后跳转的二级页面
- 订正报告及点击「查看答题情况」后跳转的二级页面
- 拓展练习报告
- 单词听写报告
- 结课报告
- 阶段复习/测试报告
- 考试报告

**问题二：小猿优课公众号内报告内容标题显示「猿辅导」**

需修改为「小猿优课」，涉及报告：
- 课程报告

**问题三：小猿优课 App 内分享/微信群打卡，端外落地页图片 Logo 显示「猿辅导」**

需修改为「小猿优课」，涉及报告：
- 课课练报告（笔记）
- 习题报告（随堂探究）
- 订正报告

**问题四：小猿优课 App / 公众号内提示文案显示「猿辅导」**

「请在猿辅导 App 内订正错题」→「请在**小猿优课** App 内订正错题」，涉及报告：
- 习题报告（随堂探究）
