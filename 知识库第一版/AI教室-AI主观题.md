## 一、功能简介

直播课堂中的主观题支持对学生作答进行**实时 AI 批改**，并给出个性化反馈；批改后的等级将计入**称号升级**。

---

## 二、功能范围

| 维度 | 范围 |
|---|---|
| 阶段 | 小学 |
| 年级 | 2～6 年级 |
| 学科 | 新人文、语文优++、语文 |
| 教室类型 | **AI 教室**（⚠️ 不支持伪直播） |

---

## 三、整体流程

| 阶段 | 操作方 | 内容 |
|---|---|---|
| 课前 | 老师 / 教研 | 在 Cyber 建题并配置，在 Muse 课件绑定主观题（灰测期间需提前两周将题目给到研发调试） |
| 课中 | 老师端 | 发起主观题，查看提交率和点评完成率，结束后展示榜单 |
| 课中 | 学生端 | 作答 → AI 批改 → 获取星级 / 金币 / 个性化评语 |
| 课后 | 老师 / 辅导 | 在课程报告、带班表中查看主观题作答详情 |

## 四、如何建题（Cyber 平台）

**入口**：
```
https://cyber.zhenguanyu.com/#/other-tools/subjective-question/list?phase=xiaoxue&subjectId=1&businessLine=cyber
```
导航栏阶段学科选「小学语文 / 新人文 / 读写优++」→ 「其他」→「AI 主观题调试工作台」

> 注：语文、新人文、读写优++ 的题目创建后统一存放，**不按科目区分**。

### Step 1：新建题目

| 字段 | 说明 |
|---|---|
| 阶段 | 默认小学 |
| 学科 | 默认与 Cyber 导航栏科目对应 |
| 年级 | 必填，可选一年级上 / 下 ～ 六年级上 / 下 |

### Step 2：编辑题目配置

**作答方式**：默认文本（学生端为文本输入）

**考查内容**（下拉选择）：
文言文翻译、人物形象分析、概括文章内容、情感主旨分析、理解句子含义、启示劝说、诗歌画面、手法赏析、提取关键信息、理解词语含义、表达观点、语言风格赏析、作用分析、想象预测、概括段落大意（题型后期可能继续增加）

> ⚠️ 以下字段均**不支持**英文输入法下的字符：`, . / < > ? ; ' : " [ ] { } \ | \` ~ ! @ # $ % ^ & * ( ) - = _ +`

| 字段 | 字符上限 | 说明 |
|---|---|---|
| 题目材料 | 3000 字符（1 汉字 = 2 字符） | 仅作判题依据，学生端不展示；提供给 ChatGPT 判题的完整题目信息（文章段落、古诗词原文、图片描述等） |
| 题干 | 200 字符 | 题目要求 |
| 参考答案 | 400 字符 | 题目标准答案 |

**批改方式**（三选一）：

| 方式 | 说明 |
|---|---|
| 按得分点批改 | 根据学生答案命中得分点的情况进行反馈 |
| 按作答要求批改 | 根据是否满足作答要求反馈，适合开放性题目 |
| 按得分点 & 作答要求批改 | 同时判断得分点命中情况和作答要求满足情况 |

**得分点配置字段：**
- 得分点类型（≤100 字符）
- 得分点描述（≤100 字符）
- 是否核心得分点：若「是」，该得分点会出现在评语中
- 是否需要精确匹配：若「是」，学生回答须与得分点完全一致才得分
- 最多添加 **5 个**得分点

**作答要求配置字段：**
- 每条作答要求（≤400 字符），例如「表达对居里夫人的感激之情」「使用第二人称"您"」
- 最多添加 **5 条**作答要求

### Step 3：保存题目

配置完成后点击「保存」，页面跳转至 Cyber 题目详情页。详情页包含三个 Tab：
- **题目配置**：可二次编辑题目配置
- **基本信息**：可修改年级
- **作答数据**：展示该题目在所有课程中的数据；多版本题目数据分开展示

### Step 4：题目调试

**Bot 调试**：填写「好 / 中 / 差」三种作答情况的答案数量（默认 5 / 10 / 15，范围 0～150）和期望回答后，点击「生成评估结果」；约 5 分钟内通过**企微**收到评估结果，同时在题目调试 Tab 展示。

**人工调试**：手动输入学生回答（最多 200 个，每条 ≤400 字符），支持下载 Excel 模板批量添加；同样约 5 分钟内通过**企微**收到评估结果。

### Step 5：Muse 绑定 AI 主观题

课件页面右上角点击「+ AI 主观题」→ 输入题目 ID（可点击「前往 Cyber」查询）→ 保存。

### Step 6：Muse 查看 / 编辑 / 删除题目

| 操作 | 说明 |
|---|---|
| 查看 | 点击课件右上角「AI 主观题」按钮 |
| 编辑 | 跳转至 Cyber 题目详情页修改，修改后 Muse 内自动同步 |
| 删除 | 从当前课件页删除绑定关系 |

> 注：同一题目 ID 绑定到多个课件页时，题目修改后**所有使用该题目的课件页均自动同步更新**。

## 五、如何发起（老师端）

**发起**：在对应课件右下角点击「开始作答」。

**进行中可查看：**
- **提交率**：分母 = 在线学生人数，分子 = 已点击提交的学生数
- **点评完成率**：分母 = 已提交人数，分子 = 已听完语音反馈的学生数

**结束流程：**
1. 点击「收起主观题」：收起榜单，恢复课件显示；
2. 点击「结束作答并展示榜单」：展示精彩作答榜，学生端同步展示猿小助气泡反馈；
3. 点击「关闭榜单」：主观题环节结束。

**猿小助气泡反馈文案（老师点击结束作答时触发）：**

| 学生状态 | 气泡文案 |
|---|---|
| 上榜 | 恭喜你上榜啦！ |
| 提交但未上榜 | 要继续加油呀～ |
| 已提交但未听完反馈 | 评语可在课后报告中查看喔～ |
| 未提交 | 这次没有提交，下次要及时作答喔～ |

## 六、学生端详情

### 6.1 作答流程

| 阶段 | 说明 |
|---|---|
| 作答前 | 老师点击「开始作答」后出现答题卡；上方为题干，中间为答题区（最多输入 150 字）；答题卡支持收起 / 展开 |
| 作答中 | 在答题区输入答案后点击提交 |
| 提交后 - 批改中 | 后台调用 AI 批改，等待约 **1～7 秒**（大部分为 3～4 秒） |

### 6.2 批改结果展示

**星级与金币：**

| 星级 | 金币 | 称号计入 |
|---|---|---|
| ⭐⭐⭐ 三星 | 10 金币 | ✅ 计入称号升级 |
| ⭐⭐ 二星 | 8 金币 | ✅ 计入称号升级 |
| ⭐ 一星 | 5 金币 | ❌ |
| 0 星 | 0 金币 | ❌ |

> 当作答为乱码、无实义答案或空白时，等级为 **0 星**。

**过渡语**：猿小助语音 + 文字气泡：「批改完成啦！我们一起来听听你的评语吧～」，语音结束后播放答题卡开门动效，展示作答详情与批改评语。

**评语反馈**：猿小助语音点评，提到「得分点」时对应词语**高亮显示**；反馈完成后停留在此页直到主讲老师点击结束，语音不可重复播放，文字评语可上下滑动查看。

### 6.3 榜单展示

老师点击「结束作答并展示榜单」时，学生端统一展示作答榜单 + 猿小助气泡反馈（同第五章文案），直至老师点击「关闭榜单」后环节结束。

老师需下载最新跟课端后，给用户发送的图片才会呈现主观题作答情况。

### 8.2 直播课后 · 回访图片

图片形式：
- 主观题 + 客观题组合
- 纯主观题

### 8.3 带班表

**学生作答详情：**
- 测验情况将个性化主观题单独拆出，并标记星级和是否精彩作答；
- 点击主观题题号，可查看用户作答和 AI 个性化反馈文本；
- 正确性计算：**三星、二星 = 正确；一星、0 星、未作答 = 错误**。

**单次课回访 · 测验列：**
支持老师选择本节课重点运营的主观题，结合用户作答情况进行回访。
