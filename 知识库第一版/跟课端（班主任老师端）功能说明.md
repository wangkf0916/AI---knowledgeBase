## 二、功能概览

跟课端支持班主任老师在上课过程中完成以下任务：

| 功能 | 说明 |
|---|---|
| 查看未到课学生 | 一键查看本节课尚未进入教室的学生 |
| 查看全部学生 | 切换不同排列方式查看所有学生状态 |
| 观察并督促走神学生 | 自动识别走神学生，支持视频沟通 / 私信 / 艾特 |
| 表扬 / 寻找特征学生 | 按排序方式快速找到表现好 / 差的学生 |
| 课件区放大 | 点击按钮放大课件区（功能待进一步优化） |
| 讨论区发言 | 在老师视频下方区域输入发送 |

## 三、功能详述 · 小组教室 & 双向视频教室

### 3.1 查看未到课学生

> **未到课**：指**一直未进入教室**的学生（与到课后离线不同）。

> 隐形操作：双击「联系方式」列的号码，可实现号码全选（方便快捷联系）

### 3.2 查看全部学生（小班 Tab）

可切换选择不同排列方式查看学生（蓝色框位置切换）。

**小班 Tab 人数说明（x/y）：**

| 数值 | 含义 |
|---|---|
| **y** | 小班总人数 |
| **x** | 当前在线人数 |
| **y - x** | **到课后离线**的学生数（进入教室后又断线），这部分学生会进入走神列表 |

### 3.3 走神列表

> ℹ️ **走神统计说明：**
> - 走神数据**只有上课后才开始统计**，每 **30 秒**更新一次；
> - 课前 10 分钟阶段，走神数量显示为 0 是**正常情况**，并非功能异常。

**走神列表的增减规则：**

| 方向 | 规则 |
|---|---|
| 进入列表 | **系统自动判断**，学生达到走神条件时自动加入 |
| 移出列表 | **老师手动**点击「完成督促」移出，系统只进不出 |

**走神原因（可选看）：**

| 走神原因 | 判定条件 |
|---|---|
| 离线 N 分钟 | 学生累计离线超过 **30 秒**，则判定为走神 |
| 连续 N 题未达 | 学生连续没做的题目超过 **2 题**，则判定为走神 |
| 后台 N 分钟 | 学生累计后台超过 **3 分钟**，则判定为走神；**侧边栏场景也归入「后台播放」Tab** |
| 多窗口 N 分钟 | 学生命中多窗口识别规则（分屏/多屏叠加/悬浮窗），进入走神「多窗口」Tab；详细规则见[十六](#十六多窗口走神识别规则) |
| 离开镜头 N 分钟 | 学生长时间有脸在镜头，之后超过 **30 秒**脸不在镜头前，则判定为走神 |
| 再次 xxxx | 学生被判定走神、被老师移除列表后，再次因**相同原因**进入列表，原因前加「再次」前缀 |

**走神原因展示优先级（高 → 低）：**
后台（含侧边栏）> 连续未作答 > 离线 > 连续答错 > 多窗口 > 离开镜头

**走神原因时长显示规则：**
- 时长 < 1 分钟：显示"XX **不足1分钟**"
- 时长 ≥ 1 分钟，不足半分钟：向下取整（如 3 分 20 秒 → "XX **3分钟**"）
- 时长 ≥ 1 分钟，超过半分钟：向上取整（如 3 分 30 秒 → "XX **4分钟**"）

> 进入列表时间 = 学生达到某一走神原因的起始时刻。

**监督方式：**

- **视频沟通**：有机会看到学生视频，老师可要求学生打开自己的视频；
- **私信**：同线上私信；
- **×2**：代表本节课该学生被老师视频沟通的次数、艾特的次数（包括右键视频沟通和讨论区手动艾特）。

**完成督促：**
认为学生表现没问题时，点击「完成督促」将其移出走神列表。

### 3.4 表扬 / 寻找特征学生

进入各班级 Tab，通过排序项筛选目标学生；如需关注表现好的学生，可从对应排序的**最末尾处**寻找。

## 四、功能详述 · 非小组教室 & 非双向视频教室

功能框架与小组教室一致，以下为**主要差异点**：

| 对比项 | 小组教室 & 双向视频教室 | 非小组教室 & 非双向视频教室 |
|---|---|---|
| 离线判定阈值 | 累计离线 > **30 秒** | 累计离线 > **3 分钟** |
| 离开镜头走神判定 | ✅ 支持 | ❌ 不支持 |
| 艾特次数显示 | ×**2** | ×**5**（视频沟通次数 + 艾特次数） |
| 快速艾特 | 需手动 | ✅ 点击「艾特」按钮后自动在讨论区艾特到该学生，可接着发消息 |

## 六、老师反馈与已知问题

以下为灰度期间收到的老师反馈，供参考（部分已在二期优化中处理）：

- 视频切换过慢
- 课件放大后，不要隐藏讨论区和老师视频
- Resize 不能缩小，老师需要并行工作
- 一节课来了几分钟后请假的学生，希望不再留在走神列表（→ 已在二期优化）
- 高年级期望可以一次艾特多个人 / 私信群发功能
- 群发助手期望支持全选（→ 已在二期优化）
- 双向视频时卡顿严重，视频框需要显示学生姓名
- 走神判断不够精准：累计离线统计会把来晚的学生也纳入
- 学生列表区域希望可以缩放
- 希望保留来晚学生的「到课离线」分类，且 3 分钟后才显示在走神列

## 九、1v1 视频沟通快速截图

> 来源：[石墨文档](https://shimo.zhenguanyu.com/docs/kKZpKJN4dPRMiEQ4) · 跟课端 **v2.9.1+（推荐 v2.11.0）**
>
> [下载跟课端 v2.11.0](https://yfd-tool.oss-cn-beijing-internal.aliyuncs.com/apphub-apps/Windows/344/Online/2.11.0/2fb32c29-be23-11f0-b152-00d861b2c4f1/yuanfudao-mentor-2.11.0.20167-installer-x64.exe)

**背景**：辅导老师跟课中有大量视频沟通后截图外化的动作，为减少操作步骤，对 1v1 视频沟通补充了快速截图能力。

**适用范围**：不限阶段 / 年级 / 学科，跟课端使用。

### 9.1 整体流程

```
课前：主管在 Focus 配置外化话术
课中：辅导老师发起 1v1 视频沟通 → 点击截图 → 选择话术 → 发送（直接发至学生家长微信）
课后：在 Focus 带班表查看截图留存
```

### 9.2 话术配置（主管操作）

入口：**Focus → 管理 → 快速截图话术配置**

- 主管下属有多个部门时，需**面向各部门单独配置**；
- 每个部门下支持配置 **5 个**用户分层；
- 每个分层下支持配置 **3 条**话术；
- 配置完成后需**手动启用**；同一分层下有多条话术时，只能启用 **1 条**。

### 9.3 截图与发送（辅导老师操作）

1. 对学生发起 1v1 视频沟通后，卡片上出现**【截图按钮】**；
2. 点击截图按钮，直接截取当前沟通画面；不满意可**再次点击重新截取**（发送时只发最新一张）；
3. 结束视频沟通后，选择主管预配置的话术，默认包含红绿条，可取消勾选只发视频画面；
4. 点击**「发送」**，内容直接发至该学生的**家长微信**，成功后显示「截图已发送」；
5. 点击**「删除图片」**：内容无法找回；
6. 点击**「取消」**：无法继续发送，但截图内容**保存至 Focus**，可在 Focus 查看。

### 9.4 Focus 带班表截图留存

- 课中进行了 1v1 视频沟通且使用了快速截图的用户，课后可在带班表「**直播课列 → 红绿条下方"课中回访"**」查看截图物料；
- 支持筛选：是否有过 1v1 视频沟通 & 是否在课中有过快速截图回访。

## 十、群发视频沟通

> 来源：[石墨文档](https://shimo.zhenguanyu.com/docs/kEzy8MNKldYnSXZb) · 0707 上线，**0811 全量**
>
> PRD：[Confluence](https://confluence.zhenguanyu.com/pages/viewpage.action?pageId=865487086)

**背景**：为提升辅导老师视频沟通覆盖效率，支持「**先录制视频，再批量发起视频沟通**」。

**使用范围**：素养 / 学科所有阶段、科目；跟课端 **v2.3.0+**（已全量）

> ⚠️ 1016 起，单节课视频沟通上限已调整至 **5 次**

### 10.1 版本要求

| 客户端 | 最低版本 |
|---|---|
| 跟课端 | 2.3.0 |
| 学生端 iOS & 安卓 | 8.11.0 |
| 学生端 iPad & 安卓 Pad | 8.11.0 |
| 学生端 PC | 7.3.0 |
| 学生端 Mac | 2.3.0 |

### 10.2 整体流程

功能分为**录制**和**群发**两部分，可录完即发，也可先录制稍后群发。

### 10.3 视频录制

1. 点击入口「**群发视频沟通**」，进入学生选择页面；
2. 选择学生方式：
   - **全选**当前筛选项下的所有学生；
   - **仅选中**当前页面中的学生；
3. 点击「确定」唤起视频窗口，发起方式默认选中「**录制新视频**」；
4. 调试好音视频后，点击「开始录制」（**录制时长 ≤ 1 分钟**）：
   - 点击「取消」：回到开始录制初始界面；
   - 点击「完成」：保存已录制视频；
5. 录制完成后可回看；建议**给视频命名**便于二次查询：
   - 点击「重录」：回到初始录制界面；
   - 点击「群发」：视频发送给所选学生（学生端样式与 1v1 视频沟通一致）。

### 10.4 选择已录制视频群发

1. 选好学生并打开视频窗口后，在发起方式处点击「**选择已录制视频**」；
2. 从下拉列表中找到本节课已录制好的视频，可回看、重录或重命名；
3. 点击「群发」发送该视频。

## 十一、讨论区马甲（伪用户发言）

> 来源：[Confluence - 初高中导流课讨论区新增马甲](https://confluence.zhenguanyu.com/pages/viewpage.action?pageId=859429430)
>
> UI 稿：[Miaoduo 设计稿](https://beta.miaoduo.com/file/ae2WEEMwOUYKa37HHquFb33?nodeId=0%3A1&type=design)

### 11.1 背景与使用场景

**问题**：初高中导流课到课率低（大科目约 25%，小科目约 10%），课堂发言稀少（大科目平均每班 10-35 条，小科目更少），课堂氛围冷清，影响学生留存和销售转化。

**解决方案**：辅导老师可在讨论区使用「**马甲**」能力，以假昵称（伪用户）发言，学生看到的是其他学生 / 家长在发言，营造热闹的直播间氛围。

**主要使用场景：**
1. 开场、主讲老师介绍、讲题、公式 / 大招讲解、激励报名等环节，用不同「伪用户」回应主讲老师；
2. 固定几个「伪用户」穿插在各场景中反复出现，与主讲老师配合，强化递进感和真实感。

### 11.2 功能范围

| 维度 | 范围 |
|---|---|
| 阶段 | 初高中 + 小学（1030 扩展） |
| 班课类型 | 短期班、特训班（小学含系统班） |
| 教室类型 | 普通大班教室（含伪直播教室）、双向视频教室、小程序伪直播 |
| 端 | 跟课端、学生端、老师端 |

> **1030 更新**：开放范围扩展至：
> - 小学 + 系统班 & 短期班 & 特训班 + 大班和双向视频教室（含对应伪直播）
> - 初高中 + 短期班 & 特训班 + 大班和双向视频教室（含对应伪直播）

### 11.3 辅导老师端操作

**入口**：讨论区右下角「**切换身份**」图标

| 状态 | 表现 |
|---|---|
| 默认 | 非高亮，hover 时高亮并展示「使用假昵称在讨论区发言」 |
| 点击后 | 图标高亮，弹出发言弹窗（含昵称编辑框 + 消息输入框） |

**弹窗填写规则：**
- **昵称**：必填，支持文字 / 数字 / 英文大小写 / 标点符号 / 空格，**最长 50 字**；
- **消息**：默认提示文案「发言会以假昵称在学生端讨论区出现，请谨慎发言」，**最长 400 字**；
- 昵称和消息均不为空时，「发送」按钮才可点击；
- 每次点击「切换身份」图标或切换全部 / 小班 Tab 时，昵称和文本**自动清空**；
- 弹窗出现时，界面其他功能点击不产生变化。

**发送逻辑：**
- 发送成功后弹窗消失，发言以「伪用户」身份展示在讨论区；
- 辅导老师侧**不支持对伪用户禁言**，也**不支持删除伪用户发言**（右键昵称不弹出操作框）。

**发送失败场景：**

| 场景 | Toast 提示 | 弹窗状态 |
|---|---|---|
| 当前小班被辅导老师禁言 | 「当前小班已被禁言」 | Toast 消失后弹窗关闭 |
| 全部小班均被禁言（全部 Tab）| 「全部小班已被禁言」 | Toast 消失后弹窗关闭 |
| 主讲全员禁言 | 「老师已对全员禁言」 | Toast 消失后弹窗关闭 |
| 网络异常发送失败 | 「发送失败，请稍后重试～」 | Toast 消失后弹窗及内容**保留** |

**课堂活动期间发言限制（与真实学生保持一致）：**

| 活动类型 | 伪用户是否可发言 |
|---|---|
| 测验题、互动题、跟读题 | ✅ 发起过程中可发言（学生提交后同样可发） |
| 幸运彩蛋 | ❌ 期间不支持发言 |
| 辅助线题、标记题、自由阅读、主观题、拍照互动 | ❌ 活动过程中禁止发言 |

### 11.4 讨论区展示规则

**辅导老师侧（跟课端）：**
- 命中全部 Tab：发言前展示「**面具图标 + [全部] + 昵称**」
- 命中某小班 Tab：发言前展示「**面具图标 + 昵称**」（不显示班级）
- 全部 Tab 下查看历史发往全部班级的伪用户发言：仅展示「面具图标 + 昵称」

**主讲老师端：**
- 伪用户昵称前展示**面具图标**，昵称后展示班级（`昵称[xx班]` 或 `昵称[全部]`）；
- 可对伪用户发言进行**发言上墙**（展示默认头像 + 昵称 + 内容，无面具）；
- 开启**弹幕**时，伪用户发言同样以弹幕形式展示；
- **不支持**对伪用户进行禁言（长按昵称不弹出禁言框）；
- 主讲使用全员禁言时，也**无法看到**伪用户发言。

**学生端：**
- 讨论区按发言顺序依次展示伪用户发言（视觉上与真实学生无异）；
- 全员禁言 / 小班禁言时，学生同样无法看到伪用户发言；
- 支持**敏感词过滤**；
- 伪用户发言**计入讨论区快捷互动**；
- **旧版本学生端**也支持展示伪用户发言（版本兼容）；
- **回放**中也会展示伪用户发言。

## 十二、跟课话术配置

> 来源：[石墨文档](https://shimo.zhenguanyu.com/docs/q4Ry0dXQe6w8fEbx) · PRD：[Confluence](https://confluence.zhenguanyu.com/pages/viewpage.action?pageId=728691377)

### 12.1 功能简介

辅导老师**提前配置话术**，在课程打铃或播放到相应课件时，以辅导老师角色自动发出。

> ⚠️ 话术针对**本节课全部学生**生效。例如某节课由 A、B 两个团队同时带课，A 团队配置了话术，B 团队的跟课区也会收到。

### 12.2 功能范围

| 维度 | 范围 |
|---|---|
| 阶段 | 小学、初中、高中 |
| 学科 | 除猿编程、斑马、南瓜科学的初中所有学科 |
| 班课类型 | 特训班、短期班、系统班 |
| 课程形式 | 直播课 |
| 课程类型 | 全部 |
| 直播教室类型 | 普通大班教室、支持双向视频的大班教室 |
| 跟课端版本 | V3 跟课端 |

### 12.3 话术配置方法

**配置入口：**

- 系统班：[Focus 系统班跟课话术配置](https://focus.yuanfudao.com/#/%7Bfocus-react%7D/#/task-system/systematic-follow-lesson-config)
  - 权限负责人：**田育珍**（系统班管理者，可给自己团队带的全部班课配置，包含当前学季系统班和赠送的导流课）
- 导流课：一般由策略老师配置，开通权限联系 **董轩鸿**

**配置内容：**

点击课程列表右侧「编辑」按钮进入话术配置页（仅主讲教案已生成时可点击）。包含两类话术：

**① 特定时间话术：**
- 包含上课铃、下课铃（含课间休息上/下课铃），铃声个数由系统根据课程信息自动生成；
- 话术字符上限：**300 字**。

**② 特定课件话术：**
- 每页课件均可配置，话术字符上限：**300 字**；
- 支持两种发送时机：
  - **时机 1**：课件刚打开时发出；
  - **时机 2**：课件结束切换到下一页时发出。

**从其他课程复制话术：**
- 点击「从其他课程复制话术」，输入被复制课程 ID；
- 复制成功后，若当前课程已配置话术，将**直接覆盖**；
- 支持复制的条件：同阶段 + 同班课类型 + 同科目 + 同年级，且**两个课程教案总页数完全相同**；
- 「特定时间」和「特定课件」话术均支持复制。

### 12.4 教案变更时的处理

| 教案变更类型 | 系统提示 | 对已配置话术的影响 |
|---|---|---|
| 课件**内容**修改 | 页面提示 + 企微机器人通知 | 话术不受影响，但需人工检查是否需同步修改话术 |
| 课件**新增**页面 | 页面提示 + 企微通知：该课件为新增 | 不影响已有话术 |
| 课件**删除**页面 | 页面提示 + 企微通知：原第 X 页课件已删除 | 被删除页的话术**一并删除** |
| 课件**顺序调整** | 页面提示 + 企微通知：该课件由原第 X 页调整到第 Y 页 | 话术不受影响，但需人工检查顺序调整后话术是否仍合适 |

> 当教案变更时，跟课话术配置页面会收到通知弹窗，点击「确认」后刷新页面（刷新前将自动保存已编辑的话术内容）。

### 12.5 话术发送规则

| 配置类型 | 发送时机 | 备注 |
|---|---|---|
| 上课铃 / 下课铃话术 | 对应打铃时，以**班主任老师名义**发出 | — |
| 课件打开时话术 | 课件打开后发出 | 若该课件展示不足 **5 秒**，话术**不发出** |
| 课件切换到下一页时话术 | 离开该课件时发出 | 若该课件展示不足 **5 秒**，话术**不发出** |

## 十四、跟课端发送实时红绿条（高级群发）

> 来源：[Confluence — V1&V3跟课端接入Focus高级群发](https://confluence.zhenguanyu.com/pages/viewpage.action?pageId=595883371)（2024-01，底部工具栏入口）· [Confluence — 支持发送跟课端实时红绿条](https://confluence.zhenguanyu.com/pages/viewpage.action?pageId=589857303)（2023-12，初版）· [Confluence — 跟课端实时红绿条迭代-25.3月](https://confluence.zhenguanyu.com/pages/viewpage.action?pageId=822531940)（2025-03，题号展示逻辑更新）

**背景：** 辅导老师课中需要向家长发送学生课堂表现素材（红绿条、视频截图等），原来需要自己截图再粘贴至微信，效率低、覆盖不完全。本功能支持直接从跟课端唤起 Focus 高级群发，一键发送实时红绿条图片。

> ℹ️ 适用范围：V1、V3 教室；全阶段、全科目、全班课类型。

### 14.1 跟课端入口

**入口一：底部工具栏**

底部工具栏原有「微信群发助手」图标，hover 后展开为两个按钮：

| 按钮 | 说明 |
|---|---|
| **企微群发助手** | 保持原有逻辑，选人后跳转至企业微信原生群发助手（所有用户发送相同内容） |
| **高级群发（支持红绿条）** | 选人后跳转至 Focus 高级群发页面，支持对不同用户发送不同图片（如各自的红绿条） |

**入口二：学生卡片 hover（较新）**

1. 鼠标 hover 学生卡片上的微信图标；
2. 弹出菜单中点击**「红绿条回访」**；
3. 多选学生后，点击「红绿条回访」批量唤起高级群发。

### 14.2 跳转至 Focus 高级群发流程

1. 点击后**直接进入「选择收信人身份」**步骤（跳过内容选择）；
2. 点击「下一步」进入高级群发弹窗：
   - 自动在输入框中添加「**跟课端实时红绿条**」内容；
   - 内容选项中新增「直播课」→「**跟课端实时红绿条**」选项：
     - 此选项**仅从跟课端唤起时才展示**；
     - 进入后**只有此选项可选**，不可叠加其他内容。
3. **名单不可编辑**：从跟课端唤起的高级群发，Focus 侧名单禁止编辑，hover 名单时提示「仅支持在跟课端修改名单」。

### 14.3 红绿条图片样式

发给家长的图片包含以下信息：

| 字段 | 内容 |
|---|---|
| 标题 | {用户姓名}的课堂表现 |
| 副标题 | 节次名称（episode 名称） |
| 主体内容 | 当前学生的实时红绿条（题号色块 + 跟读题独立模块） |
| 说明 | 色块含义说明 |

**题号展示逻辑（2025.3 更新）：**

| 题目类型 | 作答状态 | 展示样式 |
|---|---|---|
| **普通测验题** | 答对 | 🟢 绿色题号 |
| | 答错 | 🔴 红色题号 |
| | 半对 | 半绿半红题号 |
| | 未作答 | ⚫ 灰色题号 |
| **跟读题** | — | 单独拆分为独立模块展示：含各星级达成次数，以及每道题的评星和作答状态 |
| **互动课件题** | 已作答（任意结果） | 🟢 绿色题号 |
| | 未作答 | ⚫ 灰色题号 |

> ℹ️ 2025.3 更新前，跟读题和互动题在完成作答后仍展示为灰色（与未作答一致），导致红绿条结果与用户实际作答不符；本次迭代修复了此问题。

## 十六、多窗口走神识别规则

> 来源：[Confluence — 识别监督学生多窗口等走神场景](https://confluence.zhenguanyu.com/pages/viewpage.action?pageId=936236492)
>灰度文档：[【灰度文档】识别监督学生多窗口等走神场景](https://confluence.zhenguanyu.com/pages/viewpage.action?pageId=996259447)
> 功能无需配置 featureset，按课程 ID / 班课 ID 维度灰度上线。

### 16.1 本期识别的 P0 场景（共 5 个）

| 序号 | 端 | 场景 | 识别规则 |
|---|---|---|---|
| 1 | iPad | 教室窗口被收起在侧边栏（线上已有） | 收起超过一定时长即触发 |
| 2 | 安卓 / 安卓 PAD | 多屏叠加 / 悬浮窗（教室窗口上层出现遮挡） | 教室窗口被其他应用遮挡持续 **> 8 秒**；2 秒内聚焦/失焦状态快速切换时**不上报** |
| 3 | 桌面端（Mac） | 教室窗口被收起在侧边栏 | 收起超过 **5 秒** |
| 4 | 桌面端（Mac & Win） | 分屏 | 任一非教室窗口所占屏幕比例 **> 30%**，持续 **> 5 秒** |
| 5 | 桌面端（Mac & Win） | 多屏叠加 | 教室窗口被遮挡，或下层任一非教室窗口占屏比 **> 30%**，持续 **> 5 秒** |

> ⚠️ **桌面端 PRD 补充说明：**
> - 桌面端分屏、多屏均归类为「多窗口」；若遮挡窗口未达 30% 临界值则识别为「后台」。
> - 教室下方有多个窗口时，只要其中**任意一个**超过 30%（不是累加）即触发。
> - 安卓：将教室窗口上移至任务管理界面 → 识别为后台；缩小至小窗且失焦 → 识别为多窗口。

### 16.2 走神 Tab 结构变化

| Tab | 归入场景 |
|---|---|
| 后台播放（原有） | 退后台 / 锁屏 / **侧边栏**（iPad & Mac 侧边栏场景统一归入此 Tab，走神原因中展示"侧边栏 X 分钟"） |
| **多窗口（新增）** | 安卓悬浮窗 / 桌面端分屏 / 桌面端多屏叠加 |

> 多窗口 Tab 在 AI/小组教室中展示于「连续未答」之后；在普通大班教室中展示于「连续答错」之后。

### 16.3 走神列表展示规则

- 学生命中多窗口/侧边栏识别规则后，**立即**进入对应 Tab（多窗口 Tab 或后台播放 Tab）及走神-全部 Tab。
- 学生**状态恢复正常后，从列表中剔除**（与线上后台逻辑一致）。
- 走神原因展示规则与时长计算方式同 [3.3 节](#33-走神列表)。

### 16.4 可行性说明（错判 & 漏判）

| 端 / 场景 | 问题类型 | 说明 |
|---|---|---|
| iOS 多屏叠加 | **错判** | 设备触发台前调度但只有一个教室窗口时，也会被识别为多屏；处理方式：仅提示「可能多窗口」，辅导结合红绿条、答题情况自行判断 |
| 安卓 多屏叠加（教室在下层） | **漏判** | 教室窗口下层有其他窗口但学生未操作时无法识别 |
| 安卓 分屏 | **漏判** | 分屏状态下学生操作行为仍在教室窗口时无法识别 |
| iOS 后台播放音视频 | **错判风险** | 本期暂不处理该场景 |

## 十七、小班禁言

> 来源：[石墨文档 — V3跟课端支持班主任对小班禁言](https://shimo.zhenguanyu.com/docs/xF1MyKaelQn0unHN) · [PRD（Confluence）](https://confluence.zhenguanyu.com/pages/viewpage.action?pageId=822539969)

### 17.1 功能简介

班主任可在 V3 跟课端对**指定小班**发起全员禁言，帮助维持小班发言秩序。

### 17.2 功能范围

| 维度 | 范围 |
|---|---|
| 阶段 / 学科 | 全部（猿编程除外） |
| 班课类型 | 全部 |
| 课程类型 | 直播课、伪直播课 |
| 跟课端 | **V3 跟课端**（不支持旧版） |

**功能已全量上线。**

**客户端最低版本要求：**

| 端 | 最低版本 |
|---|---|
| 辅导 App（Android/Pad） | 8.7.0 |
| 优课 App | 1.66.0 |
| 素养 App | 3.7.0 |
| 跟课端 PC | — |

### 17.3 操作方式（跟课端）

**发起禁言：**
1. **右键**小班 Tab，点击「小班全员禁言」按钮；
2. 在弹窗中选择禁言时长：**3 分钟 / 5 分钟 / 10 分钟**；
3. 禁言生效后，班级 Tab 上方显示**禁言标识**。

**解除禁言：**

| 方式 | 说明 |
|---|---|
| 自动解除 | 到达禁言时间后自动解除 |
| 提前手动解除 | 右键小班 Tab → 点击解除禁言 |

### 17.4 各端展示规则

| 端 | 禁言后展示 |
|---|---|
| 跟课端 | Tab 上方显示禁言标识 |
| 学生端（大班教室） | 发言入口置灰，无法发言 |
| 学生端（小组教室 / AI 教室） | 发言入口置灰，无法发言 |
| 老师端 | 展示当前小班处于禁言状态 |
