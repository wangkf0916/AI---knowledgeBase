## 一、背景：为什么从随文批升级到原图批

原有的「**随文批**」方案依赖 OCR 文字识别，存在以下问题：

1. OCR 识别不准导致字句批改内容错乱，辅导老师兜底成本高；
2. 敏感词误伤多（寒假占群反馈 case 的 24%），且 C 端直接拦截上传体验差；
3. 报告模块与原文位置割裂（开头、结尾、详略等问题无法对应到原文）；
4. 缺少句子级别的润色建议。

**原图批方案优势：**
- 直接在用户上传的作文原图上圈画批注，更贴近线下老师批改方式；
- 无需展示 OCR 识别结果，OCR 准确率问题对用户不可见；
- 敏感词校验移到 B 端，C 端上传流程不再阻塞；
- 支持新增「**单句润色**」批改项，A → B 的直接句子修改。

## 三、上传流程变更

**原流程**：拍照 → OCR 识别 → 用户修正文字 → 提交批改

**新流程**：拍照 → **直接提交批改**（去掉 OCR 修正步骤）

| 变更点 | 说明 |
|---|---|
| 去掉 OCR 识别结果页 | 不再需要用户检验/修正文字，照片直接提交 |
| 敏感词检测移到 B 端 | C 端上传不再拦截，生成报告后由辅导老师在 B 端处理 |
| 按钮文案 | 原「下一步」改为「**提交批改**」 |
| 字数校验保留 | 图片有文字且字数达标 → 激励弹窗 → 进入等待页；不达标 → 弹窗提示（不强制阻塞） |

**拍摄引导（新手引导）：**
- 首次使用（新用户或版本更新后第一次）展示新手引导；
- 点击「跳过」关闭；点击「下一步」逐步引导后进入拍摄。

**拍摄流程：**
1. 拍摄完成后图片自动矫正（裁切/旋转/文字方向），并播放矫正过程动画；
2. 用户一次拍摄双页时，裁切页自动选取一页显示；
3. 矫正 loading 失败：展示网络错误 toast，回到拍摄状态。

## 四、批改报告页

### 4.1 整体结构

| 模块 | 说明 |
|---|---|
| **总评** | 等级 + 分数 + 雷达图（6 维度） |
| **原图批（字句批改）** | 在用户作文原图上圈画批注 |
| **详细点评** | 仅展示审题、立意、详略（不重复原图批内容） |
| **个性化润色** | AI 全文润色（润色部分高亮显示） |
| **素材积累** | 讲师配置的好词好句模块 |

### 4.2 原图批改模块

**批注类型：**

| 批注类型 | 标注样式 | 是否有序号 | 是否可点击 |
|---|---|---|---|
| 错别字 | 圈画 + 附近显示正确文字 | 无 | 不可点 |
| 不文明用语 | 圈画 + 显示「用语不当」 | 无 | 不可点 |
| 精彩用词 / 精彩描写 | 序号 + 划线 | 有 | 可点击查看评语 |
| 句子润色（新增） | 序号 + 划线 | 有 | 可点击查看评语 |
| 开头 / 结尾 / 启发性问题 | 序号 + 划线 | 有 | 可点击查看评语 |

> ℹ️ 序号编号不包括错别字和不文明用语类型。

**特殊情况：**
- 同一位置有多个批注时（包含或交叉），合并为一个序号，评语在弹层中堆叠展示；
- 启发性问题和单句润色出现在同一句时，高亮范围取更长的那个。

#### 手机端交互

1. 点击序号或划线句子 → 底部批改详情弹出（默认最小高度，可上拉至最大高度）；
2. 弹层内可切换序号（序号过多时可横向滚动）、点击「上一个/下一个」切换；
3. 切换序号时，原图自动定位到对应位置；
4. 点击原图非可点击区域 / 向下滑动 → 弹层收起，序号取消高亮；
5. 点击页面顶部 tab → 切换至其他报告模块。

**新手引导（手机端）：**
- 首次进入原图批模块时展示；
- 在第一段显示高亮句子 + 引导文案：「点击序号或划线句子可以查看点评内容哦~」；
- 点击「我知道了」或弹窗外区域关闭；仅展示一次。

#### Pad 端交互

- **左右分栏**：左侧展示原图批注，右侧展示对应评语（评语区不可点击，随左侧滑动同步）；
- 批注按从上到下排列，第一个顶部与格子纸顶部对齐；
- 多个批注内容重合时，右侧展示多条评语，共用一个序号；
- 点击划线处 → 高亮该句子，右侧评语定位到对应高度。

#### PC 端

- 无拍摄引导（PC 不拍照），无矫正动画；
- 其余逻辑同 Pad。

### 4.3 详细点评

- 仅展示审题、立意、详略（原图批已覆盖的内容不重复）；
- 不再分「内容」和「结构」两类，直接平铺展示。

### 4.4 个性化润色

- 模块名由原「个性化范文」改为「**个性化润色**」；
- 润色部分在文字中**高亮显示**（词汇/句子/句群/段落级别）；
- 注：对原文删除的内容不显示删除线（技术暂不支持）；
- 若含不文明用语，总评评语增加固定文案：「但是，你的作文有不恰当的用词，要注意表达得体哦」。

## 五、异常情况

| 场景 | 处理方式 |
|---|---|
| 作文含敏感词 / 不文明用语 | C 端不拦截上传；B 端生成报告后检验，分享按钮对高风险用户不可用；原图批注中圈画并标注「用语不当」 |
| 矫正 loading 失败 | 弹通用网络错误 toast，回到拍摄状态 |
