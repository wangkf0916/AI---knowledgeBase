## 一、功能概述

口算练习是学生端「**精练**」tab 下的数学练习功能，面向 **小低（App 选择 1-2 年级）** 的用户。

计算是小学阶段的刚需，尤其小低阶段需要打好计算基础。本功能通过**闯关升级徽章 + 金币激励**的方式，让学生自主进行手写计算练习。

## 三、学生端使用流程

### 3.1 入口

- **手机端**：精练 tab，当且仅当 App 选择年级为一、二年级时展示；
- **平板端**：同手机端。

### 3.2 内容选择

- **首次进入**：根据用户在读班课（如有）或首页所选年级自动推荐年级版本；
- **非首次进入**：默认进入上次选择的年级版本；
- 点击顶部年级版本，可拉起内容选择弹窗切换年级版本。

### 3.3 选择赛场（闯关）

1. 点击具体**知识点**，进入赛场选择页；
2. 选择具体赛场，挑战该知识点的口算掌握程度；
3. **必须在前一个等级赛场达到三星，才能解锁下一个赛场**；
4. 用户在该知识点的最高挑战星级会展示在知识点入口处。

### 3.4 练习内容

按所选知识点，根据教研老师配置的表达式进行练习。

**题型包括：**
- 比大小
- 加减乘除
- 混合运算

用户进入后**手写输入**答案进行挑战。

### 3.5 练习结果

- 完成挑战后，根据所得星级发放金币；
- 点击结果页的「**分享成果**」可分享手写成果；
- 用户获得的该知识点最高等级会展示在知识点陈列页面。

## 六、Focus 平台说明

### 6.1 学生个人详情页

- 拓展模块 → 「**口算练习**」；
- **整体掌握**：展示用户所有练习过的知识点的掌握程度，包括：
  - 星级、累计练习数据、最新练习数据；
  - 如最新练习触发星级晋升，展示晋升详情；
  - 支持按年级 / 学期 / 教材版本筛选。
- **学习记录**：展示用户每天详细的学习情况，包括：
  - 每天是否学习、学了哪些知识点、练习次数；
  - 当天知识点的星级晋升情况。

### 6.2 带班列表页

- 带班列表页 → 「拓展」→「口算练习」；
- 老师可自行选择想看的知识点（点击「选择知识点」按年级 / 学期 / 教材版本筛选）；
- 选择后展示所有学生对该知识点的掌握星级及达到星级的时间；
- 点击具体星级，可在抽屉内查看该知识点的详细练习数据。

## 七、常见问题

**Q：为什么看不见精练 tab？**
1. 确认用户当前年级选择是否为**一年级或二年级**；
2. 确认客户端版本是否为 **7.34.0 及以上**；
3. 确认后仍无入口，向技术支持报障。
