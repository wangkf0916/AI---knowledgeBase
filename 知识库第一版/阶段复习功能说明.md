## 一、功能简介

阶段复习是每上完 **3-4 节课**后，回顾和检测前面课程学习效果的学习环节，在**长学季系统班**中使用。

**作用：**
- **教学层面**：复习巩固已学知识，培养学生及时复习的学习习惯；
- **运营层面**：辅导老师可通过阶段测试及早发现学生学习问题，提供个性化服务。

**当前支持范围：**
- 入口限制：**小学数学 0-6 年级系统班** & **编程科目**
- 班课类型：长学季系统班

**两个学习任务（均可单独配置）：**

| 任务 | 说明 | 金币奖励 |
|---|---|---|
| **知识回顾** | 前几节课知识点串讲视频，时长 ≤ 45 分钟 | 看完 **+10 金币** |
| **阶段测试** | 随到随测、有倒计时的阶段性测验，仅客观题，系统自动批改 | 提交即得 **+10 金币** |

> ℹ️ 配置时可以没有知识回顾，但**必须有阶段测试**。

## 三、学生端流程

### 3.1 入口

阶段复习以**学习任务卡片**的形式展示在班课主页的课程大纲/课程列表中：
- **App / iPad**：点击「我的课程」→ 班课主页 → 课程列表中找到阶段复习卡片；
- **PC / Mac**：点击切换到课程列表第三个标签「阶段复习」。

### 3.2 知识回顾

- 点击入口直接进入视频播放页面；
- 看完视频获得 **10 金币**；
- ⚠️ 拖动进度条到末尾系统不做严格校验，也会发放 10 金币。

### 3.3 阶段测试

**时间规则：**

| 时间维度 | 说明 |
|---|---|
| 开放时间 | 运营在创建时配置，到达开放时间后学生才能进入 |
| 逾期时间 | 过了逾期时间后，学生不能作答也不能提交 |
| 答题时长 | 从学生开始作答后倒计时，倒计时结束系统**自动收卷** |

> ℹ️ **截止前进入不影响作答时长**：只要在截止时间前进入，仍享有完整的配置答题时长（如配置 30 分钟，哪怕截止前 1 分钟进入，依然有 30 分钟作答）。

**题目形式：** 目前仅支持**客观题**（选择、填空），暂不支持主观题，系统自动批改。

**作答流程：**
```
测试说明页 → 作答页 → 测试报告页
```
- 提交后立刻可以看到测试分数和详细题目解析；
- 完成阶段测试（只要提交）即可获得 **10 金币**。

## 四、Amaze 配置（教务运营）

### 4.1 阶段复习模板（班型维度）

**入口：** Amaze → 全部班课 → 班型 → 新建班型 → 阶段复习模板

点击「添加阶段复习模板」，选择标签后编辑，字段如下：

| 字段 | 格式 | 说明 |
|---|---|---|
| **名称** | 28 个汉字 / 56 个字符 | 阶段复习名称，用于学生端展示 |
| **知识回顾** | 有 / 无 | 是否配置知识回顾视频 |
| **阶段测试名称** | 28 个汉字 / 56 个字符 | 阶段测试名称，用于学生端展示 |
| **测试开放时长** | 数字（小时） | 从阶段测试开放开始计时，到期无法进入 |
| **测试用时** | 数字（分钟） | 开始测试后的答题倒计时时长 |

### 4.2 排班后配置时间

发布班课设计任务后，大纲中显示「待创建的阶段复习」，点击填写信息：
- **有知识回顾**：需输入知识回顾开放时间（须早于测试开放时间）+ 测试开放时间；
- **无知识回顾**：只需输入测试开放时间。

也可通过「增加阶段复习」按钮在班课中手动单独添加一次阶段复习（字段同上）。

## 五、Cyber 配置（教研老师）

### 5.1 阶段测试组卷

**入口：** Cyber → 班课产品课程大纲 → 阶段测试

- 在阶段复习设计详情页进行组卷，流程同**班课考试**；
- 可复制其他阶段测试考卷，也可新建；
- 新建后点击「编辑」在组卷编辑器中布置模块、题目和分值；
- 完成后发布考卷；如需变更题目，可再次编辑并重新发布。

**支持题型：** 仅客观题（系统自动批改），暂不支持主观题。

### 5.2 知识回顾视频关联

**入口：** Cyber → 班课产品课程大纲 → 回顾视频 → 点击「去布置」

在阶段复习设计详情页，弹窗中搜索并输入回顾视频 ID，确定后完成关联。

## 六、知识回顾视频录制（主讲老师 iPad 端）

### 6.1 创建回顾视频

**入口：** Cyber → 内容库回顾视频 → 新建回顾视频（操作与创建预习视频一致）

1. 上传回顾教案及所需视频/音频素材；
2. 上传教案后，在教师端**扫描二维码**进入录制教室；
3. 录制完成后可预览，确定后发布，发布后可被阶段复习关联使用。

### 6.2 录制前注意事项

> ⚠️ 录制前必读：

| 注意事项 | 说明 |
|---|---|
| **系统版本** | iPadOS 需在 13 以上，否则可能录制黑屏 |
| **屏幕遮挡** | 课件区不能有任何遮挡（如外部弹框），否则会录入画面 |
| **电量** | 确保录制前设备有足够电量 |
| **音频** | 建议佩戴耳麦，嘴离麦近，保证声音清晰 |
| **课件** | 确保课件中无多余笔记残留；课件区展示要讲的课件首页 |
| **翻页方式** | 仅支持正常翻页，**不支持缩略图跳转翻页** |
| **时长限制** | 最长 45 分钟，超时自动停止录制 |

### 6.3 录制操作

**进入录制教室：**
1. 点击课程表右上角「…」→「扫一扫」（仅主讲老师有权限，辅导暂未开放）；
2. 首次使用需授权相机权限（用于扫描二维码）；
3. 扫描二维码进入教室；
4. 首次使用需授权蓝牙权限。

**录制：**
- 录制开始前，工具栏工具和课件翻页均可正常使用；
- 点击「开始录制」→ 系统弹出「录屏与麦克风」授权弹框 → 点击授权即开始录制；
- 书写方式与教室中完全一致，唯一区别是**不能调起缩略图**；
- 录制完成后点击「结束录制」。

**视频上传/删除：**

| 操作 | 结果 |
|---|---|
| 点击「上传」 | 视频上传到 Cyber，自动退出教室 |
| 点击「不上传」 | 自动退出教室，视频仅保存到本地相册，**之后无法再上传到阶段复习中** |

> ℹ️ 不上传的视频可作为教学素材发给学生，或在本地核查视频是否有问题。

## 七、Focus 回访（班主任老师）

> ℹ️ 阶段测试是**随到随测**，不是集中考试，因此**不支持在测试进行中实时查看学生是否已进入测试**，但会显示学生是否已提交。

- 课程大纲中配置了阶段复习的，可在列表中查看学生**知识回顾视频**和**阶段测试**的完成数据；
- 支持点击分数查看题目详情；
- 支持**下载测试报告**和**测试错题**；
- 支持在学生详情页查看阶段复习数据；
- 支持制作**阶段复习表扬榜**（按阶段测试得分）。

## 八、常见问题 FAQ

| 问题 | 解答 |
|---|---|
| 学生在 App 上看不到阶段测试入口？ | 确认是否用**班主任账号**登录。班主任账号在学生端不展示阶段测试；学生身份登录后可正常显示。若确认是学生身份仍看不到，联系**李金刚（lijg）**。 |
| 截止前 1 分钟进入，还有多长时间作答？ | 享有**完整的配置答题时长**（如配置 30 分钟，仍有 30 分钟），不会只有 1 分钟。 |
| 学生开始作答后忘记交卷怎么办？ | 无需手动处理，倒计时结束后**系统自动收卷**。学生也可在倒计时结束前主动提前交卷。 |
| 学生成绩什么时候出来？ | 客观题（选择/填空/判断）：提交后**立刻出成绩**，学生 App 和老师 Focus 均可立即查看。主观题（拍照上传）：需辅导老师人工批改并发送报告后，学生和老师才能看到成绩（支持批改一个发一个）。 |
