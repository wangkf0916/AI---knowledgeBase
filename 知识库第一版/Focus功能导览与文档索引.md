## 二、我的带班（主页）

| 区域 | 说明 |
|---|---|
| 今日任务 | 展示当日待执行任务（已完成 / 未执行 / 已达标 / 任务总数） |
| **新学员触达任务** | 展示新学员触达进度：符触达数 / 即将超时数 / 已超时数 / 当周已触达数；用于追踪新学员首次沟通覆盖情况 |
| 我的带班 - 未结束 / 已结束 | 班课列表，含进行中 / 未开始分类 |
| 学生列表 | 进入带班表，查看学生到课率、完课率、习题提交率等 |
| 小班数据 | 班课维度数据汇总 |
| **转化数据（右上角）** | 当前班课维度的转化指标看板，含排行榜视图；展示字段：预定率、补缴率、完课率、续（90% 到课率）；可按学科/班课类型筛选，点击「详情」查看完整数据 |
| 通话数据（右侧） | 外呼时间段、通话数、接通数、有效接通率、累计/平均通话时长 |
| 园丁活动（右侧） | 当前活动 / 历史参与记录（含三叶草奖励） |
| 带班运营计划（右上） | 跳转运营计划管理 |
