## 一、功能概述

「配音小达人」是课后新增的学习环节，学生下课后在 App 内为绘本内容进行角色配音，完成后可打卡分享。家长可通过公众号推送查看学生配音作品。

**开放时机：** 下课后开放
**逾期时机：** 由后台运营设置，建议与随堂练习逾期时间保持一致

> ℹ️ 配音小达人只能通过**班型 → 课型**维度创建使用，不支持单课程维度创建。

## 三、后台配置

### 3.1 Amaze — 教务运营开课

**配置入口：** Amaze 后台 → 班型 → 课型列表 → 增加课型

> 如何通过班型创建班课：[操作说明](https://amaze.zhenguanyu.com/assets/new-lesson-system-readme.pdf)

### 3.2 Cyber — 绘本配音内容录入

**功能入口：** Cyber → 资源库 → 对话与配音 → 绘本配音类型内容

**创建绘本配音：** 点击「新建」→ 选择「创建绘本配音类型内容」，填写以下信息：

| 字段 | 说明 |
|---|---|
| **名称** | 绘本配音名称，不暴露给学生，仅供老师维护查找 |
| **绘本内容** | 上传设计提供的绘本 zip 包；内部仅支持 **png** 文件；png 文件需用数字标识排序（如「绘本配音资源1」、「绘本配音资源2」） |
| **背景音频** | 上传 **5 分钟以内**的 mp3 格式背景音，学生参与配音时播放 |
| **配音文本** | 绘本内容对应的文本，按提示格式录入；**完成录入后**方可配置角色信息和文本音频 |
| **角色信息** | 针对文本中解析出的角色，配置头像及是否需要学生配音 |
| **文本音频** | 配置每句文本对应音频文件（支持批量上传按顺序匹配），以及每句对应的**绘本页数**和**建议配音时长**（超过建议时长的配音**不计入该句成绩**） |

配置完成后保存，下游即可使用此绘本配音。

### 3.3 Cyber — 课程设计应用

**功能入口：** Cyber → 班课产品 → 班课产品详情页 → 课程设计详情页 → **配音小达人 Tab**

- 可关联已有绘本配音，或在此处直接新建；
- 关联完成后，相关课程中自动同步绘本配音内容。

## 四、学生端使用流程

### 4.1 看绘本

- 学生需**依次看完所有绘本内容**；
- 可点击暂停键控制暂停 / 播放；
- 可通过**左滑 / 点击句子区域**切换句子进度；
- 句子播放时会**高亮**当前文本。

### 4.2 配音过程

1. **角色说明页**：说明需要配音的角色信息和个数；
2. **配音环节**：需在**倒计时范围内**完成配音；
3. **配音结果**：显示该句评星；
4. 依次完成所有句子，完成整个配音环节。

### 4.3 报告页

- 按时完成 → 奖励 **20 金币**；
- 左侧显示**配音评星**；
- 右侧可进行**打卡、分享朋友圈**，查看配音作品；
- 打卡成功后额外获得 **+5 金币**；
- 打卡海报可扫码查看学生本人的配音作品。

## 六、Focus — 班主任回访

| 查看位置 | 展示内容 |
|---|---|
| 学生详情页 → 单次课情况 → 课后环节 | 新增「配音小达人」，展示学生完成星级；点击「查看配音作品」可查看并收听具体配音文本 |
| 单次课回访列表 → 课堂表现类目 | 新增「配音小达人」列，展示对应单次课的完成情况 |
| 课程累计回访列表 → 课后累计字段 | 新增「配音小达人」列，展示学生在整个班课下的完成次数 |
| 单次课榜单 → 表扬榜 | 新增「配音小达人」类型，可选择单次课下完成配音的学生制作榜单 |
