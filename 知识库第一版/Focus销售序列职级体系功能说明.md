## 一、功能背景

针对「猿辅导辅导与销售部 - 小初销售中心 - 小学销售 / 初中销售 - 销售专员」岗位，设计了一套**季度职级段位体系**，通过段位晋升激励销售辅导降低离职率、提升外部招聘竞争力。

> ⚠️ **不适用于**：组长及管理层。

**灰度范围（Focus 端展示）：** 灰度 Key `fudaodengjitixi`，部门范围：小学销售、成长中心、初中销售。

## 二、职级段位体系规则

### 2.1 段位序列

| 段位 | 代号 | 说明 |
|---|---|---|
| 初燃原石 | S0 | 默认初始段位 |
| 青铜 | S1 | — |
| 白银 | S2 | — |
| 黄金 | S3 | 外部招聘最高初始定级 |
| 钻石 | S4 | — |
| 王者 | S5 | 顶层段位，预计约需 1 年达到 |

### 2.2 晋级机制

- **评估方式**：按同业务线 / 同期 / 同年级圈定范围，以**完成度（转化率 ÷ 目标转化率）相对排名**评估；
- **晋级线**：综合排名**前 30%**（含新辅导、离职辅导，实际晋升比例会低于 30%）；
- **评估周期**：每季度一次，由 HR 人工评估并登记；
- **晋升方式**：逐级晋升，首季度最多升至青铜（S1）；
- **外部招聘**：入职时 HRBP 给予初始定级，最高不超过黄金（S3）。

### 2.3 降级 / 淘汰规则

| 情形 | 处理 |
|---|---|
| 青铜及以上，当季排名区间 > XX% | 降级 |
| 严重违规 | 取消当季晋级资格 |
| 连续处于排名后 20% | 被优化 |

### 2.4 特殊情况

| 情形 | 规则 |
|---|---|
| 新员工保护 | 入职当季参与考核，但**首季度不降级**；缺席 ≤1 期也有可能晋升；缺席 ≥2 期则无法晋升 |
| 管理层降职 | 降回销售序列后最高保留 S1 |
| 外部架构转入 | 当赛季一律定为 S0，缺席 ≤1 期也可能晋升 |

### 2.5 奖励

不同段位对应**每月津贴**（具体金额见规则文档），并解锁专属 Focus 报单弹窗皮肤和顶部栏装扮。

## 三、Focus 端展示功能

### 3.1 新赛季定级弹窗

**触发逻辑：**
- 仅对灰度范围内的辅导触发；
- 辅导打开 Focus 首页时，系统判断当前赛季是否有该辅导的定级信息，有则弹出（**仅触发一次**；若该赛季段位信息更新则可再次触发）；
- 弹窗优先级最高，覆盖其他弹窗。

**弹窗流程（共 5 步）：**

1. **首页**：展示当前赛季名称 + 时间范围，点击【继续】进入下一步（无上赛季排名数据时按钮文案改为"揭晓定级结果"）；
2. **上赛季回顾**（仅有"上赛季排名区间"数据的辅导展示）：展示上赛季段位、排名区间（"前 XX.X%"）、参与期次；
3. **定级结果**：过渡动画后展示当前赛季段位 + 激励文案 + 段位奖励；
   - 段位提升：「甩开 XX.X% 辅导，冲到【XX】没悬念，新赛季继续猛猛出单」
   - 段位留级：「继续蓄力【XX】，新赛季续报看我一波带走」
   - 段位降级：「暂退【XX】憋大招，新赛季要拿回属于我的一切」
   - 原石段位：特殊处理，展示**下一段位**的奖励
4. **分享海报**：可一键复制段位海报到剪贴板，在企微群内分享；
5. **奖励路线**：展示所有段位徽章和对应奖励，支持查看晋级规则（跳转石墨文档）。

### 3.2 小恐龙皮肤

| 皮肤类型 | 触发条件 | 说明 |
|---|---|---|
| 报单弹窗皮肤 | 灰度范围内 S1-S5 辅导，触发定级弹窗后生效 | S0 保留原皮肤；S1-S5 替换为专属新皮肤（绿/金恐龙） |
| 顶部栏皮肤 | 灰度范围内 S1-S5 销售辅导，成功触发定级弹窗后下次打开 Focus 生效 | S0 保留原皮肤 |

> ℹ️ 皮肤持续到下次触发定级弹窗时更新（并非赛季开始时间）。

### 3.3 奖励路线（固定入口）

- 入口：Focus 头像框下方「**我的段位**」，展示最新段位名称 + 徽章；
- 点击进入「奖励路线」页面，可查看当前赛季信息、当前段位、各段位奖励；
- 若当前赛季尚未定级，显示「结算中，敬请期待」。

## 四、Hermes 后台管理（HRBP / 绩效 HR）

### 4.1 权限说明

| 功能模块 | 有权限的角色 |
|---|---|
| 赛季管理（增删改查） | 绩效 HR |
| 段位名单管理（增删改查） | HRBP + 绩效 HR |

权限配置地址：[Ladon 权限系统](https://ladon.zhenguanyu.com/#/projects/158/operations)

### 4.2 赛季管理

路径：Hermes → 成长管理 → 段位管理 → 赛季管理

- 每个赛季需填写**赛季名称**（自动编号，从 0 开始）和**开始/结束时间**（开始时间精确到 00:00:00，结束时间精确到 23:59:59）；
- 已结束的赛季不可编辑；进行中的赛季只能修改结束时间；
- 赛季名称和时间范围会在 Focus 端展示给辅导。

### 4.3 段位名单管理

路径：Hermes → 成长管理 → 段位管理 → 段位名单管理

**上传字段：**

| 字段 | 必填 | 说明 |
|---|---|---|
| ldap | ✅ | 需在 Hermes 架构下，不可重复 |
| 段位 | ✅ | S0 / S1 / S2 / S3 / S4 / S5 |
| 上赛季排名区间 | ❌ | 0.0%～100.0% 内的数字，保留一位小数 |
| 上赛季服务期次 | ❌ | >0 的整数 |

**上传时机：**

| 角色 | 操作场景 | 时机 |
|---|---|---|
| 绩效 HR | 季度首月上传上季度在职老员工定级结果 | 每季度首月（如 10.20） |
| HRBP | 新员工入职定级上传 | 入职后，延迟约 2 周可接受 |
| HRBP | 管理层降职后定级 | 操作降职后，可参考该 ldap 历史赛季段位进行定级并上传 |
| HRBP | 其他业务转入定级 | 架构调整完成后上传（统一 S0） |

> ℹ️ 若上传 ldap 在列表中已存在，则为**覆盖更新**。
>
> ⚠️ 数据项对应赛季**结束后不可编辑或删除**。

## 五、后续规划（二期）

1. **赛季高光表现回顾**：H5 形式展示辅导上季度高光数据（转化率、服务课次等）；
2. **晋级进度提示**：排行榜上提供模糊性排名提示，激励辅导持续关注；
3. **个人主页 - 成就管理**：查看历史各赛季定级情况，管理皮肤和头像框；
4. **招聘系统对接**：HRBP 在下 offer 时直接配置段位，入职后自动同步到 Hermes。
