## 一、功能简介

小猿助手 PC 版是安装在 **Windows 电脑**上的录音客户端，用于在**电脑端企业微信**通话时自动录制录音并上传至 Focus 工作台，填补了原有方案（手机企微 + EMON 录音）仅支持手机端的空白。

> ⚠️ 当前仅在**高中销售团队灰度**中，未全量开放。

**前置要求：**
- PC 端企业微信须升级至 **5.0.3 及以上**版本
- 通话时需连接**办公网络**（飞连），**不支持家庭 WiFi 或手机热点**

---

## 二、安装说明

**下载地址：**
```
https://dora-gallery-online.oss-cn-beijing.aliyuncs.com/windows-call-client/WeChatCallRecorder_Setup_1.0.5_Release.exe
```

> ⚠️ 请将链接**复制到 Chrome 浏览器**中访问下载，**勿直接点击链接**。

**安装步骤：**

1. 下载完成后，双击 `.exe` 文件，按安装向导完成安装；
2. **必须选择"以管理员权限安装"**（务必勾选，否则程序无法正常启动）；
3. 安装完成时勾选**"立即启动程序"**。

---

## 三、登录与配置

1. 安装完成后，桌面出现"小猿助手"快捷方式，双击启动；
2. 使用 **Focus 账号和密码**登录；
3. **业务线必须选择【辅导】**，选错则无法录音，需退出登录后重新选择；
4. 首次运行时若弹出"是否允许公共/专用网络访问此程序"，**必须选择"允许"**。

---

## 四、使用注意事项

| 注意事项 | 说明 |
|---|---|
| 网络要求 | 必须使用**飞连**连接办公网络，家庭 WiFi / 手机热点无效 |
| 企微窗口 | 通话时**不得最小化**企微窗口：最小化后时长 < 90 秒的通话无录音，时长 > 90 秒的通话前 90 秒录音会丢失 |
| 确认运行状态 | 将鼠标悬停在任务栏小恐龙图标上，显示"监控中"即为正常运行；若不正常，右键 → 重新启动 |

## 五、版本升级

- 新版本更新为**强制升级**，按弹窗提示操作即可；
- **升级完成后需手动双击桌面图标重新启动小猿助手**，不会自动启动。

## 六、常见问题排查

### Q1：程序启动失败

**原因：** 安装时未使用管理员权限。

**解决：** 再次双击桌面图标启动（无需重新安装）。

---

### Q2：通话结束后，录音在 Focus 工作台没有显示

按以下步骤逐步排查：

1. **确认小猿助手是否正常运行**（任务栏小恐龙 → 悬停查看是否显示"监控中"）；
2. **确认业务线是否正确**（v1.0.4 及以上可在程序内查看，需选择【辅导】）；
3. **手动补传**：右键任务栏小恐龙 → 补传录音；
4. **同步数据**：手机企微 → 右上角三个点 → 同步数据（若不可点击，先重启企微再操作）；
5. 若以上操作均无效，提供老师的 **userId + 通话详细信息（时间、时长）**，走正式报障流程。

> ℹ️ 通话时长 < 90 秒 且无录音，大概率是电脑卡顿导致 OCR 识别失败，或通话窗口被最小化。**重启电脑后**后续录音会恢复正常。

---

### Q3：录音上传失败

1. 右键任务栏"小猿助手" → 选择**"补传录音"**；
2. 若仍失败：手机企微 → 右上角三个点 → 检查 EMON 是否连接 → 点击**"数据同步"** → 在"企微消息（近 15 天）"中点击**"重新上传"**。

---

### Q4：全新电脑首次运行报错 "DLL load failed" / 安装后无录音

**原因：** 缺少 Windows 运行库。

**解决：** 下载并安装以下程序：

```
https://dora-gallery-online.oss-cn-beijing.aliyuncs.com/windows-call-client/VC_redist.x64.exe
```

双击下载的 `.exe` → 点击安装 → 等待完成。
