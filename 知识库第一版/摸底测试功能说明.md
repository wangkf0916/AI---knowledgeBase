## 一、功能简介

摸底测试是**特训班**班课的课前准备环节，用于在正式上课前了解学生的学情基础。入口位于班课主页第一个任务卡片「**课前准备**」中。

---

## 二、版本要求

| 客户端 | 最低版本要求 |
|---|---|
| 手机（Android / iPhone） | 当前线上全版本均支持 |
| iPad | 当前线上全版本均支持 |
| Windows 电脑 | **6.35.1 及以上** |
| Mac 电脑 | **1.35.1 及以上** |

> 电脑端可前往猿辅导官网下载：[https://www.yuanfudao.com/info/download](https://www.yuanfudao.com/info/download)

---

## 三、学生端入口

1. 下载安装猿辅导 App（手机、iPad 或电脑）；
2. 登录购课账号；
3. 进入「**我的课程**」；
4. 点击购买的**特训班班课卡片**，进入班课主页；
5. 找到第一个任务卡片「**课前准备**」，点击「**摸底测试**」进入。

> ℹ️ 各端（手机、iPad、Windows/Mac 电脑）入口位置相同，均在班课主页的「课前准备」任务卡片中。

---

## 四、作答流程

摸底测试分为以下几种类型，作答流程略有不同：

**类型 1：仅答题（无信息收集）**

须知页 → 作答 → 提交 → 自动生成成绩

**类型 2 / 3 / 4：收集信息 + 答题**

须知页（告知分两模块）→ 家长填写基本信息（校内成绩 + 教材版本）→ 学生参与答题 → 提交 → 自动生成成绩

> 示例：初中语文、小英英语（类型 4，收集教材版本 + 学生答题）；初二物理暑秋、初三化学暑秋（类型 1）

| 步骤 | 说明 |
|---|---|
| **须知页** | 告知测试规则及模块组成 |
| **学情信息**（选配） | 家长填写校内成绩和教材版本，部分科目/年级无此步骤 |
| **作答页** | 正式答题（支持语音读题，详见[语音读题功能说明（练习场景）.md](./语音读题功能说明（练习场景）.md)） |
| **报告页** | 自动生成测试成绩 |

## 五、发送链接功能说明

### 5.1 链接机制调整

摸底测试链接由原来的**一期一个链接**改为**一个班课一个链接**。

辅导老师需从 **Focus 工作台**复制对应班课的摸底测试链接，发送给该班课的学生，不同班课的学生链接不同。

**Focus 工作台查找链接路径：**
对应班课 → 学生列表 → 开班沟通 → 摸底测小问号

> ⚠️ **不建议**在微信里发送链接，容易发错，导致学生无法作答。**推荐引导学生直接去 App 入口作答。**

### 5.2 报错场景及应对方案

**场景一：「登录手机号与摸底测试链接不匹配，请重新用购课手机号登录或咨询班主任老师。」**

| 排查步骤 | 操作 |
|---|---|
| 第一步 | 确认发送的链接是否与学生购买的班课对应（链接必须从 Focus 工作台复制） |
| 第二步（链接无误） | 提醒学生使用**购课手机号**重新登录 |
| 第二步（链接有误） | 在 Focus 工作台重新复制并发送正确链接 |

**场景二：「当前链接已失效，请咨询班主任老师或进入 APP 内查看」**

| 情况 | 应对方案 |
|---|---|
| 学生已完成摸底测 | 引导学生去 App 查看测试报告（路径同 App 作答入口） |
| 学生未完成摸底测 | 优先引导学生去 **App 入口**作答；也可在 Focus 工作台复制新链接发送 |

> 背景：7 月 21 日起，摸底测试链接需与班课对应，之前发送的旧链接将失效。

### 5.3 引导学生去 App 作答（推荐方式）

1. 手机或 iPad 上下载安装猿辅导 App（**电脑端暂无摸底测试入口**）；
2. 使用**购课手机号**登录；
3. 进入「我的课程」；
4. 点击特训班班课卡片，进入班课主页；
5. 找到第一个任务卡片「**课前准备**」，点击「**摸底测试**」进入。

## 六、双科摸底测合并功能

> 功能上线：2023.12.20 · 生效：24 寒起

### 6.1 背景与适用范围

为提升双科特训班的摸底测完成率，将双科的摸底测作答入口合并为一个入口。

**适用范围：**
- 班课类型：特训班（单科和双科均适用）
- 科目：人文博雅、新思维、英语阅读表达
- **同样适用于学科双科**（如语文+数学等）

> ⚠️ 目前报告仅适配了**人文博雅**和**新思维**两科的知识点标签。其他科目若想使用此功能，须保证知识点标签与这两科一致，否则报告展示会有问题。

### 6.2 功能表现

**双科特训班：**
- 作答入口合并为一个，入口名称改为「**课前评估**」（原「课前准备」）；
- 作答顺序：问卷作答 → 新思维科目作答 → 人文博雅科目作答 → 英语科目作答（如有）；
- 全部科目提交后，展示**双科合并报告**。

**单科特训班：**
- 作答入口不变，流程不变；
- 报告样式升级为新样式。

### 6.3 报告内容

- 各科题目正答率、知识点正确率、作答用时
- 各科雷达图和知识点解读
- 各科答题情况

### 6.4 注意事项

| 情况 | 说明 |
|---|---|
| 双科均已提交 | 在课前评估有效期内，所有科目提交后立即可见报告 |
| 双科只提交了一科 | 需等**课前评估逾期后**才能看到报告 |
| 配置开始/结束时间 | 两科摸底测的开始和结束时间**必须配置一致**（同时开始、同时结束），系统会取最早开始时间和最晚结束时间拼合，时间不一致会导致课前评估时间范围异常 |

## 七、课前评估链接发送（Focus 端）

> 来源：[石墨文档 — 课前评估链接-功能介绍](https://shimo.zhenguanyu.com/docs/q5jy5blQ1bGwHeBr)

支持通过 Focus 以三种方式将「课前评估链接」发送给用户，用户点击后可直接唤起 App 并跳转「课前评估」页面，缩短操作路径。

### 7.1 发送入口

| 发送方式 | 路径 |
|---|---|
| 辅导私发 | 企微侧边栏 → Focus → 发送课前评估链接 |
| 辅导群发 | 带班表 → 高级群发 → 课前评估 → 课前评估链接 |
| 主管群发 | 运营计划 → 高级群发 → 课前评估 → 课前评估链接 |

> ℹ️ 原「高级群发 - 摸底测」中的选项（如测试报告、摸底测知识点报告）已整体移入「**课前评估**」选项下。

### 7.2 用户端跳转逻辑

| 平台 | 跳转流程 |
|---|---|
| PC 端（Windows / Mac） | 点击链接 → 浏览器中转页 → 点击【打开 APP】→ 唤起桌面客户端 → 跳转「课前评估」页面 |
| 移动端 Android | 点击链接 → 应用宝中转页 → 在浏览器打开 → 点击【允许】→ 唤起猿辅导 App → 跳转「课前评估」页面 |
| 移动端 iOS | 点击链接 → 中转页 → 点击【打开 APP】→ 唤起猿辅导 App → 跳转「课前评估」页面 |

### 7.3 注意事项

**跳转优先级（多平台可用时）：**

部分课程在多个 App 平台同时可用时，链接按以下优先级跳转：

> 素养 App > 小猿优课 App > 猿辅导 App

例如：某课程在「小猿优课」和「猿辅导」同时可用，点击链接会优先跳转小猿优课，需注意对用户的引导话术与此保持一致。

**PC 端版本限制：**

| 平台 | 不支持跳转的版本 |
|---|---|
| Windows | 7.9.0 以前的版本 |
| Mac | 2.9.0 以前的版本 |

> ⚠️ 用户 PC 端版本过低时，链接无法跳转至「课前评估」页面，需通过语言或图片引导用户手动打开 App 并进入对应入口。

**移动端无法正常跳转的常见原因：**

| 原因 | 现象 / 应对 |
|---|---|
| 网络问题 | 用户侧有提示，引导检查网络后重试 |
| 登录账号与购课账号不一致 | 产品有提示，引导用户切换为购课账号登录 |
| 其他原因 | 反馈「猿辅导技术支持」处理 |

> ℹ️ 未下载 App 的用户点击链接后，系统会先引导用户下载 App。
