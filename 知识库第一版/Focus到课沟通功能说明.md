## 一、查看到课沟通入口

**路径：** 打开 Focus → 进入带班表 → 查看「基本信息」列下「到课沟通」条目

---

## 二、编辑到课信息

点击小铅笔图标，进入到课编辑页，针对与用户的沟通情况，确认用户每节课的到课信息。

### 2.1 到课情况分类

| 到课情况 | 操作 | 标签显示 |
|---|---|---|
| 确认到课 | 选择「确认到课」→ 选择到课类型 | 预期到课 / 晚到 xx 分钟 |
| &nbsp;&nbsp;↳ 预期到课 | — | 预期到课 |
| &nbsp;&nbsp;↳ 晚到 5/10/15/20/30 分钟及以上 | — | 晚到 xx 分钟 |
| &nbsp;&nbsp;↳ 固定伴学课 | 仅**初中系统班**及**上海数学六年级沪教版**展示 | 固定伴学课 |
| 确认回放 | 选择「确认回放」→ 选择星期 | 周x回放（周一～周日） |
| 请假 | 选择「请假」 | 已请假 |
| 待确认 | 课程无任何操作 | 待确认 |

> ⚠️ 所有操作**只针对未到上课时间的课程**可点；辅导课和考试**不支持请假**。

### 2.2 带班表工具栏「标记为」

带班表工具栏的「到课确认」批量操作已整合至**「标记为」**入口：

**标记为 → 标签**：批量给学生添加 / 取消标签（标签管理在选项下方，可增删编辑）

**标记为 → 到课确认**：

| 批量操作项 | 子选项 |
|---|---|
| 确认到课 | 预期到课 / 晚到 5/10/15/20/30 分钟及以上 / 固定伴学课（仅初中/沪教6年级） |
| 确认回放 | 周一～周日回放 |
| 请假 | — |

> ⚠️ 同时选中 2 节课程时，「到课确认」选项**不展示**。批量操作若有课程已有标记，执行前会弹窗提示「此操作将覆盖课程已有的状态标签，确定继续吗？」

### 2.3 到课情况修改时机

- **课程开始前**：可修改到课情况
- **课程开始后**：无法再进行修改

## 三、「到课沟通列」汇总展示规则

> 以下展示规则为**并集**展示，符合多个条件时，同时展示多个标签。

| 用户课程情况 | 列标签展示 |
|---|---|
| 所有课程均为「预期到课」 | 全部到课 |
| 存在课程为「预期到课」（非全部） | 部分到课 |
| 所有课程均为「晚到 xx 分钟」 | 全部晚到 |
| 存在课程为「晚到 xx 分钟」（非全部） | 部分晚到 |
| 所有课程均为「固定伴学课」 | 全部伴学课 |
| 存在课程为「固定伴学课」（非全部） | 部分伴学课 |
| 所有课程均为「确认回放」 | 全部回放 |
| 存在课程为「确认回放」（非全部） | 部分回放 |
| 存在课程为「请假」 | 有请假 |
| 所有课程均未操作 | 待确认 |

**筛选项：**

| 筛选维度 | 选项 |
|---|---|
| 猿辅导其他班课 | 时间冲突 / 无冲突 |
| 是否能稳定到课 | 全部到课 / 部分到课 / 全部晚到 / 部分晚到 / 全部伴学课 / 部分伴学课 / 全部回放 / 部分回放 / 有请假 / 待确认 |

## 四、「到课确认列」展示规则

### 4.1 初中 / 上海沪教6年级数学

到课确认列按**两个 Tab** 展示：

**直播课 Tab 标签：**
待确认 / 预期到课 / 晚到 5/10/15/20/30 分钟及以上 / 周x回放 / 固定伴学课 / 已请假

**直播课 Tab 筛选项：**
预期到课 / 晚到 x 分钟 / 固定伴学课 / 已请假 / 临时调课 / 待确认

**回放 Tab 筛选项：**
周一～周日回放 / 待确认

**伴学课 Tab：** 与线上原逻辑一致

### 4.2 其他学段（非初中/非沪教6年级数学）

- 只展示**直播课到课确认**标签（无伴学课 Tab、无回放 Tab）
- 编辑框中**无「固定伴学课」选项**
- 筛选项与直播课 Tab 一致（无伴学课/回放筛选）

## 五、在「单次课回访」表单中编辑到课情况

> 仅支持对**未开课课程**进行修改。

**操作步骤：**

1. 查看「单次课回访」表单中的「到课确认」列；
2. 点击小铅笔，进入标签选项栏；
3. 选择并点击标签，完成到课情况修改。

## 七、到课确认链接（用户自助确认）

> 来源：[石墨文档](https://shimo.zhenguanyu.com/docs/3jMXY2pe4ezgHnmK) · 整理日期：2026-04-25

支持老师通过企微向用户发送**专属到课确认链接**，由用户自己选择要请假的课程和请假原因，减少老师逐一沟通的成本。

### 7.1 群发链接

- 在**高级群发**功能中选择「到课确认」，系统会通过企微给每位用户发送**专属链接**；
- 链接以**卡片形式**发送，可提高点击率；
- 用户填写链接收集到的数据会展示在带班表中。

### 7.2 私发链接

- 企微侧边栏新增「**发送链接**」功能，点击后直接给当前对话用户发送其**专属到课确认链接**；
- > ⚠️ 链接为该用户的专属链接，**请勿直接转发给其他用户**。

### 7.3 带班表展示——「到课沟通（只读）」列

> ⚠️ 此列需由主管在带班表配置中将**「到课沟通（只读）」**列添加进来，**替换**原「到课沟通」列。

| 用户确认状态 | 颜色 |
|---|---|
| 确认到课（含迟到） | 🟢 绿色 |
| 请假 | 🔴 红色 |
| 查看回放 | 🔵 蓝色 |
| 未确认 | ⬜ 灰色 |

- 鼠标悬停课程格可查看**上课时间**和**确认状态**；
- 点击单元格可查看**课程详情**和**请假原因**，并支持**编辑**；
- 用户请假时需选择**请假原因**。
