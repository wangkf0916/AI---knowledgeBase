## 一、功能简介

伴读闯关本质上是一节**录播课**，在配置的解锁时间解锁后，学生可进入教室，完成「**一边带读一边答题**」的闯关式答题练习。

**核心特点：**
- 屏幕上方有**闯关进度条**表示答题进度，无可手动滑动的进度条；
- 学生答题途中可退出教室，**再次进入时从上次退出进度继续**作答；
- 完成后再次进入教室，仅展示**作答战绩页面**；
- 有**专属课程报告**，供学生观看课中错题视频讲解。

**互斥限制：**
伴读闯关与以下课程类型**互斥**，不可同时选择：
- 刷题课
- 个性化练习课
- 主讲带练课
- 小程序录课（不支持）

## 三、学生端详细说明

### 3.1 开场环节

学生进入教室后，有主讲老师打招呼的**开场环节**，介绍本节课涉及的材料名称和阅读内容（由老师在建教案时配置）。学生点击「**准备好了**」，进入正式环节。

### 3.2 正式作答环节

- 屏幕上方显示**闯关进度条**，段数为教案中配置的题目数；
- 学生无论答对/答错，**进度条均前进一格**，并观看当前题目的**题后讲解**，后可继续作答；
- 老师发起测验至学生提交题目期间，**老师窗口关闭**，学生沉浸式作答；
- 所有题目作答完成后，推送一道**宝藏题**（跟读题不可作为宝藏题）；
- 若未配置宝藏题，则最后环节结束后直接展示成绩页。

> ⚠️ 老师录制题后讲解时，不要出现"你真棒"、"不要灰心哦"等针对对错的话术，因为所有学生（无论对错）都会看到相同讲解。

### 3.3 金币奖励规则

**有激励课程：**

| 题目类型 | 结果 | 金币 |
|---|---|---|
| 普通互动题 | 答对 | **15 金币** |
| 普通互动题 | 答错 | 0 |
| 宝藏题 | 答对 | **20 金币** |
| 宝藏题 | 答错 | 0 |
| 跟读题 | 0 星 | 1 金币 |
| 跟读题 | 1 星 | 3 金币 |
| 跟读题 | 2 星 | 4 金币 |
| 跟读题 | 3 星 | 5 金币 |

**无激励课程：** 所有题目答对/答错均不得金币。

### 3.4 课程完成

- 课程完成后展示**本节课作答战绩**；
- 伴读闯关只能顺次观看一遍（可分多次完成）；
- 完成后再次进入教室，仅展示作答战绩页面；
- 专属课程报告支持学生**观看课中错题视频讲解**。

## 四、老师端详细说明

### 4.1 如何建课

1. 在 Amaze 后台建课时，在课程信息「伴读闯关」字段选择「**有**」；
2. 「时长」字段会在学生端显示；
3. 课程有**解锁时间**，支持老师在「开设课程并备课后——学生端解锁前」这段时间内完成录课。

### 4.2 建教案（Muse 配置）

配置阅读材料信息：
- **材料名称**：学生开场环节展示；
- **阅读内容**：学生开场环节展示。

**教案结构（必须按以下模块配置）：**

| 模块 | 是否必配 | 说明 |
|---|---|---|
| 默认模块 1：开场环节 | **必配** | — |
| 互动题模块 | 可配 | 每个模块里必须有且只有 1 道互动题 / 跟读 / 趣味互动 / 拍照互动 |
| 宝藏题模块 | 可配 | 其中有且只有 1 道互动题 |
| 默认模块 2：收尾环节 | **必配** | — |

**配置限制：**
- 互动题：不得添加「连续多道脚本的定制题 / 通用题中的连续多道 / 游戏题里的连续多道」；
- 其它课件页：不支持少儿互动课件中的**进出门测**和**连续测**。

### 4.3 如何录课

录课端会自动按教案配置的模块生成对应的**录制节点**，老师需**顺次录制**所有节点，不能跳节点录制。

**录课前：**
- 自动检查课件是否为最新版本及规范配置，未规范则需根据弹窗提示更新；
- 其他逻辑同普通录播课。

**录课中——状态说明：**

| 状态 | 录制进度文案 |
|---|---|
| 进教室未开始录制 | 「未开始录制」 |
| 录制某节点中 | 「正在录制"节点名称"」 |
| 录制完 ≥1 个节点后等待 | 「本节课已录制 x 个节点，待录制 y 个节点」 |

**录制节点规则：**
- 每个节点只能从**当前节点第一页**开始录制，开始时有二次确认弹窗；
- 录制中可在**本节点范围内**自由翻页，不可跨节点；
- 每个节点录制完成后及互动题发起测验至结束测验期间的内容**不会被录制**（老师窗口关闭）；
- 结束测验后有**缓冲时间**，以保证分割间隔点录制的连贯性。

**操作按钮：**

| 操作 | 说明 |
|---|---|
| 开始录制 | 开始当前节点录制（需在节点第一页） |
| 暂停重录本节 | 清空本节已录内容，回到节点首页重录 |
| 继续录制 | 完成一节后，在新节点首页点击继续 |
| 完成本节录制 | 非最后节点：翻至下节第一页；最后节点：完成录制并退出（有互动题未发起测验时不可完成） |

**非录制状态：** 除翻页器外所有区域置灰不可用；翻页器可用（可在当前节点内翻页查看缩略图）。

**录制状态：** 「本页板书」功能**不可用**。

### 4.4 录课后——重新录制

与普通录播课相同：在课程录制列表的「已录制」Tab 找到对应课程，选择**重新录制**。

> ⚠️ 重新录制会**清空该课程所有已录内容**，并创建新的录播教室，同时自动从 Muse 后台拉取最新教案。

### 4.5 录课后——看课（管理员端）

- 回放 Tab 中展示「日期」「时段」，对应**最后一次录制完成的时间**；
- 每次在老师 iPad 端重新录制，会重新生成新的课程回放，管理员端同步更新；
- 管理员端内容为**所有录制内容的平铺**（UI 同普通录播课），不会根据作答情况跳转。

### 4.6 课程报告配置入口

目前仅在以下位置展示入口：
- **Amaze 后台**
- **主讲工作台**的备课详情页
