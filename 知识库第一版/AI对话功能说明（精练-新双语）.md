## 一、背景

校内课改后对英语口语越来越重视，双语用户提升口语的诉求排名第二。历史功能已有纠音、跟读练习，但缺少让学生**主动输出**的练习环节，学生存在"只会跟着念、不理解用法、不能回答问题"的情况。

本功能通过 **AI 带练场景对话**的方式提升学生口语水平，在精练场景下复用 AI 对话练习的底层能力。

## 三、学生端功能说明

### 3.1 入口

有系统班的用户，在**精练 tab** 可看到此功能入口。

### 3.2 环节开始页

- 列出本次学习的知识点（可能包含词汇和句型，也可能仅有其中一种）；
- 点击【开始练习】后进入正式对话。

### 3.3 对话过程

- AI 人物向学生提出**跟读题、半开放问题或开放问题**；
- 题目顺序和图片个数不固定，根据老师后台配置显示；
- 学生点击音频按钮录音作答，AI 人物根据作答结果进行**反馈、讲解和追问**。

### 3.4 报告

- 全部对话完成后展示报告；
- 报告内容包括：整体评星、开口次数等数据 + 完整对话记录；
- 用户可点击报告上的音频回顾对话；
- **环节过期前支持无限次重复练习**，点击【再练一次】重练，重复后报告刷新。

### 3.5 星级评分标准

**计分规则：**
- 提问不参与分数计算；
- 跟读题得分 = 语音打分的分数；
- 开放 / 半开放问题：完全正确 = 100 分，有错误 = 50 分；
- backup 问题：回答 yes / no 均算正确，得 100 分；
- 最终得分 = 所有计分题总分 ÷ 计分题数量。

**星级对应：**

| 星级 | 分数区间 |
|---|---|
| 1 星 | [0, 40) |
| 2 星 | [40, 70) |
| 3 星 | [70, 100] |

## 四、Cyber 配置说明

**配置入口：** [Cyber - 拓展训练 - AI 对话（小学英语）](https://cyber.zhenguanyu.com/#/expansion-training/ai-conversation?phase=xiaoxue&subjectId=3&selected=1)

路径：小学英语 → 「拓展训练」tab → 「AI 对话」模块

### Step 1：创建新对话

选择对应年级后，点击「+ 新建 AI 对话」按钮创建新对话。

### Step 2：配置对话内容

**对话主题：**

| 配置项 | 要求 |
|---|---|
| 封面图 | 宽高比 4:3，支持 .png / .jpg，不超过 1M |
| 标题 | 不超过 60 字符（30 汉字），必填 |
| 副标题 | 不超过 30 字符（15 汉字），必填 |

**对话内容：**

| 配置项 | 说明 |
|---|---|
| 题目评分标准 | 可选 L0 / L1 / L2 / L3 / L4 / L5 / L6，不同年级对应不同评分标准 |
| 对话背景 | 可选：教室 / 操场 / 客厅 / 学校门口 / 动物园 / 城市街道 / 沙滩 / 森林 / 商场 / 餐厅 |
| 对话开场白 | 必填，不能为空 |

**添加题目（点击「+ 添加题目」）：**

支持 4 种题型，每种题型上限 **10 道**，至少配置 1 道题目（题型不限）。

**① 单词跟读题 / 句子跟读题（配置项相同）：**

| 配置项 | 要求 |
|---|---|
| 引导语 | 必填 |
| 跟读文本 | 必填 |
| 图片（选填） | 4:3，支持 .png / .jpg，不超过 1M |
| 知识点 | 默认 1 个，最多 3 个，必填 |

**② 半开放问题：**

| 配置项 | 要求 |
|---|---|
| 引导语 | 必填 |
| 问题 | 必填 |
| 提示（选填） | 可为空 |
| 图片（选填） | 4:3，支持 .png / .jpg，不超过 1M |
| 图片描述（选填） | 上传图片后可填 |
| 示例回答 | 必填 |
| 知识点 | 默认 1 个，最多 3 个，必填 |

**③ 开放问题：**

| 配置项 | 要求 |
|---|---|
| 引导语 | 必填 |
| 问题 | 必填 |
| 提示（选填） | 可为空 |
| 图片（选填） | 4:3，支持 .png / .jpg，不超过 1M |
| 图片描述（选填） | 上传图片后可填，仅支持英文、数字和半角符号 |
| 示例回答 | 必填 |
| backup 问题 | 必填 |
| backup 示例回答 1 / 2 | 仅当图片为空时显示，必填 |
| 知识点 | 默认 1 个，最多 3 个，必填 |

### Step 3：APP 内预览

- 保存后，对话默认为「**未发布**」状态；
- 点击「预览」按钮，输入手机号获取预览资格，5 分钟后登录 App 查看，**24 小时内有效**；

> ⚠️ 内容修改后需更换手机号重新预览，同一手机号无法获取最新版本。

- 输入手机号错误或该号未注册猿辅导 App，则预览资格获取失败；
- 对话**发布后不可再预览**，「预览」按钮变为不可点击态。

### Step 4：发布对话

- 预览无误后，点击「发布」按钮正式发布；
- 发布后内容修改会**实时同步到 App**，无需手动更新；
- 发布后可直接在 App 查看正式版。

**其他：**
同一 Level 内，支持通过关键字（对话 ID 或名称）、发布状态、创建人筛选对话。
