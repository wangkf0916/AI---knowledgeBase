## 一、功能概览

**AI 词文串烧**是 L2 阶段用户在英语 AI 学练通中，每周**阅读课 Day 4** 的环节。定位是在 **AI 生成的个性化小故事**中，复习本周掌握不牢固的单词（每位用户的易错词不同，生成内容不同）。

**主要流程：**

```
知识回顾 → AI 小故事练习（拖拽 + 跟读）→ 选择标题 → 完成页 → 报告页
```

## 二、具体功能说明

### 2.1 环节说明 & 加载页

- 环节说明页动效播放完后，跳转「AI 小故事生成中」加载页；
- 此处使用**大模型实时生成**练习文章，**加载 30 秒内为正常现象**；
- 加载完成后自动进入知识回顾环节。

### 2.2 知识回顾

**目标：** 再次复习易错词。

**复习内容分类：**
- **易错词**：学习环节中答错的词；
- **巩固词**：做对但分数不够高的词（用于补全至 5 个词）。

每个单词提供**释义 + 示范音频**。

**交互流程：**
1. 进入时 AIX 语音自动播放；
2. 自动播放单词英文发音，用户记忆发音和含义；
3. 再次点击音频按钮可重播；
4. 音频播放期间「下一个单词」按钮置灰；
5. 播放完后可点击跳转下一词；
6. 全部完成后按钮变为「学会了，开始练习」，点击进入 AI 小故事练习。

### 2.3 AI 小故事练习

使用大模型**个性化生成**包含 5 个复习词的对话文章，人物固定为 Matt 和 Wendy。

**左侧：** AI 生成的对话（5个词被挖空，分布在不同页面）
**右侧：** 需要复习的 5 个词语（用于补全对话）

每个单词的作答分两步：

**① 拖拽补全对话：**
- 将词语拖拽到对应空格；
- 拖拽正确：动效展示 + 进入单词跟读 + **3 香蕉奖励**；
- 拖拽错误：直接弹回。

**② 单词跟读：**

| 跟读结果 | 后续操作 |
|---|---|
| 一次跟读 3 星 | 直接自动过题 |
| 一次跟读 ＜3 星 | 强制二次跟读（二次结果无论如何均过题） |

跟读香蕉奖励（按最后一次评星）：

| 星级 | 香蕉 |
|---|---|
| 3 星 | **5 个** |
| 2 星 | 3 个 |
| 1 星 | 1 个 |
| 0 星 | 0 个 |

**页面辅助功能：**
- **翻译对话**：点击查看全文中文翻译；
- **长按句子**：翻译为中文（含挖空单词），松手恢复英文；
- **翻页按钮**：可左右翻页查看上下文（未作答完当页也可翻页）；
- **播放音频**：无挖空的页面自动播放；有挖空的页面挖空部分高亮后可点击播放（音频包含挖空单词）；作答正确后自动播放音频。

### 2.4 选择标题

所有单词作答完成后，进入**选择标题**环节：
- 点击选项即作答，错误时标记提示，需重新选择；
- 选择正确后点击「生成故事卡」进入完成页。

### 2.5 完成页

**一轮练习（仅一轮）：** 仅展示，展示后自动进入报告页。

**两轮练习：**
- 第二轮仅进行「单词记忆 + 对话练习（拖拽 + 跟读）」；
- 不重复标题选择和生成新故事卡；
- 完成后直接进入报告页；
- **补充奖励**：第二轮练习完成额外获得 **20 香蕉**。

### 2.6 报告页

| 展示内容 | 说明 |
|---|---|
| 左侧 | 评星 + 作答后的专属小故事卡片 |
| 右侧 | 本课收获（已掌握 / 仍需巩固的词）；拖拽和跟读全对才判定为「已掌握」 |
| 查看全文 | 点击小故事卡片可查看 |
| 翻译对话 | 效果同环节内翻译 |
| 保存图片 | 点击可保存小故事图片 |
