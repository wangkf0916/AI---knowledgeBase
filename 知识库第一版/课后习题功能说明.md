## 一、功能概述

课后习题完成后，学生可进行两种后续学习环节：

| 功能 | 触发条件 | 适用范围 |
|---|---|---|
| **错题订正** | 首次提交习题后有错题 | 小学数学 3-6 年级系统班、初中数学系统班 |
| **拓展练习** | 课后习题批改完出成绩后 | 小数课（小学数学） |

## 二、错题订正

### 2.1 功能说明

学生首次提交课后习题后收到报告，若有错题则有**一次订正机会**。辅导老师 iPad 端可再次批改订正题目，Focus 工作台可查看订正数据。

### 2.2 iPad 老师端批改

**入口：** iPad 老师端 → 右上角「…」→「批改」→ 待批改列表 → 本节课的批改任务卡片

**卡片结构：** 本节课的批改任务分为两部分：

| 部分 | 说明 |
|---|---|
| **习题批改** | 首次提交的课后习题 |
| **订正批改** | 学生订正后的题目 |

点击「习题」或「订正」下的数字，跳转到对应任务开始批改。

> ℹ️ 卡片内「共 N 人提交，M 人已收到报告」为**课后习题**的提交人数和习题报告发送人数，**非**订正提交信息。

**批改操作：**
- 整体页面与课后习题批改无明显区别；
- 订正题目会在题目名上增加**【订正】**标识；
- 右上角「学生姓名」可切换学生，同时可切换「习题」/「订正」下的学生；
- **自动切换**：批改完「习题」下所有待批改题目时，自动切换至「订正」，反之亦然；
- 订正题目的作答情况：只展示学生提交的订正题目作答情况。

**批改注意事项：**
- 需要订正的题目，第一次习题报告**不会给学生展示解析**，以便学生独立订正；
- 希望对需订正的题目**添加语音批语和详细标注批语**，帮助学生明确解题思路；
- 学生做错的习题提交批改时，若未添加语音批语，**系统会弹出提示**。

**报告发送：** 批改后，报告也分为「习题报告」和「订正报告」两部分，需老师及时各自发送。

### 2.3 Focus 工作台

**分层回访（单次课数据）：**
可结合「习题完成情况」和「错题订正完成情况」组合筛选需要关注的学生。

| 情况 | 订正状态 |
|---|---|
| 习题满分 | 显示「无需订正」 |
| 习题未批改完成 | 显示「无需订正」 |
| 习题批改完成且不满分 | 需要订正（含系统批改和老师手动批改） |

**学生详情页（知识点掌握情况）：**
- 每个习题之间用竖线分割；
- 批改完成的错题会显示在对应习题右侧的括号里；
- 订正错题正确率 = 订正中回答正确的题目数 ÷ 需订正的题目总数；
- 订正结果**不影响**习题本来的得分和正确率；
- 订正可以获得金币，可在金币详情中查看；
- 点击作答结果可查看错题订正详情，点击「批改详情」可在批改页面查看批改情况。

### 2.4 学生端

**金币奖励：**

| 行为 | 金币 |
|---|---|
| 完成课后习题 | **+30 金币** |
| 习题满分 | **+30 金币** |
| 有错题并完成订正 | **+15 金币** |
| 打卡到微信群（如有） | **+5 金币** |

**打卡功能：**
- 学生完成后可微信打卡，分享海报到学习群（类似预习打卡）；
- 订正期间**没有打卡按钮**；
- 若订正前未打卡，订正完成后可继续打卡。

**适用范围（订正 + 打卡）：** 小学数学 3-6 年级系统班、初中数学系统班。其他班型、学科、年级的课后习题**不可订正，也没有打卡功能**。

## 三、拓展练习

### 3.1 功能说明

拓展练习是小数课后的新学习环节，针对学生的作业答题情况**个性化推题**：
- 作业题**做对** → 推同知识点**难题**（标签：重难点拓展题）；
- 作业题**做错** → 推同知识点**简单题**（标签：错题同类题）。

题目顺序、知识点、数量与作业保持一致，仅**难度不同**。

> ℹ️ 目前仅支持客观题（普通习题），**不支持少儿互动题**，系统自动批改，无需老师手动批改。

### 3.2 版本要求

| 客户端 | 最低版本 |
|---|---|
| iOS & Android | 7.17.0 |
| Mac | 1.28.0 |
| PC | 6.28.0 |

### 3.3 开放时机

| 习题类型 | 开放条件 |
|---|---|
| 全客观题 | 学生提交后系统立刻批改，**立即开放** |
| 含主观题 | 辅导老师**手动批改完并发送报告**后开放 |

### 3.4 逾期说明

| 场景 | 逾期时间 | 逾期后表现 |
|---|---|---|
| 拓展练习自身逾期（长学季） | 开放后 **7 天**（168h） | 可查看知识点和题目解析 |
| 拓展练习自身逾期（短学季） | 开放后 **1 天**（24h） | 可查看知识点和题目解析 |
| 课后习题未完成导致逾期 | 随课后习题一同逾期 | **无法**查看知识点和题目解析，拓展练习不生成 |

### 3.5 学生端体验

**入口：** 课后习题之后，单独的学习任务（首次进入有欢迎页）

**作答页：**
- 每道题目前展示题目标签（重难点拓展题 / 错题同类题）；
- 支持翻译对话（查看解析）。

**报告页：**
- 展示：正确率、作答时长；
- 知识点（取决于教研配置，仅精品考点树的题目才展示关联知识点名称，不展示详细解释）；
- 点击「作答情况」可查看解析；
- 解析页与作业解析页相同，增加「考查知识点」模块。

**金币奖励：**

| 行为 | 金币 |
|---|---|
| 完成拓展练习 | **+30 金币** |
| 全部答对 | **+10 金币** |

> ℹ️ 拓展练习**不支持打卡**。

### 3.6 Focus 回访

- 在我的小班列表和学生详情页可查看学生拓展练习作答情况；
- 点击拓展练习得分 → 弹出拓展练习抽屉，可查看具体题目作答情况，并复制回访图片；
- 支持制作**拓展练习表扬榜**：榜单制作页 → 单次课榜单 → 表扬榜 → 类型选择「拓展练习完成」。

### 3.7 后台配置（Amaze + Cyber）

**Amaze 开启拓展练习（教务运营）：**
开启后，教研老师可在课程设计中，课后习题下方找到「拓展练习」栏目。

**Cyber 题目录入（教研老师）：**
1. 点击「生成」开始配置；
2. 对每道课后习题点击「生成题目」，配置正答或误答拓展题目；
3. 系统按规则从精品题库中随机匹配题目；
4. 可点击「重新随机」重新选取；若系统找不到题或对所有题不满意，可点击「指定题目」人工选取；
5. 配置完全部正答和误答题目后，点击「保存」。

> ⚠️ 有新布置的课后习题时，需**同步补充布置拓展练习**，否则题目不完整，会触发系统预警。

### 3.8 Q&A

| 问题 | 解答 |
|---|---|
| 拓展练习何时开放？ | 习题批改完出成绩后系统自动开放（客观题提交即开放，主观题需老师批改后开放） |
| 学生客户端看不到拓展练习入口？ | 确认客户端版本是否达到最低要求（见 3.2） |
| 拓展练习需要老师批改吗？ | 不需要，系统自动批改，立即出结果 |
| 班主任账号登录学生端可体验拓展练习吗？ | 不可以，班主任视角不展示拓展练习入口 |

## 四、题目讲解视频

> 来源：[石墨文档](https://shimo.zhenguanyu.com/docs/G8RdRWJQTHQJTJjP) · PRD：[普通习题](https://confluence.zhenguanyu.com/pages/viewpage.action?pageId=100292537) · [互动题](https://confluence.zhenguanyu.com/pages/viewpage.action?pageId=79261567)

### 4.1 功能概述

课后习题分为**普通习题**和**少儿互动题**两类，两类题目均支持展示**题目讲解视频**。

学生完成习题后，在题目解析页可查看对应的讲解视频（点击即可播放）。

### 4.2 学生端展示条件

学生能看到讲解视频，需同时满足以下 **3 个条件**：

| 条件 | 说明 |
|---|---|
| ① 客户端版本达标 | 猿辅导 App ≥ 7.20.0 · Windows 猿辅导 ≥ 6.31.0 · Mac 猿辅导 ≥ 1.31.0 |
| ② 老师已录制上传 | 主讲老师已为该题录制并上传讲解视频（参见[主讲老师端-讲解视频录制.md](./主讲老师端-讲解视频录制.md)） |
| ③ 配置开启展示 | 配置习题时勾选「展示讲解视频」（**互动题有此配置，普通习题无需配置**） |

### 4.3 查看入口与时机

**通用规则：**
完成所有题目 → 所有题目批改完成 → 进入习题结果页（分数页）→ 点击查看某题解析 → 解析页可见讲解视频。

**3-6 年级（有订正流程）：**

| 题目状态 | 能否看到讲解视频 |
|---|---|
| 首次提交**答对**的题目 | ✅ 可以 |
| 首次提交**答错**且**未订正** | ❌ 不可以 |
| 答错题目**订正完成后** | ✅ 可以（在订正完成后查看解析时展示） |

### 4.4 各端支持情况

| 端 | 支持 |
|---|---|
| Android 手机 / iPhone | ✅ |
| iPad | ✅ |
| Windows 电脑 | ✅（≥ 6.31.0） |
| Mac 电脑 | ✅（≥ 1.31.0） |
