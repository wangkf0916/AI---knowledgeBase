## 一、功能简介

在英语直播课堂（小组教室）中，主讲老师发起「**小小演说家**」教学活动：

- 在小班范围内自动分为**每组 3 人**的小组；
- 每人依次复述**一页**课件内容，共同完成整个活动；
- 活动结束后，系统对学生发言内容进行三个维度的 AI 打分，以**评星**方式呈现综合得分；
- 不同评星对应不同金币奖励。

**AI 打分维度：**

| 维度 | 说明 |
|---|---|
| 内容完整度 | 复述内容是否覆盖要点 |
| 发音准确度 | 英语发音是否标准 |
| 表达流利度 | 语言表达是否流畅 |

**金币奖励：**

| 评星 | 金币 |
|---|---|
| 0 星 | 0 金币 |
| 1 星 | 5 金币 |
| 2 星 | 10 金币 |
| 3 星 | 15 金币 |

> ℹ️ 成绩达到三颗星，才可以获得奖项（称号等）。

## 三、学生端流程

1. 老师发起练习后，学生进入练习；
2. 正式进入后，**开场引导**告知本人是第几个发言；
3. **轮到本人发言时**：对照课件页面进行英文复述；
4. **轮到同学发言时**：可以对同学进行**点赞鼓励**；
5. 所有同学发言结束后，依次展示**个人成绩**和**小组成绩**的打分反馈（评星）；
6. 达到三颗星方可获得奖项。

---

## 四、主讲老师端操作

1. 翻到配置了练习活动的课件页时，点击「**开始练习**」按钮发起活动；
2. 练习进行中，屏幕左上角会**随机展示一组同学的实时情况**；
3. **注意**：正在练习的学生听不到老师发言，学生完成练习后才能恢复听老师声音；
4. 点击「**结束练习**」后，活动结束，学生端自动进入颁发榜单流程。

## 五、辅导老师跟课端

活动进行中，跟课端仅展示一个弹窗说明当前状态，不参与活动流程。

## 六、后台配置

### 6.1 Amaze 建课配置

**支持配置范围：**
- 学段：小学；学科：英语 / 英文阅读表达；课程类型：直播课；班课类型：系统班

**配置校验规则：**
1. 只有「分组教室」配置为「是」之后，「小小演说家」才能配置为「是」；
2. 「小小演说家」配置为「是」后，激励**只能选「是」且自动置灰，不可更改**。

### 6.2 Muse / Cyber 课件内容配置

**两个新建入口：**
- **Cyber**：资源库 → 「对话与配音」模块 → 点击「新建」→ 选择「小小演说家」
- **Muse**：任意页面 → 课堂活动操作区 → 点击「小小演说家」→ 选择「新建」或「选用已有」

> ⚠️ 若课件内无创建入口，请检查该课程是否在 Amaze 中配置了小小演说家；灰度阶段需联系产研为课程配置灰度。

**新建小小演说家（弹窗内三个模块）：**

| 模块 | 说明 | 是否展示给学生 |
|---|---|---|
| **名称** | 用于后续检索，不展示给学生 | 否 |
| **封面图** | 活动开始前和结束后的封面，宽高比 4:3 | 是 |
| **内容** | 每页的配图 + 复述文本等 | 是 |

**内容页配置（每页）：**
- 点击「添加配图页」新增活动页，**页数至少为 3 页**（保证每组 3 人各有一页）；
- 每页需填写：
  - **配图**：尺寸 1443×630；
  - **示范音频**：学生未开口时自动播放；
  - **建议复述时长**：必须 > 示范音频时长 + 6 秒；
  - **复述文本**：纯英文文本；填写后可点击「使用 TTS 预设配置生成音频」自动生成两段补位机器人音频。

**编辑已有小小演说家：**
> ⚠️ 修改某个小小演说家内容后，**所有用到该活动的课件均会同步更新**。

**在课件中选用已有小小演说家：**
- 课件页右上角 → 「小小演说家 - 选中已有小小演说家」→ 在弹窗中检索（支持新建人、ID、关键字）→ 选中后点击「确定」插入；
- 支持点击标签预览详情，支持「移除」当前页绑定的活动；
- 点击橙色 ID 可跳转详情页修改。

## 七、Focus 工作台（辅导老师）

| 功能 | 说明 |
|---|---|
| **带班表数据** | 查看小小演说家当堂课环节内的最高得分和发言详情 |
| **排序 / 筛选** | 支持按得分排序、区间筛选；支持筛选获得称号的用户 |
| **参与详情** | 多次参与时按时间正序展示，列表中显示每次评级，点击展开查看表现详情 |
| **音频试听** | 支持试听示范音频和用户录制的发言音频 |
