## 一、项目简介

小组教室是有别于目前线上教室的一种新教室形态，核心区别有两点：

### 分小组上课
- 学生不再能看到整个小班的学生，只能看到同小组学生（**一组最多 5 人**）
- 学生可以看到更多信息：是否在线、作答情况、真实头像（签到时拍照）

### 双向视频
- 学生开启视频后，可在课上实时看到自己的视频和老师的视频
- 主讲老师可在课上轮循随机订阅部分学生视频，每次可看 4 位
- 辅导老师：旧版本一次最多看 1 位；**新版本可同时看到 8 位**学生视频

### 项目目的
- 培养小低年级学生良好学习习惯
- 给学生提供更加纯粹的学习环境，辅助提升上课专注度
- 提高老师们对学生听课状态的掌控能力（监管、表扬、发现新问题）

### 机器人补位机制

| 条件 | 规则 |
|---|---|
| 触发时机 | 上课 **15 分钟后** |
| 触发条件 | 小组内真实用户数量 **= 1** |
| 不触发条件 | 小组内真实用户数量 **> 1** |
| 效果 | 系统向该小组补入机器人，避免学生完全独自上课 |

> ℹ️ 机器人在**点名发言**环节不会被点中；在**思辨说（分组表达）**中，人数不足时也会用机器人补齐4人小组。

## 三、各端功能详情

### 学生端

**课前签到流程：**
1. 进入教室前需授权开启相机权限
2. 开启权限后可拍一张照片签到（签到 +10 枚金币），照片作为本节课的小组头像
3. 如不满意可重拍；如不想拍照可点击「不拍照，仅签到」
4. 签到后系统自动分组，分组成功后进入教室
5. 若来迟（课程已开始），跳过签到和分组直接进入教室

**上课中功能：**
- 发言气泡：学生发言 4s 消失，辅导老师发言 6s 后消失
- 支持 3 种动态小猿标签表情
- 小组全员答对题目时，所有成员展示「全员答对」动效
- 支持小组积分大比拼，每次作答后更新排行
- 结算全勤后：揭晓最终获胜小组，为获胜小组颁奖，鼓励未获胜小组

### 主讲老师端

- **自动随机**：每 30s 自动切换 4 位同学展示在老师端
- **手动随机**：每点击一次，重新展示 4 位同学视频
- 结算全勤后可为获胜小组颁奖、鼓励未获胜小组
- 一键鼓励功能

### 辅导老师（跟课端）

- 点开学生详情后可查看该学生的实时视频画面
- 学生讨论区发言分类精确到「小班 → 小组」维度
- 支持视频沟通功能：学生摄像头打开时，辅导老师可与学生进行真正的视频沟通

> ⚠️ 班主任老师在小组教室中，每次发送的话术字数**不能超过 35 个字**

### 4. 辅导老师查看走神学生 & 发私信（已全量）

**功能说明：**
- 辅导老师端可实时看到班里此刻没有认真听课的学生视频画面
- 支持辅导老师给学生发私信，提醒学生认真听课

**识别原理：**
- 每 15 帧做一次识别，以 60 帧作为一个检测周期
- 检测人眼睛闭合度：连续 60 次内闭合度 < 20% 的次数超过 40 次 → 学生困倦，判为不专注
- 检测学生是否在看屏幕：连续 60 次内超过 30 次检测不到人脸，或头部旋转角过大超过 30 次 → 判为不专注

**跟课端新功能（持续更新 2021.1.26）：**
- 新增「可能走神」选项，智能筛选当前时刻可能不认真听课的学生
- 老师可点击视频右下角移除按钮将学生移出走神列表（需选择理由）
- 支持辅导老师向学生发送私信：在学生视频/姓名展示区右键 → 选择「发私信」→ 编辑后发送

**推荐用法：**
- 私信：用于「批评」或「单独提醒」某个学生（只有该学生可收到）
- 公开表扬：建议艾特某个小组，或在小班范围内表扬

**上线节奏：**
- 小范围灰度：11.13 ～ 11.29（无需报名，逐步开量覆盖）
- 预计全量：11.30

## 七、小组间 PK 排行榜（产品规格）

> 来源：小组教室-小组间PK排行榜9-6.pdf，版本 9-6，2020.04.29

### 背景与目标

**问题：**
1. 家长和学生并没有对小组形成概念，觉得分组和不分组没有太大区别
2. 目前的小组教室缺少除金币外的外部激励因素，学生少了围绕竞争产生的外部驱动力

**方案：**
- 新增小组间 PK 排名机制，在课上得金币的环节（除签到外），均展示小组 PK 排名并累积小组积分
- 最终公布单次课程的小组积分排名

### PK 规则详解

**统计范围：** 全勤 + 所有可获得金币的课堂活动（目前包含互动题，不包括少儿互动课的互动题）

**每轮活动达成率计算：**

| 活动类型 | 计算公式 |
|---|---|
| 互动题正确率 | 小组内本道题答对人数 ÷ 当前小组人数（含不在线） |
| 小组全勤率 | 小组全勤人数 ÷ 当前小组人数（含不在线） |

> - 答对定义：手动模式作答正确；辅助判断模式：3/4、0/-5 和 12/2 都算对
> - 四舍五入精确到整数位，超过 100% 按 100% 计算
> - 小组人数包括假学生

**每轮排名规则：** 按各小组活动达成率百分比排名；出现并列时优先展示本组，其他并列小组按组序顺序排列

**积分规则（同目前班级积分规则）：**

| 排名 | 获得积分 |
|---|---|
| 第 1 名 | 5 分 |
| 第 2 名 | 3 分 |
| 第 3 名 | 2 分 |
| 第 3 名之后（达成率 > 0） | 1 分 |
| 活动达成率 = 0 | 0 分 |

> 当第一名出现并列时：第二名轮空，实际第二名变为第三名，其他名次依次后移
> 示例：5,5,2,2,1,1 / 5,3,3,1,1,1 / 5,5,5,2,1,1 / 5,3,2,2,2,2 / 5,0,0,0,0,0

**最终 PK 结果：** 结算全勤后，根据 PK 组内各小组最终积分排名，产生最终获胜小组

**「小组 PK 分组」规则：**
- PK 单元容量：跟随班容适配，本期规定为 **6 组**，前端需可适配 5 组或 6 组
- 分组规则举例（以 PK 组容量 = 6 为例）：
  - 学习小组序号在 1-6 组之间 → 进入教室展示 1-6 组作为其 PK 组
  - 学习小组序号在 7-12 组之间 → 进入教室展示 7-12 组作为其 PK 组
  - 以此类推

**假同学展示规则调整：** 复制同组第一位同学的签到、作答、全勤成绩，在该同学数据返回后，假同学同步进行数据展示，个人称号也要复制。

### 整体上课流程

#### 课前阶段
- **学生端**：进入教室后立即覆盖全局蒙层，展示弹框提示，说明小组 PK 相关内容；点击「我知道了」后蒙层消失且不再展示
- **主讲老师端**：首次进入教室时展示「小组课堂比拼」说明弹框，点击「好的」关闭，弹框不再重复出现
- **辅导老师端**：进入教室后首先展示「小组课堂大比拼」弹框说明，点击「好的」后展示所在小班所有 PK 对战小组说明

> 弹框内容：本节课上，学生将以每组为一个单元，进行多轮小组间比拼。每轮比拼结束后，根据小组表现进行排名，排名越高获得积分越多。结算全勤后，将产生排名第一的获胜小组。

#### 上课阶段
- 打铃开始瞬间：学生端 PK 说明蒙层自动消失，老师端弹框自动关闭
- **每轮课堂活动结束后**（老师点击结束瞬间）：
  1. 展示结束动画
  2. 从课件上方中部弹出本轮小组积分情况弹层（数据未返回时先转圈）
  3. 动态展示：各小组活动达成率进度条 → 百分数消失 → 出现累积积分 → 本轮积分累加至累积积分
  4. 最终按加上本轮后的累积积分重新排名，突出展示第一名
  5. 整个过程时长控制在 3-5 秒内
- 当我所在小组全员答对时，展示全屏「全员答对」动效（展示 3 秒内）

#### 结算全勤阶段
1. 老师点击「结算全勤及 MVP」前，弹框提示：结算全勤后将产生小组积分排名和 MVP，确定结算？
2. 结算成功后，展示蒙层 + 演示动画 + 文字提示（正在发放全勤奖和 MVP）
3. 全勤动画播放完毕后，学生端展示「全勤积分情况」，积分累加动效结束后直接进入最终积分排名揭晓
4. **最终排名揭晓**：展示「谁是最终获胜小组」动画 → 展示最终小组积分排名，动画过程 3 秒内

#### 颁奖阶段
- **为获胜小组颁奖**：颁奖台升起，每个小组成员挂上第一名勋章，展示信息：标题、成员头像/姓名、颁奖台、第一名勋章、组名、表扬语（大获全胜）
- **鼓励未获胜小组**：展示优秀勋章，表扬语「大家都是最棒的！」
- 老师也可随时点击「回到课件」跳过颁奖环节，学生端颁奖蒙层消失

### 异常处理

| 场景 | 处理方式 |
|---|---|
| 积分数据 3s 内无法加载 | toast 提示：网络异常，本轮小组积分排名情况暂时无法获取 |
| 结算全勤连续 2 次失败 | 弹框提示老师继续上课，不再展示获胜名单及颁奖环节 |
| 无法加载最终排名 | 弹框提示：网络异常，暂时无法加载最终获胜小组名单【回到课件】/【重试】 |
| 颁奖过程中断网重连 | 若请求已发送则学生端不受影响；若未发送则重新展示上一步 |
| 断网重连/退出重进/切换设备 | 重新连接后判断当前进度，继续展示对应环节 |

## 八、点名发言

### 功能简介

老师在直播上课时随时发起，系统在每个小组里随机抽取 1 位学生发言，组内其他学生可以点赞互动。发言最长 60 秒，老师可随时提前结束。活动期间学生无法听到老师声音。

**升级版**（新增举手发言模式）支持两种形式：
- **随机发言**：在小组内随机抽取一名同学发言，若点到的同学前 8s 无声，则随机换一个同学发言（最多一次换人机会）
- **举手发言**：发起后学生有 6s 时间举手，随后在举手学生中随机点名 1 位发言；若该小组无人举手，则随机抽取

### 功能范围

### 学生端体验

## 九、AI 拍照主观题

> 适用于 AI 教室，不支持伪直播

### 功能简介

### 课上流程（新思维含订正版）

1. **发起拍照**：老师点击课件右下角「开始作答」→ 学生端出现拍照按钮
2. **结束拍照**：参考提交率后点击「结束拍照」（二次确认），之后进行题目讲解
3. **开始点评订正**：参考批改完成率（建议达 99%-100%）后点击「开始点评并订正」
4. **展示榜单**：点击「展示榜单」，拍照订正活动结束

> 批改完成率 = 完成批改人数 / 提交人数；订正完成率 = 完成订正人数 / 在线人数

### 学生拍照说明

- 默认拍整页（新思维）/ 拍单题（语文系），可切换

- 自动框选作答内容，学生可手动调整框选范围（桌面端无自动框选）
- 拍摄要求：**字写端正、放平拍摄、拍摄清晰、作答放在引导框内，不上传人脸**

### AI 点评流程（学生侧）

1. 提交后等待批改（6-8s 识别 + 1-7s 批改）
2. 展示星级与金币：三星 10 金币 / 两星 8 金币 / 一星 5 金币 / 0 星 0 金币
3. 猿小助语音播放评语，评语中提到得分点时高亮显示
4. **新思维专属**：评语结束后 AI 根据错误步骤进行关键步骤提问，学生语音作答后 AI 总结

## 十、思辨说（分组表达）

### 功能简介

直播课上由主讲老师发起，所有学生按照 **4 人 1 组**随机分组，围绕提前设置的话题进行轮流表达、辩论，最后由 AI 对每个人表达的**流利度、准确度、丰富度**进行打分。

### 功能范围

| 阶段 | 学科 | 班课类型 | 教室类型 |
|---|---|---|---|
| 小学 | 人文博雅 | 全部（必须有激励的课程） | 大班教室 / 小组教室均支持，不支持伪直播和回放 |

### 版本要求（2022.12.26 发布）

| 端 | 最低版本 |
|---|---|
| 主讲老师 iPad | 4.13.0 |
| 学生 iOS | 7.70.0 |
| 学生 Android | 7.70.1 |
| 学生 Win | 6.76.0 |
| 学生 Mac | 1.76.0 |
| 辅导跟课端 Win | 1.76.0 |

### 开课配置

**Amaze 建课：**
- 新建直播课时选择「分组表达：是」→「激励」自动设为「是」且不可更改为「无」
- 「分组表达」字段确认后不可再修改；伪直播/录播课不支持

**Muse 配置（课件页）：**
通过「新建分组表达」或「复用已有分组表达」配置，需填写：

| 配置项 | 说明 |
|---|---|
| 话题 | 本次辩论的话题，用于主持人小猿开场播报 |
| 观点 A / B | 分别分配给红方、蓝方，注意不要带尾部标点符号 |
| 发言提示 | 给学生的答案提示，难度可自行决定 |
| 得分点 | AI 打分依据，每个得分点可填多个子得分点，命中任意一个即得分（最多 5 个） |
| 机器人发言稿 | 人数不够时机器人用，**需点击生成音频确认效果** |

### 上课流程

#### 老师端
1. 翻到配置有思辨说的课件页，点击右下角发起练习（需先结束其他进行中的活动）
2. **练习中**：默认随机旁听某个小组，可点「随机进组」切换；查看进度统计（已完成/进行中/已离线/未参与）和结果统计
3. **挑选精彩发言稿**：支持图片和文字发言稿，最多挑选 10 个；可从班主任推荐 tab 优先筛选
4. **结束练习** → 点击「展示最佳辩手榜单」或「展示精彩发言稿榜单」

#### 学生端

| 环节 | 说明 |
|---|---|
| 随机分组 | 4 人小组，红方 2 人 / 蓝方 2 人，人数不够用机器人补齐 |
| 开场引导 | 主持人小猿语音播报话题和阵营；主讲老师全程静音，学生只能看到老师视频 |
| 准备发言稿 | 共 150s，支持文本编辑（上限 100 字）或拍照上传；全组提前准备好则自动进入下个环节 |
| 轮流发言 | 顺序：红 1 → 蓝 1 → 红 2 → 蓝 2，每人最多 50s，可提前结束；机器人自动播放预设发言 |
| 自由辩论 | 按「红-蓝-红-蓝...」交替抢麦，每次上麦最多 25s；超过 10s 无人抢麦或持续超 1.5 分钟自动结束 |
| 表达反馈 | AI 对轮流发言环节打分：流利度（AI 判断）、准确度（命中得分点）、丰富度（有效发言时长） |
| 颁奖环节 | 本组最高分获「最佳辩手」称号并颁奖（可并列）；MVP 优先级 > 最佳辩手 > 答题称号 |
| 练习小结 | 展示得分、称号、金币明细（准备发言稿 +5 / 参与表达且得分不为 0 +25 / 最佳辩手 +10） |

> ⚠️ 老师发起练习时，学生不在教室或无麦克风权限则无法参加；后续加入会被分到全是机器人的假组

#### 跟课端 / 管理员端
- 辅导老师可在跟课端推荐精彩发言稿给主讲挑选
- 管理员端：所有管理员被分在同一组，数据不影响班级数据

### Focus 数据展示

- 带班表 → 单次课回访 → 分组表达列：可按用户得分排序/筛选
- 点击展开查看发言详情：表达回顾（观点/发言时长/字数）、表达小结（数据快照/称号）、发言稿、发言音频
