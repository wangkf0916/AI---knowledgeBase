## 一、背景

当前赠品系统存在诸多场景不满足业务需要、系统拓展性差等问题，因此对赠品系统进行**重构及解耦**，以满足当前业务场景，提高整体系统的拓展性和易用性。

---

## 二、赠品配置

### 2.1 赠品定义

- **赠品**：实际被赠送的礼品，可以是班课，也可以是口算 VIP、搜题 VIP；后续可拓展优惠券等。
- **赠品与规则的关系**：每一个赠品规则需维护要赠送的赠品；同一个赠品也可被多个赠品规则引用。

### 2.2 新建赠品 — 配置项说明

| 字段 | 说明 |
|---|---|
| 赠品名称 | 自定义名称 |
| 赠品类型 | **班课** 或 **权益 VIP**（口算 VIP / 搜题 VIP，需选择赠送时长） |
| 联动退赠品 | 选「是」：源订单退款后联动退赠品；选「否」：不联动 |
| 实物赠品费用扣除 | 选「是」：退款时扣除实物赠品费用（通常选「是」）；选「否」：不扣除 |
| 联动调赠品 | 选「是」：源订单调班后赠品订单联动调班；选「否」：不联动 |
| 可赠次数 | 「只赠 1 次」：该赠品最多只能被赠送一次；「无限制」：可重复赠送 |

> 赠品类型为「班课」时，还需选择具体要赠送的班课及是否关联对应规则。

---

## 三、赠品规则配置

### 3.1 赠品规则定义

- **赠品规则**：限定用户满足什么条件（用户范围、购买限制、购买时间等）才触发赠送。
- 一个赠品规则可关联多个赠品。

### 3.2 新建赠品规则 — 配置项说明

| 字段 | 说明 |
|---|---|
| 赠品规则名称 | 自定义名称 |
| 赠送方式 | 「即买即赠」或「定时赠送」（定时赠送需填写具体生效时间） |
| 用户行为 | 「购买指定班课」：用户购买班课后触发；「无行为」：用户无需动作 |
| 购买时间 | 用户在该时间范围内购买班课，方可满足规则 |
| 班课范围 | 可填写多个；可选指定合集或固定班课范围 |
| 下单限制 | 全部班课范围满足，或满足其中指定几个班课范围 |
| 可赠次数 | 「只赠 1 次」：该规则只能触发一次；「无限制」：可重复触发 |
| 目标用户 | 可指定具体的目标用户 |
| 订单渠道 | 「不限制」或「限制」（填写来源渠道，限定来源订单渠道） |
| 指定 keyfrom | 「指定」：设置赠品订单的 keyfrom；「默认」：使用默认 keyfrom |
| 是否计入绩效 | 是 / 否 |
| 赠课原因 | 填写赠课原因 |
| 购课短信 | 是否发送购课短信 |
| 赠品 | 可配置多个赠品内容 |

### 3.3 赠品规则操作

| 操作 | 条件 | 说明 |
|---|---|---|
| 编辑 | 任意状态（未开始） | 已开始的规则不可再编辑 |
| 复制 | 任意状态 | 复制赠品规则 |
| 取消 | 任务未开始 | 点击取消，取消任务 |
| 终止 | 任务已开始 | 点击终止，终止任务 |

### 3.4 到课完成触发赠课

支持用户行为选择「**达成课程指标**」，满足到课条件后自动触发赠课：

| 配置项 | 说明 |
|---|---|
| 用户行为 | 选「达成课程指标」 |
| 课程指标内容 | 班课内完课率达成 |
| 完课率定义 | 可配置完课率阈值（目前仅计算直播时间） |
| 班课范围 | 指定班课 ID 或班课范围；命中多个班课时，任意一个达成指标均算 |
| 达成条件 | 连续 N 天完课 / 任意 N 天完课 |
| 达成天数 | 配置具体 N 天 |

## 四、赠品关联配置

### 4.1 定义

在赠品支持关联调班时，通过配置**关联范围**，当赠品在该范围内时自动联动调班，提升操作效率。

### 4.2 配置方式

1. 输入赠品名称和关联调赠品 ID；
2. 配置完成后，若配置的赠品在同一关联范围内，则调班后会自动联动调班。

---

## 五、赠课规则内容

### 5.1 达成课程指标触发赠课

当用户满足一定的课程指标后，触发相应赠课：

| 配置项 | 说明 |
|---|---|
| 赠送方式 | 只可选「定时赠送」 |
| 用户行为 | 选「达成课程指标」 |
| 生效时间 | 配置触发赠课的时机 |
| 课程指标内容 | 选「班课内完课率达成」 |
| 完课定义 | 可自定义完课定义 |
| 班课范围 | 选择在哪些班课下完成课程指标才算达成 |
| 达成条件 | 任意 N 天 / 连续 N 天 |

> 触发逻辑：当用户达到相应上课条件后，触发实际赠课。

### 5.2 达成摸底测分数触发赠课

当用户满足摸底测分数条件后，触发赠课：

| 配置项 | 说明 |
|---|---|
| 赠送方式 | 即时赠送 或 定时赠送 |
| 用户行为 | 选「摸底测分数成绩」 |
| 时间范围 | 用户在该时间范围内完成测试，方触发判断 |
| 摸底测 ID | 配置基于哪个摸底测 ID 的成绩进行判断 |
| 摸底测分数范围 | 闭区间判断 |

> 触发逻辑：用户在指定摸底测 ID 下完成测试，若满足分数范围，则实时或定时触发赠课。
