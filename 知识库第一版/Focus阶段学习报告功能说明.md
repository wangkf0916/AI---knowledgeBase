## 一、功能简介

阶段学习报告是面向**长学季系统班**的阶段性学习总结工具，由主管老师按班课范围统一生成，班主任根据报告对学生进行一对一回访。

**三个核心能力：**

- **主管**：创建「班班期望」（即班主任寄语的文案模板）并生成指定班课范围内的阶段学习报告；
- **班主任**：在带班表查看已生成报告，按多维度筛选目标学生并发起回访；
- **学生**：通过微信接收报告链接，查看个人阶段学习数据与班主任寄语。

> ℹ️ **「班班期望」**是主管为自己团队创建的回访话术模板，仅在该主管个人团队下所带班课内生效，不跨团队共享。

## 二、主管操作

### 2.1 进入配置页面

打开 Focus → **「管理」→「运营计划」→「阶段学习报告」**，进入配置页面。

### 2.2 创建模板话术（班班期望）

1. 选择部门及班课范围；
2. 点击「模板话术」→「新增」，为所选班课范围创建班班期望的模板话术；
3. 已创建的话术可随时点击「编辑」修改。

> ⚠️ **必须先完成所选班课范围的模板话术创建，才可以进行阶段报告的生成！**

### 2.3 生成阶段学习报告

1. 点击「阶段报告」，选择任一已创建模板话术的班课范围；
2. 选择**课程结束范围**（时间范围），点击生成。

**生成规则说明：**

| 规则项 | 说明 |
|---|---|
| **回访轮次 & 回访次数** | 均为默认选项，依次递增；同一轮内完成三次回访后，可开启下一轮新的回访 |
| **课程数据范围** | 包含的课程数据为所选日期之前已结束的课程 |
| **报告覆盖用户范围** | 默认选项，不可手动选择；每次回访均会排除同轮内已生成报告的用户 |
| **课程数量最小限制** | 所选日期范围内，班课已结束的主课数量须满足：小数 ≥ 6 节，小语 / 小英 ≥ 3 节 |

3. 报告生成需要一点时间，生成后可在对应班课范围下查看详情，包括：
   - 当前回访轮次 & 同轮次回访次数；
   - 每次生成人数 & 未生成人数。

> ❓ **待确认**：原文未说明「一次回访」的判定标准——是辅导老师发送报告链接算完成一次回访，还是学生实际阅读了才算？这影响「已回访 N 次」的筛选逻辑，请向产品确认。

## 三、班主任操作

### 3.1 查看报告列表

报告生成后，班主任可在 **带班表 → 单次课回访** 内查看已生成报告的学生详情。

**支持按以下维度筛选目标用户：**

| 筛选维度 | 可选项 |
|---|---|
| 回访次数 | 未回访 / 已回访（N 次） |
| 报告内容明细 | 累计听课时长、答题参与率、答题正确率、金币获取数量 |
| 用户行为 | 全部阅读 / 部分阅读 / 未读 |

### 3.2 查看报告详情

点击报告详情，弹出对应用户的详细内容，支持以下操作：

| 操作 | 说明 |
|---|---|
| **复制链接 / 分享至微信** | 通过微信进行一对一回访 |
| **查看错题详情** | 查看报告覆盖课程中学生实际答错的互动题及对应知识点 |
| **编辑文案** | 修改个人报告内的班主任「寄语」，实现个性化回访内容 |

### 3.3 高级群发

**操作路径：** 带班表 → 单次课回访 → 勾选目标用户 → 高级群发 → 选择「**系统班 - 阶段学习报告、知识点推题**」→ 完成群发。

> ℹ️ 高级群发的发送限制（条数、内容类型等）参见 [Focus群发功能说明.md](./Focus群发功能说明.md)。

## 四、数据指标口径说明

> 来源：[石墨表格 — 阶段回访报告数据统计指标](https://shimo.zhenguanyu.com/sheets/DjXQyVkyCycQ3VXP/MODOC)

报告分为四大维度，各维度包含个人得分与班级平均得分，均以百分制呈现（完成度 × 100 取整）。

### 4.1 学习主动性

| 指标 | 口径 |
|---|---|
| 核心课时长 | 系统班主课（教学与练习、测评及讲解）的 Amaze 后台时间（episodeStart～episodeEnd），已开课且未删除 |
| 听课时长 | max（直播教室/直播后台运行时间，看回放时长），统计范围同上 |
| 个人课程参与度 | 听课总时长 ÷ 核心课总时长 |
| 听课时长表现得分 | 课程参与度 × 100（四舍五入取整） |
| 核心课题目数 | 核心课上老师发起测验的总题目数（含出门测、入门测、随堂测；普通习题、互动题、少儿互动题均计） |
| 学生答题数 | 核心课上学生提交过的题目数 |
| 答题参与度 | 学生答题数 ÷ 核心课题目数 |
| 答题参与表现得分 | 答题参与度 × 100（四舍五入取整） |
| **学习主动性个人得分** | 平均数（听课时长表现得分 + 答题参与表现得分） |
| 班级各平均值 | 同 lesson 下所有学生对应指标的平均值 |

### 4.2 学习习惯

| 指标 | 口径 |
|---|---|
| 课前预习完成度 | 用户完成预习次数 ÷ 系统班对应预习总次数 |
| 准时到课率 | 准时到课次数 ÷ 核心课总次数（以打上课铃为准，进入教室时间 ≤ 上课铃时间为准时） |
| 笔记完成度 | 完成笔记次数 ÷ 对应笔记总次数 |
| 课后习题完成度 | 完成习题次数 ÷ 对应习题总次数 |
| 复习动画完成度 | 完成复习动画次数 ÷ 对应总次数 |
| **学习习惯个人综合得分** | 以上各表现得分的平均值（各科目计算维度略有差异）：<br>· 小数/小语：预习 + 到课 + 笔记 + 习题<br>· 小英：预习 + 到课 + 复习动画 + 习题<br>· 初中：到课 + 习题 |
| 班级各平均值 | 同 lesson 下所有学生对应指标的平均值 |

### 4.3 能力掌握

能力标签由教研在 Cyber 后台配置，每道题最多关联 2 个能力标签，最多展示 6 个能力维度。

| 指标 | 口径 |
|---|---|
| 能力 N 表现得分 | 能力 N 关联题目中答对数 ÷ 关联总题目数 |
| **能力综合得分** | 所有能力得分的平均值 |
| 能力的良好状态 | 同 lesson 内个人能力综合得分排名前 30% 的分数线 |
| 能力的优秀状态 | 教研按年级科目划定的固定分数线 |

> ℹ️ **能力掌握计算公式（2021.4.26 更新）：** 新能力掌握值 = 学习主动性 × 50% + 学习习惯 × 30% + 旧能力掌握值 × 20%（更新原因：原公式导致分数普遍偏低）

### 4.4 知识点分析

知识点由教研在 Cyber 后台配置，每道题最多关联 1 个知识点标签。

| 指标 | 口径 |
|---|---|
| 知识点总个数 | 报告覆盖题目中关联的知识点总数 |
| 知识点待提高 | 关联题目存在**答错或未作答**的知识点 |
| 知识点已掌握 | 关联题目**全部答对**的知识点 |
| 知识点未参与 | 关联题目**全部未作答**的知识点 |
