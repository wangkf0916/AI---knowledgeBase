## 一、功能简介

模拟线下 **1v1 口语考试**场景，让 **AI 考官**与学生进行问答考试。考试结束后，调用大模型对学生回答进行多维度打分，最终给出整体评级。

**功能范围：**

| 维度 | 范围 |
|---|---|
| 学段 | 小学 |
| 学科 | 双语阅读表达 |
| 班课类型 | 系统班 |
| 教室类型 | 全部 |
| 客户端 | 猿辅导 App & 猿辅导素养课 App，**仅移动端**（桌面端不支持） |

> ℹ️ 已于 2024.05.13 上线，24 年春季末（6.14）开始灰度，计划期末（6.30）全量使用。

## 三、Amaze 配置（教务运营）

**入口：** Amaze → 班型 → 阶段复习模板 → 添加阶段复习模板

1. 在阶段复习模板中，选择**测试类型：口语模考**；
2. 配置字段：口语模考测试名称、测试开放时长、测试用时。

> ℹ️ 口语模考与普通阶段测试共用阶段复习模板入口，通过「测试类型」字段区分。

## 四、Cyber 内容配置（教研老师）

**入口：** Cyber → 班课产品课程大纲 → 点击「口语模考」条目 → 点击「配置」进入详情页

配置分为两个模块，需**先完成「题目与答案配置」，再进行「视频配置」**。

### 4.1 题目与答案配置

#### Part 结构

| Part 类型 | 说明 |
|---|---|
| **准备 Part**（默认已创建） | 配置不计入打分的热场问题，仅支持「基础问答」题型 |
| **正式 Part**（手动添加） | 点击「添加 Part」新增，最多 6 个 Part，支持三种题型 |

> ⚠️ Part 内必须添加题目，存在空 Part 将无法保存；删除 Part 时，其中的题目会一并删除。

> 💡 建议先配置完弹窗内全部文本，再点击「批量生成 TTS 音频」一键生成所有题目音频。

#### 题型说明

**① 基础问答**

老师提问，学生进行口头回答。

| 配置项 | 说明 |
|---|---|
| 问题文本 | 考官提问内容 |
| 示例回答 | 展示在模考报告中 |
| 示范音频 | 可点击「使用 TTS 生成音频」生成；有问题可点击「编辑 TTS 配置」跳转 SNOW 平台微调 |
| 判答关键词 | 输入给判答模型，用于判断学生回答是否符合要求（支持多个）；「准备 Part」题目无需配置 |
| backup 问题 | 单题最多 2 组；学生未能回答主问题则依次被提问 backup 问题 1、2；配置项与主问题一致 |

**② 图片问答**

老师围绕图片提问，学生回答，图片展示在视频中间题板上。

- 上传图片；
- 配置问答（支持多组），每组问答配置项与「基础问答」完全一致（问题、示例回答、判答关键词、backup 问答）。

**③ 文本朗读**

老师发问后要求学生朗读单词或句子，朗读文本展示在题板上。

| 配置项 | 说明 |
|---|---|
| 问题 | 通常为引导性提示，如「Read the words」 |
| 文本类型 | 选择「单词」或「句子」（不同类型在学生端字号略有差异） |
| 朗读模块 | 单次在题板上展示的朗读文本；支持多个模块，学生朗读完当前模块后自动切换下一模块 |

---

### 4.2 视频配置

保存题目配置后，系统自动将所有问题抽取到「视频配置」弹窗中。

**需配置的视频类型：**

| 视频类型 | 用途 |
|---|---|
| **开始视频** | 通常为老师自我介绍或打招呼视频 |
| **问题视频** | 每道题目对应一个视频 |
| **Part 结束视频** | 通常为模块承上启下的过渡视频 |
| **等待视频** | 等待学生回答时循环播放 |

**批量上传视频规则：**
- 单次可选择多个视频上传；
- 视频文件名末尾必须为 `_序号`（如 `模考视频_4.mp4`），上传后自动定位到对应序号的条目；
- 配置完成后点击右下角「确定」保存。

> ⚠️ 视频配置完成后，若在「题目与答案配置」中更改任意「问题」，将影响「视频配置」条目名称，系统会提示更新，需再次检查视频是否正确匹配。

### 4.3 其他注意事项

- 支持从其他已配置完成的口语模考中复制内容（输入班课产品 ID 并选中目标口语模考）；
- 班课产品中配置的口语模考内容**实时同步**至 Amaze 对应班课；
- **模考解锁前 15 分钟停止同步**，请务必提前完成配置；
- 每天早上 10 点，系统检查未来 48 小时（周五检查未来 78 小时）内将解锁的口语模考，**未完成配置会触发预警邮件**。

## 五、学生端流程

> ⚠️ 仅移动端支持，桌面端不支持。

### 5.1 入口

- 配置了该环节的课程卡片新增「口语模考」入口；
- **卡片一级名称**：由 B 端配置（建议不要直接配为「口语模考」，避免与二级名称重复）；
- **卡片二级名称**：固定为「口语模考」，不可配置；
- 考试开放时间和逾期时间均由 B 端配置。

### 5.2 考试流程

```
考试准备页（点击「开始考试」）
  → 考试中（自动进入倒计时，AI 考官依次播放考题）
  → 考试结束 / 超时自动交卷
  → 等待评估页
  → 报告页
```

**考试规则：**
- 整场考试从点击「开始考试」起自动倒计时，超时未交卷**自动收卷**；
- 考试途中离开，在考试结束时间前可**回到流程继续作答**（按上次进度）；
- 考试过程中学生可以**打开摄像头**。

**支持题型：** 基础问答题、图片问答题、文本朗读题

**金币奖励：** 完成考试即获得 **+30 金币**

### 5.3 等待评估页

- 考试结束后自动跳转，展示本次考试的所有问题和答案；
- 考试结果涉及大模型批改，**固定在第二天早上 9 点**完成批改出结果。

### 5.4 报告页

**三个评分维度（评级从高到低：S / A / B / C / D）：**

| 维度 | 说明 |
|---|---|
| **语音语调** | 发音准确性与语调自然度 |
| **互动交流** | 与考官问答互动的质量 |
| **语言运用** | 语法与词汇的准确使用 |

**报告分两个模块：**
- **细项点评页**：展示三个维度中有问题或答得不好的具体内容；
- **参考对话页**：展示全部问题的参考答案和用户实际回答。

## 六、Focus 数据展示（班主任老师）

### 6.1 带班表列信息

| 字段 | 说明 |
|---|---|
| 作答时长 | 用户本次考试的作答时长 |
| 考试评级 | 整体评级（S/A/B/C/D） |
| 语法词汇 / 语音语调 / 互动交流 | 三个维度的明细得分 |

**支持的筛选项：**
- 作答时长筛选 & 排序
- 考试状态筛选
- 提交时间排序
- 评估明细得分区间筛选
- 评级筛选

### 6.2 详情页

- 点击评级进入详情页，展示用户测试报告预览，支持分享；
- 个人详情页展示用户参与模考次数及每次明细。

### 6.3 高级群发

支持通过高级群发将用户的测试报告发送给家长/学生。
