## 一、功能简介

由**班主任创建自习室**（时长 1 小时），学生可预约参与自习。课中支持：
- 老师视频轮巡监督学生
- 学生拍照提问，老师 AI 搜题后发送讲解视频
- 学生拍照上传自习成果，老师评优展示

---

## 二、功能基本信息

| 维度 | 范围 |
|---|---|
| 阶段 | 所有 |
| 学科 | 所有（**不包括猿编程**） |
| 自习室容量 | 最多 **300 人** |
| 自习室时长 | **1 小时**（含自习时间 + 其他上课时间） |

## 四、如何建课及邀约

- 创建自习室流程与创建答疑课**基本一致**；
- ⚠️ 自习室**不能创建空白教案**，复制教案时只能复制**自习室类型**的答疑课教案；
- **建课关联课程时，务必关联正在上课的课程**（如暑假上课，关联春季课程则看不到学生数据）；
- 给用户发出邀约链接后，用户可点击选择合适的时间预约，存在多个时间时，可**一次性多选**预约；
- 已添加 / 邀约的学生，在「我的课程」顶部位置显示自习室（与答疑课位置相同）。

## 五、如何备课（自习规则页）

> 负责人：郭昱彤

在 focus 自习室列表点击对应课程的「备课」按钮，选择：

### 方式一：创建空白老师教案

1. 点击「创建空白老师教案」→ 选择课件模板；
2. 配置「教案配置」弹窗后点击「确定」创建成功；
3. 进入教案编辑页后，会自动生成**「自习室」页面**（展示自习室规则）。

**「自习室」页面说明：**
- 同一个教案只能配置**一个**自习室页面，不可复制、不可删除；
- 页面默认展示：大标题「自习室」、小标题「自习室时长」和「自习室规则」，标题文本内容、字号、字体、字色可二次编辑；
- 辅导老师需将小标题后面内容**补充完整**；
- 页面下方为「自习室拍照空间展示区域」，该区域**不可与页面内其他元素重叠**，否则保存教案失败。

### 方式二：从其他课程复制

1. 点击「从其他课程复制」→ 输入被复制教案的课程 ID；
2. ⚠️ **只支持复制「自习室课程」的教案**，输入非自习室课程 ID 会失败；
3. 复制成功后自动打开教案编辑页，可进行二次编辑。

## 六、如何开始自习

> 负责人：杨恒

### 6.1 自习前

- 班主任老师翻到**「自习规则页」**课件，点击开启自习（需提前在备课环节配置好内容）；
- 整节课固定 60 分钟，老师自由把握自习时间；
- **上课前不允许开始自习**。

### 6.2 自习中 · 老师端

| 功能 | 说明 |
|---|---|
| 视频轮巡 | 老师端课件区展示所有学生视频，可轮巡监督 |
| 1v1 视频沟通 | 可对任意在线学生发起 1v1 视频通话，其他学生**看不到也听不到** |
| 默认静音 | 自习开始后老师端默认静音，可手动解除 |
| 学生筛选 | 根据「上课跟进」标签筛选（与核心课中老师给学生的标签一致） |
| 需要监督 Tab | 查看「到课离线」和「后台播放」学生，可对「后台播放」学生发起 1v1 沟通 |
| 提问 Tab | 查看学生拍照提问的题目照片（见下方答疑流程） |
| 已提交成果 | 查看学生拍照上传的自习成果，可批量标记为「优秀」，点击缩略图可放大 |

> ⚠️ 班主任中途**不可退出教室**，否则学生端无法正常进行拍照提问及上传自习成果。

**老师答疑流程：**
1. 在「提问」Tab 看到学生题目照片后，系统自动 AI 搜题；
2. 点击「AI 搜题」查看答疑视频：
   - 视频适合 → **发送给学生**；
   - 视频不适合 → 点击「课后答疑」或「视频沟通答疑」；
3. 若任意按钮都不点击，该答疑任务一直存在，对应学生**无法提下一个问题**；

> ⚠️「视频沟通答疑」需更新至 10.13 之后的老师端版本，并联系杨恒配置灰度。**仅此处的视频沟通答疑才算给学生答疑**，其他位置的视频沟通不计入。

### 6.3 自习中 · 学生端

| 功能 | 说明 |
|---|---|
| 开始自习 | 老师点击开始后，学生端课件停留在自习规则页，可正常开 / 关同组其他学生视频 |
| 拍照提问 | 点击拍题按钮拍照，若识别到多题只能选一道；**一节课最多提问 5 次** |
| 提问悬浮窗 | 提问后课件区左侧出现答疑悬浮窗，显示图片及前方等待人数，可点击收起 |
| 收到答疑视频 | 悬浮窗默认展开展示老师发来的答疑视频，答疑记录保留至自习结束 |
| 课后答疑通知 | 若老师选择课后答疑，学生端显示「老师将于自习结束后单独答疑」 |
| 拍照上传成果 | 可拍照提交自习成果，**一节课可上传多个** |

### 6.4 自习成果展示

- 老师点击「结束自习」后，学生端可看到所有**优秀自习成果**；
- 老师端和学生端**各自独立展示**（各看各的）；
- 学生端：自己的优秀成果显示在最前面，可自由滑动并点击大图查看。

### 6.5 结束展示

- 老师点击「结束展示」后，自习正式结束；
- 可进行其他与答疑课类似的活动（班主任自由选择）。

**其他说明：**
- 自习结束后**不会有回放**；
- 一节课**只能发起一次自习**，结束后不可再次发起；
- **支持老师提前下课**。

## 七、Focus 回访功能

> 负责人：田育珍

### 7.1 一线老师单节课回访

老师点击已完课的「回访」，支持筛选用户答疑课表现，并通过高级群发给家长发送对应物料。

**回访维度说明：**

| 维度 | C 端功能描述 | Focus 筛选逻辑 |
|---|---|---|
| **自习成果** | 学生拍照上传；老师按照片维度优选，一个用户可有多张被优选 | 未到课 / 到课未提交 / 到课提交-未优选 / 到课提交-优选 |
| **课堂提问** | 学生拍照提问（最多 5 题）；系统搜题后老师发讲解视频即为解答 | 未提问 / 提问未解答 / 提问已解答（特殊：提问 2 题，一解答一未解答，两个筛选项均可筛出该用户） |
| **1v1 视频** | 老师主动给学生打视频 | 无互动 / 有互动 |

### 7.2 高级群发

**入口：**
- 入口 1：自习室 - 回访 - 高级群发
- 入口 2：带班表 - 自习室列 - 高级群发

**发送内容**：给满足筛选条件且**提交自习成果**的用户发送学习结果，包含：自习时长 + 一张自习成果图。

**图片优先级**：优选图片优先（多张取第一张）；无优选则取提交的第一张。

### 7.3 一线老师带班表列

> 需管理者在带班表的「单次课回访」和「课程累计回访」中配置本列，列名为：**自习室回访**
> 配置地址：https://focus.yuanfudao.com/#/{angular}//old/#/myStudents/supervisorTableConfig

**数据展示范围设置：**
- 可点击「设置」选择本列自习室展示范围；
- 单次课回访：默认显示辅导老师关联本 episode 的自习室数据；
- 课程累计回访：默认展示所有数据；
- 带班表只展示符合筛选条件的自习室数据。

**数据字段说明：**

| 字段 | 说明 |
|---|---|
| 预约 | 自习室维度，展示符合范围的自习室预约次数 |
| 到课 | 自习室维度，展示到课次数，有数据时支持点击 |
| 到课时长 | 自习室维度，到课时长加和（单位：分钟） |
| 提交成果 - 优选 | 有提交成果的自习室数量 / 有任意内容被优选的自习室数量 |
| 提问 - 讲解 | 用户提问题目数量 / 老师发送讲解视频的题目数量（题目维度） |
| 1v1 次数 | 老师与用户视频互动次数加和 |

> 所有数据字段均支持**排序和筛选**；无数据时展示 `-`。

### 7.4 管理数据

在**自习室数据看板**可查看学生的预约到课情况及提问情况。

数据口径参考：[《自习室管理者关注的数据指标》](https://shimo.zhenguanyu.com/sheets/32wyYb8QXrEJSDbK/MODOC/)
