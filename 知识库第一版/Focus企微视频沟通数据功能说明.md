## 一、背景

小初高导流课中部分业务线（小学教辅、中价、初中教辅、高中教辅 IP 达播、商务、站内）对用户服务要求更高，销售团队对**视频沟通**有更高标准和更深入的服务要求。

为此，Focus 对企微视频沟通进行**单独区分统计**，支持带班老师在两个入口查看相关数据。

---

## 二、带班表内查看

**位置：** 带班表 → **开班沟通** Tab → 企微视频数据列

**配置方式：** 需由主管在 **Focus → 管理 → 带班表配置** 中添加该列。

**列内展示（针对单个用户的累计数据）：**
- 累计通话时长
- 接通次数
- 最近一次拨打时间

> ℹ️ 带班表内展示的是该用户的**累计汇总数据**，不支持按时间段筛选。

---

## 三、Focus 主页通话数据面板

**位置：** Focus 主页面 → 右侧**通话数据**面板

展示当天（或所选外呼时间段内）的整体外呼统计数据：

| 指标 | 说明 |
|---|---|
| 通话数 | 本时段内发起的总呼叫次数 |
| 接通 | 成功接通的次数 |
| 有效接通 | 达到有效沟通标准的接通次数 |
| 接通率 | 接通 / 通话数 |
| 有效接通率 | 有效接通 / 通话数 |
| 累计通话时长 | 所有通话的总时长 |
| 平均通话时长 | 累计时长 / 通话数 |

> ℹ️ 面板显示最近更新时间，数据非实时，存在几分钟延迟。

---

## 四、通话详情页

点击通话数据面板右下角「**详情 >>**」进入。

**支持的筛选条件：**
- **呼叫时间**：支持日期区间选择及自定义
- **学生**：按手机号搜索
- **关联班课**：下拉选择
- **只看有效通话**：勾选后仅展示有效接通记录

**详情列表字段：**

| 字段 | 说明 |
|---|---|
| 学生 | 学生昵称 + 手机号 |
| 呼叫时间 | 具体到分钟 |
| 呼叫方式 / 类型 | 如：老师呼出 · 工作手机-手机接听 |
| 通话时长 | 实际通话时间（未接通显示"未接通"）|
| 响铃时长 | 从拨出到接通/挂断的时长 |
| 关联班课 | 该用户关联的班课名称，支持「换绑」「查看详情」|
| 用户画像 | 如购买力分级标签（购买力 1 级 / 2 级等）|
| 微信 | 加微状态（如：已添加-妈妈 / 继承成功）|
| 分层 | 用户分层标签 |

> ℹ️ 页面顶部会提示是否已开启小猿助手通话录音功能及录音对象范围。
