## 一、功能简介

老师在直播课堂发起，学生在讲义上写完后，**拍照上传**获得 AI **个性化点评**。

> 与文本主观题的核心区别：作答方式为拍照（学生手写后上传图片），无订正互动环节。
> 与 AI 拍照订正的核心区别：无 AI 提问 + 学生语音订正环节，仅点评后展示榜单。

## 四、功能详述

### 4.1 如何建题（Cyber 平台）

**入口：**
```
https://cyber.zhenguanyu.com/#/other-tools/subjective-question/list?phase=xiaoxue&subjectId=1&businessLine=cyber
```
导航栏阶段学科选「小学语文 / 新人文 / 读写优++」→「其他」→「AI 主观题调试工作台」

> 注：语文、新人文、读写优++ 的题目创建后统一存放，**不按科目区分**。

**Step 1：新建题目**

| 字段 | 说明 |
|---|---|
| 阶段 | 默认小学 |
| 学科 | 默认与 Cyber 导航栏科目对应 |
| 年级 | 必填，可选一年级上 / 下 ～ 六年级上 / 下 |

**Step 2：编辑题目配置**

**作答方式**：选择「**拍照**」（选「文本」则为普通 AI 主观题）

| 字段 | 字符上限 | 说明 |
|---|---|---|
| 考查内容 | — | 下拉选择：情感主旨分析、人物形象分析、提取关键信息（后期可能增加） |
| 题目材料 | 3000 字符 | 仅作判题依据，学生端不展示；为 ChatGPT 提供完整题目信息 |
| 题干 | 200 字符 | 题目要求 |
| 参考答案 | 400 字符 | 题目标准答案 |

> ⚠️ 上述字段均**不支持**英文输入法下的字符：`, . / < > ? ; ' : " [ ] { } \ | \` ~ ! @ # $ % ^ & * ( ) - = _ +`

**题目图片 & 书写区域配置：**
- 上传方式：本地上传 / 拖拽 / 粘贴（Ctrl+V / ⌘+V）；
- 截图要求：截图需包括题干和学生回答区域，并保留讲义左右两边留白；
- 书写区域：上传后默认展示 1 个书写区域（绿色线框），可调整位置和宽高，需将左右留白包含进去；
- 示例参考：[图片截取与书写区域设置示例](https://tutor-online.fbcontent.cn/20260119//fb2704518b2ee8b06c286cb908d62f49.pdf)

**批改方式**（三选一）：

| 方式 | 说明 |
|---|---|
| 按得分点批改 | 根据命中得分点的情况反馈 |
| 按作答要求批改 | 根据是否满足作答要求反馈（适合开放性题目） |
| 按得分点 & 作答要求批改 | 同时判断两者 |

- 得分点字段：类型、描述（各 ≤100 字符）、是否核心得分点、是否精确匹配，最多 **5 个**；
- 作答要求字段：每条 ≤400 字符，最多 **5 条**。

**Step 3：保存后**，题目详情页包含三个 Tab：
- **题目配置**：可二次编辑
- **基本信息**：可修改年级
- **作答数据**：展示该题目在所有课程中的数据

**Step 4：题目调试**

- **Bot 调试**：填写好 / 中 / 差三种情况的答案数量（默认 5 / 10 / 15）和期望回答，生成评估结果约 **5 分钟**通过企微接收；
- **人工调试**：手动输入文本或图片回答（最多 200 个），支持批量导入（下载 Excel 模板）。

**Step 5：Muse 绑定题目**

课件页面右上角「+ AI 主观题」→ 输入题目 ID → 保存。

> 注：同一题目 ID 绑定多个课件页时，修改后**所有课件页自动同步**。

---

### 4.2 课上如何发起

1. 点击课件右下角「**开始作答**」发起；
2. 课中可查看：
   - **提交率**：分母 = 在线学生数，分子 = 已提交学生数；
   - **点评完成率**：分母 = 已提交人数，分子 = 已听完语音反馈学生数；
3. 结束：点击「**结束作答并展示榜单**」，呈现精彩作答榜。

---

### 4.3 学生端作答流程

**作答前**：老师点击「开始作答」后出现答题卡，中间为题干信息，学生需在讲义或白纸上手写作答。

**拍照流程：**
- 默认拍**单题**方式，可切换拍整页；
- 将作答内容放在拍摄引导框内；
- 设备未放平时，系统提示「请将设备放平拍摄」；
- 本次**不支持从相册选图**。

**拍摄后处理：**

| 处理步骤 | 说明 |
|---|---|
| 图片矫正 | 矫正倾斜图片，去除人脸 |
| 模糊识别 | 模糊时提示「建议重新拍摄」，但仍可提交 |
| 自动框选 | 自动框选学生作答区域；学生可手动调整框的范围（**桌面端无自动框选**） |

> 老师提示语要点：字写端正、放平拍摄、拍摄清晰、作答放在引导框内、拍后将作答内容框选出来。

**图片识别**：学生提交后系统识别，一般 **6～8 秒**完成。

**批改阶段：**
- 图片识别完成后，AI 批改约需 **1～7 秒**；
- 批改完成后展示：**星级 + 金币 + 称号升级**。

**星级与金币：**

| 星级 | 金币 | 称号计入 |
|---|---|---|
| ⭐⭐⭐ 三星 | 10 金币 | ✅ |
| ⭐⭐ 二星 | 8 金币 | ✅ |
| ⭐ 一星 | 5 金币 | ❌ |
| 0 星 | 0 金币 | ❌ |

> 当作答为乱码、无实义答案、空白时，等级为 **0 星**。

**评语反馈**：猿小助语音点评，提到「得分点」时对应词语高亮显示；语音不可重复播放，文字评语可上下滑动查看。

**榜单时学生气泡文案：**

| 状态 | 气泡文案 |
|---|---|
| 上榜 | 恭喜你上榜啦！ |
| 提交未上榜 | 要继续加油呀～ |
| 提交但未听完反馈 | 评语可在课后报告中查看喔～ |
| 未提交 | 这次没有提交，下次要及时作答喔～ |

## 五、Focus 功能（辅导老师）

### 5.1 直播课跟课 · 回访图片

老师需下载最新跟课端，发送回访图片时才会呈现主观题作答情况（主观题 + 客观题组合 / 纯主观题两种形式）。

### 5.2 直播课后 · 回访图片

同上，两种展示形式（主观题 + 客观题 / 纯主观题）。

### 5.3 带班表

**学生作答详情：**
- 测验情况将个性化主观题**单独拆出**，标记星级和是否精彩作答；
- 点击主观题题号，可查看用户作答图片和 AI 个性化反馈文本；
- 正确性计算：**三星、二星 = 正确；一星、0 星、未作答 = 错误**。

**单次课回访 · 测验列：**
支持老师选择本节课重点运营的主观题，结合用户作答情况进行回访。
