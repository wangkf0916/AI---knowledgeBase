## 一、功能概述

每日听读（口语打卡）是学生端「**精练**」tab 下的英语跟读功能，面向 **小低（App 选择 1-2 年级）** 的用户。

从教研角度，听口能力是英语基础能力，也是小低家长最看重的方向：
- 听力侧重**语感培养**；
- 口语侧重**使用效果外化**。

系统每个自然日推送一张英语跟读卡片，用户完成当天内容即算**打卡**。

## 三、学生端使用说明

### 3.1 入口

- **手机端**：精练 tab，当且仅当 App 选择年级为一、二年级时展示；
- **平板端**：同手机端。

### 3.2 内容选择

| 用户类型 | 说明 |
|---|---|
| **在读用户**（新课标一二年级） | 只能学习「班课专属内容」，右上角标记「班课专属内容」 |
| **非在读用户** | 可自主选择一年级/二年级的非在读内容；**切换内容次日生效** |

### 3.3 练习模式

每张跟读卡片支持 4 种练习模式：

| 模式 | 说明 |
|---|---|
| 字母练习 | 跟读字母，完成后评星；自动播放录音，用户可选择是否重新练习；滑动进入下一题 |
| 单词练习 | 跟读单词 |
| 自然拼读练习 | 跟读拼读内容 |
| 句子练习 | 跟读句子 |

**个性化推荐练习：** 在没有重点内容的天数，会基于用户历史跟读不够好的内容推荐个性化练习。

### 3.4 单次练习结果页

根据练习情况展示 3 种结果页，页面下方展示本次练习中的**精彩内容**（评分 ≥ 2 星才展示）。

### 3.5 金币奖励

> ⚠️ 该功能已**取消金币奖励**，以下为原规则，仅供参考。

~~首次完成当天跟读卡片 +6 金币；重复练习同一张卡片不额外给金币。~~

### 3.6 打卡与日历

- 完成当天内容记为「打卡」；
- 打卡天数记录在**首页**和**日历页**；
- 日历页：「已打卡」显示猿头样式，「未完成」日期有红点；
- 点击首页累计练习卡片区域可进入日历页。

### 3.7 打卡活动（月度宝箱）

> 注：仅完成当天内容才算打卡 +1，重复练习不计入打卡。

当前自然月累计打卡不同天数，可开启不同等级宝箱，获得不同数量金币。

此活动进行**灰度**，非灰度运营策略班级用户才可见打卡活动入口。

## 四、Cyber 配置说明

**入口：** [Cyber - 拓展训练 - 听说练习](https://cyber.zhenguanyu.com/#/expansion-training/listen-speak)

### 4.1 训练组

- 每个训练组有 **366 天**内容需要布置，以全年自然日为维度；
- 每日训练内容**最多布置 5 道练习**；
- 目前共 5 个训练组：非在读一二年级 + 在读新课标零一二年级；
- 如需新增训练组，需找产品提需求（联系廖芸 / 姚佳翔）。

### 4.2 每日训练布置

- 可按自然日期查找对应日期的内容；
- 已有内容显示「已布置题目数」；未布置显示「!」icon；
- 点击「新建」按钮新增题目；

**新建题目配置项：**

| 配置项 | 说明 |
|---|---|
| 练习类型 | 字母 / 单词 / 自然拼读 / 句子（每天最多 2 种类型） |
| 文本内容 | 布置具体练习文本 |
| 配图 | 题目配图 |
| 音频 | 题目音频 |
| 是否重点习题 | 标记后用于客户端错题重复推荐 |

- 列表区支持**拖拽调整题目顺序**（影响学生端展示顺序）；
- 支持对已有题目进行编辑和删除。

## 五、Focus 平台说明

### 5.1 学生个人详情页

- 新增「**拓展**」模块 → 点击「口语打卡」进入该学生的口语打卡模块；
- 顶部展示累计数据：**累计练习天数** + **本月打卡天数**（与 App 一致）。

**跟读卡片模块：**
- 展示每天推送的跟读卡片维度的练习及打卡数据；
- 多次练习的详情都在对应卡片下展示；
- 数据包括：每次练习的开口准确程度、提交时间；
- 点击具体开口可查看具体题目及学生音频。

**学习记录模块：**
- 展示用户每天的具体学习记录（学了什么、练了什么、练习情况）；
- 同一天可练习多张不同日期的跟读卡片，多次练习均记录。

### 5.2 带班列表页

- 「拓展」列表页 → 「口语打卡」列，展示近 7 天跟读卡片维度的全班学生数据；
- 数据包括：打卡状态 / 最新一次练习的满星率 / 练习时间；
- 支持筛选。

## 六、常见问题

**Q1：为什么某用户没有某天的学习卡片？**
系统仅从用户**第一次进入**开始生成学习卡片，且仅保留**最近 180 天**的卡片供用户反复练习。

**Q2：在读用户的「班课专属内容」有效期是什么？**
取当前用户所购买班课的**最晚结课时间**。
