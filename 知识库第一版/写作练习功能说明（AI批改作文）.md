## 一、功能概述

在语文课后新增「**写作练习**」环节，学生将手写作文拍照上传，系统通过 OCR 识别文字后，由 **AI（GPT）** 进行自动批改，生成包含字句批改、详细点评、个性化润色和素材积累的完整批改报告。

**功能定位**：课程增值（在语文 / 人文系统班中为课程增值），对标科大讯飞作文批改。

---

## 二、功能范围

| 维度 | 范围 |
|---|---|
| 阶段 | 小学 |
| 年级 | 3、4、5、6 年级 |
| 学科 | 语文 |
| 班课类型 | 系统班 |

---

## 三、整体流程

```
上传作文照片 → OCR 识别 + 文字校对 → 提交批改 → 等待批改（T+2天 18:00）→ 查看批改报告
```

## 四、学生端功能详述

### 4.1 写作练习环节入口

**入口位置**：班课主页写作练习环节（排在最后）

**环节状态说明：**

| 状态 | 展示文案（手机/Pad） | 展示文案（PC） |
|---|---|---|
| 未开放 | 空 | 待开放 |
| 已开放未提交 | XX 后逾期 | 请尽快提交 |
| 已提交未批改 | 待批改 | 待批改 |
| 已批改未查看 | 已批改 | 已批改 |
| 已查看 | ✓（对号 icon） | 已完成 |
| 逾期未完成 | 逾期未完成 | 逾期未完成 |
| 异常 | 异常 | 异常 |

**开放逻辑**：打下课铃后开放。

**学习任务提醒**：未完成时展示「写作练习 ×1」，排在回放和预习之后。

**逾期页面**：文案「哎呀，超过提交截止时间了，下次要准时提交练习哦。」，无查看解析入口。

---

### 4.2 上传作文照片

**上传提示弹窗**（每次都展示，用户手动点击「不再提示」后不再展示）：
> 请按照写作顺序进行拍摄，拍照时请确保纸张平整，图片内的字迹清晰可见。

**下一步按钮规则：**
- 未上传时：置灰；
- 上传数量 ≥ 1 且**全部上传成功**后：高亮可点击；
- 点击时：先校验图片中是否有文字，若无文字则清空照片并展示弹窗阻塞流程；通过后跳转 OCR 识别页。

**返回逻辑**：展示二次确认弹窗（「取消」/ 「离开」），离开后**已上传照片不保留**，数据清空。

> PC 端操作为本地上传文件，其余规则与手机/Pad 一致。

---

### 4.3 OCR 识别结果页（修正文字）

**预览状态（手机/Pad 默认）：**
- 作文文字展示在格子纸背景，每字/每标点对应一格；拼音或英文每个字母单独一格（不展示声调）；
- 点击「修改文本」按钮进入编辑状态；
- PC 端只有编辑状态，无预览/编辑切换。

**编辑状态：**
- 作文以文本框形式展示（无格子纸背景）；
- 光标默认在第一个文字后；
- 点击「完成」退出编辑；
- 若清空全部文字再提交，展示弹窗「未识别到文字，提交无效」→ 按钮「我知道了」→ 跳转回上传照片页。

**提交批改时校验顺序（优先级）：**

1. **敏感词校验**（优先）：若检测到敏感词 → 弹窗「检测到文章内存在敏感词汇，请修改后重新拍照上传」→ 清空照片并跳转上传页；
2. **字数校验**：

| 年级 | 最低字数 |
|---|---|
| 三、四年级 | 120 字 |
| 五、六年级 | 200 字 |

- 字数不足：弹窗提示（不强制阻塞），可「坚持提交」跳转等待页，或「重新上传」返回；
- 字数达标：**发放 30 金币**（按时提交奖励），展示激励动效「按时完成」，动效结束后跳转等待页。

**返回逻辑**：同上传照片页，离开后数据清空。

### 4.4 等待页

| 内容 | 说明 |
|---|---|
| 页面标题 | 写作练习 |
| 作文提交时间 | 「作文提交时间：{年月日时分}」，左上角展示 |
| 固定文案 | 作文提交成功，等待批改 |
| 预计完成时间 | 「预计 {年月日时分} 前完成批改」，为**提交当天 T+2 天 18:00** |
| 我的作文 | 展示上传的作文照片，多图按顺序排列，点击可全屏查看，多图支持左右滑动 |
| 作文题目 | 展示作文题干和要求 |
| 返回 | 直接返回班课主页 |

**等待页分享文案：**
- 主文案：XX 同学提交了一篇精彩的作文，快来看看吧
- 副文案：作文题目为《XXXX》

### 4.5 批改报告

**整体结构（Tab 导航，Tab 吸顶常驻）：**

| Tab / 模块 | 内容 |
|---|---|
| 头部综合信息 | 作文题目（最多两行）、等级、雷达图 |
| 字句批改 | 字和句维度的逐句批注 |
| 详细点评 | 细项点评 + 思考问题 |
| 个性化润色 | AI 全文改写（润色文字高亮） |
| 素材积累 | 讲师配置的好词好句素材模块 |

#### 作文成绩

| 等级 | 分数区间（定级用） |
|---|---|
| 优秀 | 70 ～ 100 分 |
| 良好 | 50 ～ 69 分 |
| 中等 | 其余 |

> - 手机端：**不展示分数**，仅展示等级；
> - Pad / PC 端：展示分数，**分数下限为 30**（低于 30 分统一展示为 30）；
> - 等级分数说明弹窗文案：「评分规则：从作文内容、结构、语言三个维度分别进行细项打分，再根据不同的权重计算作文总分。定级规则：分为 3 个等级，80-100 分为优秀；70-79 为良好；其余为中等。」（⚠️ 说明中的分数区间与真实定级分数区间不同，为历史遗留设计）

#### 雷达图

6 个维度：**审题、立意、详略、首尾、词汇、语句**（每项得分由教研组获取）。

> 若作文字数低于最低字数要求，不展示雷达图，字句批改和详细点评展示「作文字数过少，无相关内容」。

#### 字句批改

- 格子纸背景展示作文，原文标注批注序号；
- 批注类型及文案：

| 类型 | 文案格式 |
|---|---|
| 错别字 | 「XX」疑似错别字，应改为「XX」 |
| 精彩用词 | 「XXXX」（教研组提供） |
| 用词不当 | 「XXXX」（教研组提供） |
| 精彩描写 | 「XXXX」（教研组提供） |
| 表达不当 | 「XXXX」（教研组提供） |

- **手机/Pad**：批注在行间展示文本框，默认全部展开；
- **Pad**：批注从上往下排，第一个顶部与格子纸顶部对齐；
- **PC**：左侧原文 + 右侧批注（左右布局）。

#### 详细点评

- **细项点评**：展示全部点评，不区分表扬与建议，表扬在前；
- **思考问题**：引导文案「请思考以下问题并尝试将答案融入写作中！」，问题内容由教研组提供。

#### 个性化润色

- 提示文案：「老师对你的这篇文章进行了全文改写，希望对你有帮助」；
- 润色后原文中**修改部分高亮展示**。

#### 素材积累

- 提示文案：「熟记这些写作素材会对写作水平有很大提升哦！」；
- 可配置多个模块，每个模块：小标题 + 内容（均由讲师配置）。

#### 其他功能

- **作文题干**：点击展开弹窗，展示题干和作文要求；
- **作文原图**：点击全屏查看上传的照片，多图支持左右滑动切换；
- **报告加载失败**：展示失败页，按钮「点击重试」。

## 五、金币激励规则

| 奖励类型 | 触发时机 | 金币数量 | 激励动效文案 |
|---|---|---|---|
| 按时提交 | 字数达标时提交（OCR 提交时） | **30 金币** | 按时完成 |
| 等级奖励 - 优秀 | 批改完成后生成报告时下发，首次查看报告时展示动效 | **30 金币** | 文采斐然 |
| 等级奖励 - 良好 | 同上 | **20 金币** | 渐入佳境 |
| 等级奖励 - 中等 | 同上 | **10 金币** | 未来可期 |

> 字数低于最低要求时**无等级奖励**。

**学生端金币明细文案：**
- 写作练习按时提交 +30
- 写作练习成绩为优秀 / 良好 / 中等 +30 / +20 / +10

## 九、B 端配置

- 配置范围：小学、系统班、语文学科、3～6 年级；

| 作文文体 | 必填 | 如「记叙文、议论文」等 |
| 字数要求 | 必填 | 填写数字 |
| 素材积累 | 必填 | 可配置多个模块，每模块含「小标题 + 具体内容」 |
