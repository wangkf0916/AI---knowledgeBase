## 一、功能简介

**适用范围：高中导流课**

销售在开课前向用户发送**学情诊断问卷**，用户填写分数、选科、薄弱板块等信息后，系统自动生成**学情诊断与规划报告**。销售可在 Focus 工作台或企微侧边栏查看、预览、发送报告，在电话深沟阶段对报告进行专业解读，提升深沟效率和专业度。

**核心流程：**
```
发送专属问卷链接 → 用户填写学情信息 → 系统生成诊断报告 → 销售查看/预览报告 → 电话深沟解读 → 发送报告给用户留存
```

## 二、问卷填写

### 2.1 分数输入规则

- 输入提示文案：**请填写分数（整数）**
- 输入限制：
  - 不允许输入小数点
  - 不允许超过 3 位数
  - 输入值超过满分时自动填充为满分

### 2.2 专属问卷链接

问卷链接与 userId **一一对应**，无论用哪个手机号登录，填写数据均存储至该链接对应的用户下。

- 登录手机号可以与购课手机号不一致；若不一致，该手机号自动存储为 Focus 中该用户的联系手机号；
- 群发和单独发送时，每个用户收到的均为专属链接（非通用链接）。

### 2.3 上海 / 海南特殊处理

| 省份 | 差异点 | 分数转换公式 |
|---|---|---|
| **海南** | 基本信息页去掉"目前分数"；增加"目前得分"独立页面（意向科目+各科分数）| 转换分 = 80x/75 + 100（四舍五入取整） |
| **上海** | 基本信息页保持不变，各科目输入框提示"请填写原始分数（整数）" | 转换分 = 54x/75 + 120（四舍五入取整） |

> ℹ️ 海南"目前得分"页中：意向科目为三门主科 + 意向选科，最多可选三科（超出 toast 提示）；语数外满分 150，副科满分 100。

## 三、问卷发送

### 3.1 高级群发发送问卷

| 字段 | 内容 |
|---|---|
| 主标题 | 学情诊断问卷 |
| 副标题 | 点击填写，三分钟了解升学规划 |
| 图片 | 小猿优课 Logo |

### 3.2 企微侧边栏单发问卷

企微侧边栏新增**学情诊断 Tab**（仅高中阶段展示），支持选择问卷后在当前聊天中发送专属链接卡片（样式同高级群发）。

## 四、报告内容说明

> ℹ️ 报告链接**无需登录**即可查看。

### 4.1 封面信息

| 字段 | 来源 |
|---|---|
| 标题 | 学情诊断与规划报告 |
| 时间 | 报告生成时间，格式 yyyy.mm.dd |
| 学生 | 问卷中填写的姓名 |
| 省份 | 问卷中选择的省份/直辖市 |
| 年级 | 根据高考年份计算（高考年份为高三，依此类推） |
| 选科 | 问卷中选择的意向选科 |
| 学情诊断师 | 发送报告的班主任姓名 + Focus 头像 |
| 固定文案 | 本报告由{班主任姓名}老师生成，如有问题请联系老师咨询 |

### 4.2 总分位置图表

展示用户分数在高考分数线中的位置：

- 展示节点：小于用户分数的 1 个分数线 + 大于等于用户分数的 3 个分数线（最少展示 3 个）；
  - 若用户分数低于专科线：展示专科线、本科线、一本线，用户位置显示在最左端；
  - 若用户分数高于 985 线：展示双一流线、211线、985线；
- 节点枚举：专科线、本科线、一本线、双一流线、211线、985线；
- 分数线和排名取**最新一年**高考数据；排名超过一万展示 x.y 万位（四舍五入保一位小数）；
- 上海、海南总分展示**转换分**（公式见第二章）。

**成绩分析文案示例（标准省份）：**
> 当前总分 X 分，对比{最新年}{省份}高考成绩信息，你的成绩比{低于你的分数线}高出 Y 分，距离{高于你的分数线}还差 Z 分，继续努力！

**位次分析文案示例：**
> {最新年}{省份}高考位次表总人数 X 人，你的成绩排名区间是 Y-Z，超过了 N% 的考生
> 其中 N% = （总人数 - 排名区间最小值）/ 总人数 × 100%（四舍五入取整）

### 4.3 各科提分分析

- 各科分差从大到小排列（分差相同随机顺序）；
- 预计总提分空间 = 所有科目分差之和；分差为 0 的科目不展示「提升 X 分」标签；
- 环形图强调分差最大的 **3 个科目**，其余合并为"其他"；
  - 分差 > 0 的科目少于 3 科时有几科展示几科；全部为 0 时不展示环形图；
- 上海、海南展示**原始分**（并增加说明文案）。

**推荐院校：** 每个分数档最多展示 3 所院校，标签按"冲 / 稳 / 保"展示（三方返回"难"映射为"冲"，"易"映射为"保"）。

### 4.4 学科提分建议

- 科目 Tab 按分差从大到小从左到右排列；
- 图表展示当前分数、预估提分后分数、分差（海南/上海展示原始分）；
- 重难点板块来自用户问卷中选择的薄弱板块，内容由 **Amaze** 配置（每科最多 3 个，文案上限 160 字）；
  - 支持多级标题和加粗字体，展示顺序：重难点板块 > 非重难点板块；
  - 若某科目未配置重难点板块，则不展示该科目。

> Amaze 配置入口：[https://amaze.zhenguanyu.com/#/jwc/academic-assessment/section](https://amaze.zhenguanyu.com/#/jwc/academic-assessment/section)

### 4.5 省份高考信息

**高考人数趋势：** 取用户省份近 5 年数据，折线图展示，附文案分析（人数增加/减少/不变三种模板）。

**高考分数区间及排名：** 推荐高于用户分数的两个分数线，展示该分数线的平均分及对应排名，标尺刻度 50 分一格。

**院校录取情况：**

| 院校分类 | 录取人数（万人） | 录取率 |
|---|---|---|
| 985院校 | — | — |
| 211院校 | — | — |
| 一本院校 | — | — |
| 本科院校 | — | — |
| 专科院校 | — | — |

> ℹ️ 数据来自三方，某省若某类院校无数据，则不展示该行。录取率 = 录取人数 / 当年该省高考总人数（四舍五入保一位小数）。

### 4.6 学年大事记 & 成长寄语

- **学年大事记**：每个学年两张图片（上下学期各一张），由 Amaze 配置，无需区分省份；已发出的报告若大事记被编辑，仍展示发送时的内容；
- **成长寄语**：内容由 Amaze 配置（[配置入口](https://amaze.zhenguanyu.com/#/jwc/academic-assessment/message)），逻辑与原线上一致。

## 五、Amaze 配置说明

### 5.1 学年大事记配置

> 入口：Amaze → 学情诊断测评 → 学年大事记

- 筛选：年级（高一/高二/高三）、学期（上学期/下学期）；
- 每个学期**只能配置一个**，重复配置时 toast 提示；
- **编辑态只允许修改图片**，不允许修改年级/学期；
- 删除操作需二次确认。

### 5.2 知识板块富文本支持

Amaze 知识板块的"板块重要性"/"薄弱成因分析"/"提升方法"支持：
- **加粗**：选中文字加粗
- **有序列表**：最多三级，样式使用 Cyber 有序列表组件

## 六、Focus / 企微侧边栏发送报告

### 6.1 企微侧边栏

- 展示**近半年**生成的报告，不分页；无报告时展示"暂无数据"；
- 支持：**预览**（弹窗）、**复制链接**、**发送报告**；
- 发送报告格式（卡片链接）：

| 字段 | 内容 |
|---|---|
| 主标题 | {学生真实姓名}同学的学情诊断与规划报告 |
| 副标题 | 点击查看班主任的专业解读 |
| 图片 | UI 提供 |

### 6.2 Focus 带班表问卷收集列

Focus → 带班表 → 问卷收集 → 学情诊断列报告列表，新增**发送报告**按钮，点击后给该用户微信单独发送专属报告链接卡片（样式同上）。

## 七、问卷数据同步至 Focus

用户填写问卷后，以下字段**自动同步**至 Focus 用户详情（Focus 中已有值时不覆盖）：

| Focus 字段 | 问卷字段 | 备注 |
|---|---|---|
| 真实姓名 | 学生姓名 | — |
| 年级 | 高考年份 | 高考年份当年 = 高三，依此类推 |
| 高考选科 | 意向科目/意向首选科目/意向再选科目 | 只填副科时自动加上语数外三门主科 |
| 科目/薄弱点 | 薄弱知识板块 | 问卷固定选项，同步时用「、」隔开 |
